# Working with the world

These tools help populate the world and stage scenes. Most settings can be authored in the IDE; script examples on each page connect the result to gameplay events.

| Section | What you can do |
| --- | --- |
| [World objects](/docs/hollowengine/world/objects) | Place models, effects and sounds, build object hierarchies and edit individual instances. |
| [Decals](/docs/hollowengine/world/decals) | Project images or video onto the environment. |
| [Colliders](/docs/hollowengine/world/colliders) | Add collisions, interaction areas and hits on model parts. |

For asset preparation, see [Models and animation](/docs/hollowengine/models) and [VFX](/docs/hollowengine/vfx). Shared key, curve and section editing is covered in [Timeline](/docs/hollowengine/ide/timeline).

Camera sequences and their timeline are covered in [Narrative cutscenes](/docs/hollowengine/addons/narrative/cutscenes).
