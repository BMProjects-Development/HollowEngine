<center><h1>Getting Started with HollowEngine</h1></center>

**Learn how to create your first scripts in HollowEngine.**

## Installation and launch

Download HollowEngine and the [Kotlin compiler addon](/docs/hollowengine/addons/compiler) from the same [project release](https://github.com/HollowHorizon/HollowEngine/releases). Choose files for your Minecraft version and put both `.jar` files in `mods`. The compiler lets you write and change scripts.

A finished project can run without the compiler if its [export](/docs/hollowengine/project-export) includes compiled scripts. HollowEngine itself is still required.

After installing the mod and launching the game, click the HollowEngine logo in the upper-left corner. It opens the IDE workspace with four menus:

- File: Useful actions such as opening the mod folder and reloading client and server resources.
- Windows: The engine's main tools, including project files, cutscenes, editors, and more.
- Tools: Editor mode, transform controls, the UI profiler, and interface scale.
- Help: Useful information such as links to the project community and documentation.

![HollowEngine IDE workspace](/hollowengine/pictures/ide/workspace.webp)

For more information about the editor, see [Working with the IDE](/docs/hollowengine/ide). If you need to add custom resources such as models, textures, or sounds, read the [Assets](/docs/hollowengine/assets) section, which explains project files and how to reference them.

## Checking whether the compiler works

Once you enter a world, you can check whether the compiler is working. Open **Windows > Console**, switch to the **Logs** tab, and select Kotlin script mode in the input line.
Enter the code and click the run button to the right of the input. It sends a message to your player:

```kotlin
player?.let {
    it.sendSystemMessage("Hello, ${it.name.string}!".literal)
}
```

There is no player in the main menu: `player` is `null`, so no message is sent. Enter a world for this check.

![First script](/hollowengine/pictures/guide/first-script.webp)

After compilation, your message should appear in the chat:

![First script result](/hollowengine/pictures/guide/first-script-result.webp)

If you encounter a problem, contact us on [Telegram](https://t.me/hollowengine_community) and attach your logs (the `logs/latest.log` file) or a screenshot of the error.

## Creating and configuring your first NPC

The easiest way to create an NPC is to use the **Developer Tool**, which you can find on the mod's Creative Mode tab.
Right-click with the tool to create an NPC. You can then right-click the NPC to edit it. You can also Shift-right-click the air to configure yourself in the same way 👀

![First NPC](/hollowengine/pictures/guide/first-npc.webp)

The editor lets you configure the NPC's name, properties, attributes, model, scripts, and much more.

## Creating a script and attaching it to an NPC

Let's create a simple script that makes an NPC attack a player whenever they get too close.

In the **Project** tree, create `scripts/examples`, then use its context menu to create a [node script](/docs/hollowengine/scripting/node) named `guard.node.kts`. Its full path from the game directory is `hollowengine/scripts/examples/guard.node.kts`.

![Node script](/hollowengine/pictures/guide/node-script.webp)

By default, a node like this is attached to the server and starts with it after being attached through a command. We need the node to have access to an NPC and be attached to that NPC instead.
Declare what the script attaches to at the start of the file:

```kotlin
@file:Attach(NpcEntity::class)
```

![NPC node](/hollowengine/pictures/guide/npc-node.webp)

Now write the script itself:

```kotlin
@file:Attach(NpcEntity::class)

val npc = this@NpcEntity
val radius by editor.property("Attack radius", min = 1.0, max = 32.0) { 10 }
val goBack by editor.property("Return to the starting point?") { true }
var startPos = Vec3.ZERO

onStart {
    startPos = npc.position()
}

onUpdate(every = 20.ticks) {
    val target = npc.level().players()
        .filter { it.isAlive && !it.isSpectator && !it.abilities.instabuild }
        .filter { npc.distanceTo(it) < radius }
        .minByOrNull { it.distanceTo(npc) }

    npc.setTarget(target)
    if (target == null) {
        if (goBack) {
            npc.navigation.moveTo(startPos.x, startPos.y, startPos.z, 1.0)
        } else {
            npc.navigation.stop()
        }
    }
}
```

Node scripts import `NpcEntity`, `Vec3`, `onStart`, `onUpdate`, and `.ticks` automatically. `this@NpcEntity` is the entity you attached the file to. Once a second, the script chooses the closest living player within range, excluding Creative Mode and spectators. If no player qualifies, it clears the attack target and returns to its starting point. Reloading the node captures that point again.

You can now attach the script to the NPC you created. Open the Scripts section in the NPC editor and find the script there:

![Attaching the script](/hollowengine/pictures/guide/attach-script.webp)

Wait for compilation on the first attachment. The editor then shows **Attack radius** and **Return to the starting point?**. Change the radius and check how close you need to get before the NPC notices you.

![Attached script](/hollowengine/pictures/guide/attached-script.webp)

:::warning
In Survival Mode, the NPC attacks as soon as you enter its radius. Configure it in Creative Mode, then switch to Survival to test it.
:::

## Creating a dialogue interaction

Create `hollowengine/scripts/examples/npc_dialogue.node.kts`. It starts a dialogue on right-click. Detach `guard.node.kts` from this NPC or use another character for this test.

```kotlin
// Declare that this script is attached to an NPC
@file:Attach(NpcEntity::class)

import net.minecraft.server.level.ServerPlayer

// Set the name and description shown in the editor
editor.name("Dialogue interaction")
editor.description("Right-click the NPC to start a dialogue.")

// Add a few more editor properties.
// `assets = listOf("story")` lets the editor select any `.story` script.
// `restart=true` restarts the script when this value changes. Without it, this property would update,
// but the `dialogue` variable below would not.
val story by editor.property<String>("Story file", assets = listOf("story"), restart = true) {
    "scripts/examples/npc_dialogue.story"
}
val speaker by editor.property<String>("NPC name in the story", restart = true) { "Guide" }
val fromTheStart by editor.property<Boolean>("Always start from the beginning?") { true }

val npc = this@NpcEntity
// This dialogue controller is shared by all players. Use a HashMap if each player needs a separate controller.
// The path selected in the editor starts with `scripts`, while DialogueController expects a path relative
// to that folder, so remove the redundant prefix.
val dialogue = DialogueController(story.removePrefix("scripts/"))

onInteract { event ->
    if (dialogue.isRunning) return@onInteract
    // Get the server-side player
    val player = event.player as? ServerPlayer ?: return@onInteract
    // Reset the dialogue when it should always start over, for example if the player died during it
    if (fromTheStart) dialogue.reset()
    dialogue.start(player) {
        // Add our NPC as a character. Its default name is Guide.
        character(speaker, DialogueCharacter.of(npc))
        // Add a variable that can be used in the story, such as the player's name
        put("name", player.name.string)
    }
}

// Save the current dialogue progress to the NPC's entity data
onSave { context -> dialogue.save("dialogue", context.tag) }
onLoad { context -> dialogue.load("dialogue", context.tag) }
```

This NPC shares one controller: repeated right-clicks do not start another conversation while one is running. Independent conversations need a controller and saved progress for each player; see [dialogue controllers](/docs/hollowengine/dialogues/controllers).

Create `hollowengine/scripts/examples/npc_dialogue.story` alongside the node script and paste the following:

```story
// Example dialogue for scripts/examples/npc_dialogue.node.kts.

# Start

Guide: Hello, {name}! I am an NPC controlled by a script through a dialogue.
Guide: Would you like to know how I work?

@choice "Yes, tell me"
    Guide: My script, npc_dialogue.node.kts, listens for <b>onInteract</b> and starts this story.
    Guide: Everything I say is stored in <wave>npc_dialogue.story</wave>, next to the script itself.
@choice "Maybe later"
    Guide: All right, come back when you have time.
```

The project folder should now contain these files:

```text
hollowengine/scripts/examples/
├─ guard.node.kts
├─ npc_dialogue.node.kts
└─ npc_dialogue.story
```
