# Remote editing

Connect to a dedicated server to open its project in the HollowEngine IDE. From inside the game, you can edit scripts and other text files, create folders, and rename, move, or delete project files.

## Who gets access

Remote editing is disabled by default on dedicated servers. Open `config/hollowengine/remote-project.toml` in the server's working directory. These settings apply in both Minecraft authentication modes.

:::warning
The token grants access to project files and lets editors start and stop server scripts. Share it only with trusted editors. With `online-mode=false`, a regular Minecraft connection can carry the token unencrypted. Use an encrypted tunnel or VPN for access over the Internet.
:::

Replace the previous `editors` setting with `token` and `allowlist`. Generate a random 32-byte secret, for example in hexadecimal, and paste it into `token`. An empty token or `enabled = false` closes access for everyone.

```toml
enabled = true
token = ""
allowlist = ["127.0.0.1", "::1"]
```

The example allows connections from the server machine. Add IPv4 addresses, IPv6 addresses, or CIDR ranges such as `192.168.1.0/24` as needed. An empty `allowlist` accepts a token from any IP. If a player connects through a proxy, the list is checked against the peer address the server sees.

Enter the token again when you reconnect. Applying a new token or allowlist revokes previous grants. The same grant controls access to `/he scripting`. Managing scripts in the entity inspector also requires entity editing permissions.

## Opening the server project

1. Connect to a server running the same HollowEngine version as your client and open **Windows > Project**.
2. Choose **Unlock Server Project** from the dropdown next to the project name. Copy the token from the server administrator and click **Paste Token and Connect**.
3. Expand a folder and double-click a file. The IDE loads each folder's contents as you expand it.
4. Press `Ctrl + S` to save your edits. The tab is marked **Server** and continues to save to the server if you switch the tree to **Local**.

The tree gives you access to `scripts`, `assets`, `data`, and `META-INF`. The limit is 2 MiB per file. The IDE selects an editor based on the file type, including formats supplied by addons installed on the client. For example, Narrative opens a `.story` file as a graph and provides JSON highlighting in text mode. 3D model previews are currently unavailable for server files. The dropdown is hidden in singleplayer.

## When another editor changes the file

The server notifies connected editors when someone saves through the IDE. A tab with no unsaved edits updates right away. If you have unsaved edits, they stay in the tab and the IDE shows a conflict. For text files, choose **Resolve > Open Server Version** to bring over the changes you need by hand. To send your edits, choose **Keep My Edits for the Next Save** and press `Ctrl + S`. To accept the other editor's changes, choose **Replace My Edits with Server Version**.

If a file changes directly on the server's disk, use **Refresh Expanded Folders** from the project context menu to refresh the tree and open tabs. If the server version changes again after refreshing, the IDE reports a conflict on your next save.
