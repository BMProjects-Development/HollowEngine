<center><h1>Stories and dialogues</h1></center>

Build a conversation in the IDE and test it in the game. A story can also move NPCs, wait for a player to enter an area, or change the world.

## Your first story

1. Install the [Narrative addon](/docs/hollowengine/addons/narrative) and the [Kotlin compiler addon](/docs/hollowengine/addons/compiler). Add `hollowengine-narrative` to the project's dependencies.
2. In the **Project** window, right-click the `scripts` folder and choose **New Script > Dialogue**. Name the file `greeting.story`. Open it to see **Start** connected to a **Phrase**.
3. Edit the speaker and text on the **Phrase** node. Try `Guide` and `Welcome to the village!`.
4. Save the file. Enter a world with operator permissions and run the command below as a player.

```mcfunction
/he story entity @s start "greeting.story" greeting
```

The player sees the line in the dialogue overlay. The default overlay advances automatically after a reading delay. Press `Enter` to reveal the full line or move on. `/he dialogue advance` moves on immediately. The story ends when there is no next step.

## Add an answer

Right-click empty space in the graph and add **Choice**. Connect the phrase's flow output to the choice's flow input. Add two options, then connect each option to a different **Phrase**. Save and run the same command again. Each answer now leads to its own line. Press a number key to vote, or use the arrows to highlight an answer and `Enter` to confirm.

Several answers can also lead to the same line. In the example below, three options lead to two different lines.
