<center><h1>Dialogue System</h1></center>

*Write branching scenes in a compact language and start them from Kotlin scripts.*

![Dialogue system](/hollowengine/titles/dialogues/index.webp)

Dialogue scenarios use `.story` files. They live beside Kotlin scripts under `hollowengine/scripts`, but use a dedicated line-based language with highlighting, diagnostics, completion, and navigation in the built-in IDE.

For example, `hollowengine/scripts/stories/gate.story` has the address `project:stories/gate.story`.

## First story

```story
# Start

Guard: Halt. You have {money} coins.[-] Passage costs 20.

@choice "Pay 20 coins" id=pay if=money>=20
    @set money = money - 20
    Guard: You may pass.
@choice "Leave" id=leave
    Guard: Come back when you are ready.
```

Adjacent `@choice` blocks form one menu. Only the selected block runs. `if=` hides an unavailable option, while `id=` gives it a stable identifier that does not depend on displayed or translated text.

## Starting it from Kotlin

```kotlin
import ru.hollowhorizon.hollowengine.common.dialogue.DialogueCharacter
import ru.hollowhorizon.hollowengine.common.dialogue.DialogueController

val gateDialogue = DialogueController("project:stories/gate.story")

@State
suspend fun talkToGuard() {
    gateDialogue.start(player) {
        character("Guard", DialogueCharacter.of(guard))
        put("money", 35)
    }
}
```

The first participant is automatically available as `player`. Other characters are bound under the names used by the story.
