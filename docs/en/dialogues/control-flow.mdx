<center><h1>Control Flow</h1></center>

*Branch, loop, call sections, and coordinate parallel actions.*

![Dialogue control flow](/hollowengine/titles/dialogues/flow.webp)

## Conditions and loops

```story
@if money >= 20 && hasPass
    Guard: You can enter.
@else-if money >= 20
    Guard: You still need a pass.
@else
    Guard: Come back with 20 coins.

@while attempts < 3
    @set attempts = attempts + 1
    Guard: Attempt {attempts}.
```

`@else-if` and `@elseif` are equivalent. An `@else-if` or `@else` must directly follow its `@if` chain at the same indentation level.

## Choices

```story
@choice "Buy a pass" id=buy if="money >= price"
    @set money = money - price
    @jump #Paid
@choice "Ask about the city" id=city
    @call #CityInfo
@choice "Leave" id=leave
    @jump #End
```

Choice text must be quoted. Adjacent choices at the same indentation level belong to the same menu. `if=` controls visibility and `id=` supplies a stable key for Kotlin handlers and translations.

With several participants, the option with the most votes wins. Ties are random, and the first option wins if nobody voted. See [Controllers and Progress](/docs/hollowengine/dialogues/controllers) for timeout configuration.

## Labels, jumps, and calls

```story
# Start
Guard: Choose a topic.
@call #Rumours
@jump #End

# Rumours
Guard: They say the old mine is open again.
@return
```

Label names are single words. `@jump` replaces the current call stack. `@call` remembers the next line, while `@return` returns to it. Returning from the outermost story finishes the dialogue.

Targets may point to another story. The label is optional for a cross-file target:

```story
@call project:stories/common.story#Greeting
@jump project:stories/chapter_2.story#Start
```

## Asynchronous tracks

`@async` starts work in parallel and lets the main story continue immediately:

```story
@async name=patience
    @wait 20s
    @sync
    Guard: Time is up. Leave.
    @jump #End

Guard: Make it quick.

@choice "Apologise" id=apologise
    @cancel patience
@choice "Keep talking" id=talk
    @await patience
```

Dialogue lines and choices are not allowed inside an async block before `@sync`. When a track reaches `@sync`, it interrupts the current line or menu and the remainder of that block becomes the main flow.

- `@async name=track` starts a named block. Starting the same name again replaces its previous task.
- `@async name=bell play-sound minecraft:block.note_block.bell` is the inline form.
- `@await trackA trackB` waits for named tracks. `@await` with no names waits for every active track.
- `@cancel track` cancels a named track.

Give long-running tracks names so they can be awaited, cancelled, and restored from a checkpoint.
