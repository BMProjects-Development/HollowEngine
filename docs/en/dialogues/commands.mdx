<center><h1>Built-in Commands</h1></center>

*Functions available to every story without additional registration.*

![Dialogue commands](/hollowengine/titles/dialogues/commands.webp)

Arguments may be positional or named. Durations accept bare milliseconds and the `ms`, `s`, `sec`, `min`, and `h` suffixes.

## General and visual commands

| Command | Arguments | Behaviour |
| --- | --- | --- |
| `@wait` | `time` | Pauses the story. The remaining wait survives checkpoint restore. |
| `@play-sound` | `name [volume] [pitch]` | Plays a sound for every participant. |
| `@fade-in` | `[time=500ms] [color="#000000"]` | Fades the screen to a colour. |
| `@fade-out` | `[time=500ms] [color="#000000"]` | Clears the current fade. |
| `@hide-hud` | `[only=...] [except=...]` | Hides all HUD layers, selected layers, or everything except selected layers. |
| `@show-hud` | none | Restores the HUD state from before the dialogue. |
| `@camera` | `location rotation [time=1s] [fov=70]` | Moves the camera. Rotation is `[yaw, pitch]` or `[yaw, pitch, roll]`. |
| `@release-camera` | `[time=1s]` | Returns to the player camera. |
| `@cutscene` | `name [time]` | Starts a saved cutscene. With `time`, the story waits that long. |

```story
@hide-hud except=chat
@fade-in 750ms color="#120A1F"
@camera [10, 70, 5] [90, 15] time=2s fov=60
@fade-out 750ms
@show-hud
```

`@hide-hud` accepts lists and comma-separated strings. Camera and fade commands wait for their transition to finish.

## NPC commands

| Command | Arguments | Behaviour |
| --- | --- | --- |
| `@walk-to` | `who position-or-character [speed=...] [distance=...] [timeout=15s]` | Moves an NPC and waits for arrival. `timeout=0` waits without a limit. |
| `@stop-walking` | `who` | Stops NPC navigation. |
| `@look-at` | `who position [time=1500ms]` or `who character` | Looks at a position for a duration, or follows a character. |
| `@stop-looking` | `who` | Clears the NPC look target. |
| `@play-once` | `who animation [fade=330ms]` | Plays an animation once and waits for it to finish. |
| `@play-looped` | `who animation [fade=330ms]` | Starts a looped animation. |
| `@play-clamped` | `who animation [fade=330ms]` | Plays and holds the final pose. |
| `@play-ping-pong` | `who animation [fade=330ms]` | Starts a forward and reverse loop. |
| `@stop-animation` | `who animation [fade=330ms]` | Stops one animation. |

```story
@walk-to Guard [100, 64, 120] speed=1.2 distance=2 timeout=10s
@look-at Guard player
@play-once Guard hello fade=250ms
```

Movement and animation require an entity-backed character. Movement and look commands specifically require a HollowEngine NPC.

Visual state borrowed by a story is restored when the dialogue ends or a participant dies.
