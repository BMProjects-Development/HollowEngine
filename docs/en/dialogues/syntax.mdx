<center><h1>Story Syntax</h1></center>

*The building blocks of `.story` files.*

![Story syntax](/hollowengine/titles/dialogues/syntax.webp)

## File structure

Every non-empty line is a label, a command, a character line, or narrator text. Indentation opens blocks for conditions, loops, choices, and asynchronous tracks.

```story
# Start
// A whole-line comment
@if hasPass
    Guard: Everything is in order. // An end-of-line comment
```

`//` begins a comment at the start of the content or after whitespace. Empty lines and comments do not affect execution. Spaces and tabs are accepted for indentation, but a file should use one style consistently.

## Dialogue text

The speaker name before `:` must be one word made from letters, digits, `_`, or `-`. Bind a short script name when the displayed character name contains spaces.

```story
The road disappears into the fog.
Guard: Welcome back, {player.name}.
Guard: Your balance is {money} coins.[-] Do you still want to enter?
Guard: Wait here.[wait 750ms] Now we can continue.
```

- `{expression}` inserts an evaluated value.
- `[-]` pauses in the middle of a line until the participants continue.
- `[command arguments]` runs an inline function. `[@wait 750ms]` is also valid.
- `\n` and `\t` insert a newline or tab. A backslash escapes the next special character, for example `\{`, `\[`, `\"`, or `\\`.

Inline calls are available only in dialogue text. Choice captions can use interpolation, but do not execute inline commands.

### Formatting

Dialogue lines and choice captions support nested markup. Tags do not count as typewriter characters:

```story
Vitalik: I am <b>bold</b> now. Fear me!
Vitalik: <color=gold>Gold and <i>gold italic</i>.</color>
Vitalik: <wave amplitude=2 speed=3>This sentence moves in a wave.</wave>
@choice "<b>Answer confidently</b>" id=confident
```

| Tag | Result |
| --- | --- |
| `<b>`, `<strong>` | Bold text |
| `<i>`, `<em>` | Italic text |
| `<u>` | Underline |
| `<s>`, `<strike>` | Strikethrough |
| `<color=red>`, `<color=#55FFFF>` | A named color or `#RGB[A]` / `#RRGGBB[AA]` |
| `<gradient from=#FF5555 to=#5555FF speed=0.25>` | A gradient between two colors |
| `<rainbow>`, `<pulse>`, `<wave>`, `<shake>`, `<wiggle>`, `<swing>`, `<glitch>` | Animated Hollow UI effects |
| `<br>` | A line break |

Animation parameters may be overridden, for example with `<wave amplitude=4 frequency=1.5 speed=2>` or `<glitch frequency=3 intensity=2 chromatic=false>`. Every parameter is optional. An unknown or invalid tag is shown literally, so a typo never deletes author text. An unclosed known tag applies to the end of the current line; this lets formatting surround interpolations and inline pauses.

Use `&lt;`, `&gt;`, `&amp;`, `&quot;`, and `&apos;` for literal reserved characters. For example, `&lt;b&gt;text&lt;/b&gt;` displays `<b>text</b>` without making it bold.

The built-in dialogue window already uses `FormattedText(...)`. In a custom `.ui.kts` layout, call `FormattedText(line.text, visibleCharacters = line.visibleLength)`, or `FormattedTextSpans(...)` when the line must share an inline flow with a prefix. Chat preserves bold, italic, rules, and colors; motion effects gracefully render as ordinary text there.

## Variables and expressions

```story
@set visits = visits + 1
@set admitted = true
@set greeting = "Welcome back"
```

Variables hold strings, numbers, or booleans and become part of the checkpoint. Lists are temporary expression and argument values, so they cannot be stored with `@set`.

| Syntax | Meaning |
| --- | --- |
| `true`, `false` | Boolean values |
| `12`, `-2.5` | Numbers |
| `500ms`, `2s`, `2sec`, `1.5min`, `1h` | Durations converted to milliseconds |
| `"text"`, `[10, 64, -5]` | String and list literals |
| `!ready`, `-price` | Boolean negation and numeric negation |
| `*`, `/`, `%`, `+`, `-` | Arithmetic with normal precedence |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | Comparison |
| `&&`, `||` | Short-circuit boolean operations |
| `(expression)` | Explicit grouping |
| `items[0]`, `items.size`, `text.size` | Indexing and sizes |
| `Guard.name`, `Guard.uuid` | Bound character name and entity UUID |

In conditions, `false`, `0`, and an empty string are false. Other values are true. `+` adds numbers, concatenates when either side is a string, and appends values to lists.

:::warning
Reading an unknown variable or property stops the dialogue with an error. Supply initial values in the controller's `start` block before the story reads them.
:::

## Function arguments

Positional arguments must come before named arguments:

```story
@play-sound minecraft:entity.villager.yes 1.0 pitch=0.8
@camera [10, 70, 5] [90, 15] time=2s fov=60
@look-at Guard {player}
```

Bare words are strings. Quote strings containing spaces. Numbers, booleans, durations, and lists keep their types. Wrap an expression in `{...}` when an ordinary argument should be evaluated instead of treated as text.

For a named condition, use a compact expression or quote one containing spaces:

```story
@choice "Buy" if=money>=20
@choice "Buy with discount" if="money >= price && reputation > 5"
```

`tag=` is reserved by every function call. It identifies an action for event handlers without becoming part of the function signature.

## Minecraft commands

`@command` runs a Minecraft command with permission level 4 and supports interpolation:

```story
@command title @a actionbar Balance: {money}
```
