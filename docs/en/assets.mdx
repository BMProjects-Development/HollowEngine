<center><h1>Assets</h1></center>

*Where to place models, textures, UI files, sounds, scripts, and other project resources.*

![Assets](/docs/title-assets.webp)

HollowEngine loads user content from the `hollowengine/` directory in the game folder. Files that are referenced by resource location use the normal Minecraft layout under `assets/<namespace>/`.

Use a stable namespace for your project, for example `project`. Then `project:textures/ui/panel.png` points to:

```text
hollowengine/
└─ assets/
   └─ project/
      └─ textures/
         └─ ui/
            └─ panel.png
```

## Common folders

| Folder | Used for | Example reference |
|--------|----------|-------------------|
| `assets/project/textures/` | UI textures, entity textures, icons | `project:textures/ui/icon.png` |
| `assets/project/models/` | glTF, Blockbench, and entity models | `project:models/entity/guide.gltf` |
| `assets/project/ui/` | HSS styles and other UI resources | `project:ui/dialogs/confirm.hss` |
| `assets/project/sounds/` | Custom sound files | `project:sounds/voice/hello.ogg` |
| `scripts/` | Kotlin scripts and `.story` dialogue files | `quest/intro.node.kts` |

Keep assets near the feature that owns them. UI declarations are Kotlin scripts under `hollowengine/scripts`; their HSS and textures use resource locations under `hollowengine/assets`:

```text
hollowengine/
├─ assets/project/
│  ├─ ui/dialogs/quest.hss
│  └─ textures/ui/quest_portrait.png
└─ scripts/ui/quest.ui.kts
```

## Referencing assets

Use full resource locations in Kotlin UI declarations, HSS, and scripts:

```kotlin
Column(modifier = Modifier.style("project:ui/dialogs/quest.hss")) {
    Image("project:textures/ui/quest_portrait.png")
}
```

```css
.panel {
    background: image("project:textures/ui/panel.png");
}
```

```kotlin
val guide = npc(
    pos = pos(10.0, 64.0, 10.0),
    model = "project:models/entity/guide.gltf",
)
```

Kotlin script imports are resolved within the script namespace rather than as resource locations. See [Script Imports](/docs/hollowengine/scripting/imports).

## Practical rules

- Put reusable UI styles under `assets/project/ui/components/` and reusable Kotlin UI code under `scripts/ui/`.
- Put UI textures under `assets/project/textures/ui/` unless they belong to one isolated UI folder.
- Prefer resource locations over hardcoded file paths.
- Keep model textures in the same namespace as the model.
- A model can carry a `<model>.hemeta` beside it, see [Models and Materials](/docs/hollowengine/scripting/models).
- Use lowercase paths with `a-z`, `0-9`, `_`, `-`, `.`, and `/`.

If an asset is used from a `.ui.kts` or `.hss` file, document it beside that UI feature so future changes do not require searching through scripts.
