<center><h1>Commands</h1></center>

*If you typed the command symbol `/` in the chat, you might have noticed a brand-new command 👀*

![HollowEngine commands in chat](/hollowengine/pictures/commands/chat.webp)

The mod adds quite a few useful commands, which can be accessed via two main commands:

| Command         | Description        |
|-----------------|--------------------|
| `/hollowengine` | Full command name  |
| `/he`           | Short alias        |

Commands under `scripting` and `addons` that change something need operator permission (level 2).

---

# Scripting

| Command                                    | Description                                                                                     |
|--------------------------------------------|-------------------------------------------------------------------------------------------------|
| `/he scripting run <path>`                 | Run a plain script, start a node script on the server, or swap the bodies of a mixin script     |
| `/he scripting run <path> <state>`         | Start a node script in the given state                                                          |
| `/he scripting stop <path>`                | Stop a running server node script                                                               |
| `/he scripting attach <entity> <path>`     | Attach a node script (with `@file:Attach`) to an entity                                         |
| `/he scripting attach <entity> <path> <state>` | The same, starting in the given state                                                       |
| `/he scripting detach <entity> <path>`     | Detach a node script from an entity                                                             |
| `/he scripting list`                       | List running server nodes                                                                       |
| `/he scripting list entity <entity>`       | List the nodes attached to an entity                                                            |
| `/he scripting compile`                    | Compile every script and fill the cache, so a pack runs without the compiler addon              |

A script from an addon is written with its namespace: `/he scripting run my-addon:nodes/quest.node.kts`. See [Scripting](/docs/hollowengine/scripting) and [Scripts and resources in addons](/docs/hollowengine/addons/scripts).

# Addons

| Command                          | Description                                      |
|----------------------------------|--------------------------------------------------|
| `/he addons list`                | Show every addon with its version and state      |
| `/he addons enable <id>`         | Enable an addon                                  |
| `/he addons disable <id>`        | Disable an addon                                 |
| `/he addons reload <id>`         | Reload an addon                                  |

Bundled addons add their own commands: `/he mcp` ([MCP server](/docs/hollowengine/addons/mcp)) and `/he video` ([Video](/docs/hollowengine/addons/media)). See [Addons](/docs/hollowengine/addons).

# VFX

Play a `.vfx` effect at a position or on an entity:

```mcfunction
/he vfx ~ ~1 ~ project:sparks
/he vfx @s project:sparks
```

`project:sparks` refers to `hollowengine/assets/project/vfx/sparks.vfx`. See [Visual effects (VFX)](/docs/hollowengine/vfx) for creating the file and using the editor, and [Playing effects](/docs/hollowengine/vfx/playback) for stopping them from a script.

# Particles

Bedrock particle files (`.bedrock.json`) are played with their own commands.

| Command                        | Description                            |
|--------------------------------|----------------------------------------|
| `/he particle <pos> <name>`    | Create particle effect at the pos      |
| `/he particle <entity> <name>` | Bound particle effect to the entity    |
| `/he remove-particles <name>`  | Remove all particles with written type |

## Arguments

| Argument | Type     | Description        |
|----------|----------|--------------------|
| `pos`    | `vec3`   | Position           |
| `entity` | `entity` | Target entity      |
| `name`   | `string` | ID particle effect |

## Examples

```mcfunction
/he particle ~ ~1 ~ hollowengine:example
/he particle @s hollowengine:trail
/he remove-particles hollowengine:trail
```

# Models

## Information

| Command                    | Description                            |
|----------------------------|----------------------------------------|
| `/he model <model>`        | Display model info: clips, materials   |
| `/he model info <model>`   | The same                               |
| `/he model entity <entity>`| Display the model an entity shows      |

Use these to find the real animation names of a model before playing or scripting them.

## Attaching models

| Command                             | Description                  |
|-------------------------------------|------------------------------|
| `/he model attach <entity> <model>` | Attach a model to the entity |

## Disabling the vanilla model

| Command                                    | Description             |
|--------------------------------------------|-------------------------|
| `/he model hide-vanilla <entity> <hidden>` | Hide/show vanilla model |

## Installing the preset

| Command                                          | Description                                     |
|--------------------------------------------------|-------------------------------------------------|
| `/he model player-preset <entity>`               | Apply default preset                            |
| `/he model player-preset <entity> <hideVanilla>` | Same thing, but with the "hide vanilla" setting |

# Animations

## Play

| Command                                                                   | Description              |
|---------------------------------------------------------------------------|--------------------------|
| `/he model animation play <entity> <animation>`                           | Play animation           |
| `/he model animation play <entity> <animation> <mode>`                    | Play animation with mode |
| `/he model animation play <entity> <animation> <mode> <fadeIn> <fadeOut>` | Full command             |

### Arguments

| Argument  | Type     | Range                                       |
|-----------|----------|---------------------------------------------|
| `mode`    | `string` | `once`, `loop`, `clampforever`, `pingpong`  |
| `fadeIn`  | `float`  | `0..10`                                     |
| `fadeOut` | `float`  | `0..10`                                     |

Without a mode the animation plays `once`.

## Stop

| Command                                                | Description              |
|--------------------------------------------------------|--------------------------|
| `/he model animation stop <entity> <animation>`        | Stop animation           |
| `/he model animation stop <entity> <animation> <fade>` | Stop animation with fade |
