<center><h1>Blocks</h1></center>

React to block placement, breaking, or updates. Cancellable events let you prevent an action, for example to protect a building.

These are separate handler examples for `.reload.kts`. Add the imports you need at the start of your file. For client events, put `@file:ClientSide` before imports; keep server and client handlers in separate files.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.blocks.BlockEvent
```

## Placement

**Side:** both sides

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockPlace(event: BlockEvent.Placed) {
    val block = event.state
}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (`BlockPos`) - block coordinates.
- `event.player` (Player) - the player who placed the block.

## Breaking

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockBreak(event: BlockEvent.Break) {
    val block = event.state
}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (`BlockPos`) - block coordinates.
- `event.player` (Player) - the player who broke the block.
- `event.level` (Level) - the world where the block was broken.

## Updates

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockUpdate(event: BlockEvent.NeighborNotify) {
    val block = event.state
}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (`BlockPos`) - block coordinates.
- `event.directions` (`EnumSet<Direction>`) - the sides that were updated.
