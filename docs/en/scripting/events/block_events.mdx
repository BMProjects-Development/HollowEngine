<center><h1>Blocks</h1></center>

*Actions related to blocks.*

![NPC](/docs/title-missing.webp)

## Placement

**Side:** both sides

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockPlace(event: BlockEvent.Placed) {
    val block = event.state
}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (String) - block coordinates.
- `event.player` (Player) - the player who placed the block.

## Breaking

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockBreak(event: BlockEvent.Break) {
    val block = event.state
}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (String) - block coordinates.
- `event.player` (Player) - the player who broke the block.
- `event.level` (Level) - the world where the block was broken.

## Updates

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockUpdate(event: BlockEvent.NeighborNotify) {

}
```

- `event.state` (BlockState) - the current block state.
- `event.pos` (String) - block coordinates.
- `event.directions` (EnumSet<Direction>) - the sides that were updated.
