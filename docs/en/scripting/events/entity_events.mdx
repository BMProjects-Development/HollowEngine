<center><h1>Entities</h1></center>

Track an entity loading, dying, or moving to another dimension. Events provide the entity so you can check its type and change the relevant settings.

These are separate handler examples for `.reload.kts`. Add the imports you need at the start of your file. For client events, put `@file:ClientSide` before imports; keep server and client handlers in separate files.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.entity.BabySpawnEvent
import ru.hollowhorizon.hollowengine.common.events.entity.EntityEvent
import ru.hollowhorizon.hollowengine.common.events.entity.EntityLoadedEvent
import ru.hollowhorizon.hollowengine.common.events.entity.LivingEntityDeathEvent
```

## Spawned in the world

**Side:** server

```kotlin
@SubscribeEvent
fun onEntitySpawn(event: EntityLoadedEvent) {
    val entity = event.entity
}
```

- `event.entity` (Entity) - the entity that was spawned.
- `event.uuid` (UUID) - the entity's unique identifier.

## Entity death

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onEntitySpawn(event: LivingEntityDeathEvent) {
    val entity = event.entity
}
```

- `event.entity` (Entity) - the current entity.
- `event.source` (DamageSource) - the source and type of the damage dealt.

## Moving between dimensions

**Side:** server

```kotlin
@SubscribeEvent
fun onEntityTeleport(event: EntityEvent.ChangeDimension) {
    val entity = event.entity
}
```

- `event.entity` (Entity) - the entity before the move.
- `event.new` (Entity) - the entity after the move.
- `event.from` (Level) - the world the entity is moving from.
- `event.to` (Level) - the world the entity is moving to.

:::advice
Typed [`.data`](/docs/hollowengine/scripting/npc/data) carries over on its own, on `event.new`, no handling needed here.
:::

## Taking damage

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onEntityHurt(event: EntityEvent.Hurt) {
    val entity = event.entity
}
```

- `event.entity` (Entity) - the entity that took damage.
- `event.source` (DamageSource) - the source and type of the damage dealt.
- `event.amount` (Float) - the amount of damage dealt. (can be changed)

## Entity breeding

**Side:** server

*This event can be canceled (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBabySpawn(event: BabySpawnEvent) {
    val child = event.child
}
```

- `event.parentA` (Mob) - one of the parents.
- `event.parentB` (Mob?) - one of the parents.
- `event.child` (AgeableMob?) - the child. (can be changed)
- `event.causedByPlayer` (Player) - the player who caused the breeding.
