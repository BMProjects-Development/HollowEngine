<center><h1>Worlds</h1></center>

Run an action when a dimension is saved or unloaded. For example, save your system’s data before the world stops.

These are separate handler examples for `.reload.kts`. Add the imports you need at the start of your file. For client events, put `@file:ClientSide` before imports; keep server and client handlers in separate files.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.level.LevelEvent
```

## Saving

**Side:** server

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Save) {
    val level = event.level
}
```

- `event.level` (Level) - the dimension being saved.

## Loading

**Side:** server

```kotlin
@SubscribeEvent
fun onLoad(event: LevelEvent.Load) {
    val level = event.level
}
```

- `event.level` (Level) - the dimension being loaded.
