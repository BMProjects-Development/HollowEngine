*Actions related to the server.*

## Lifecycle

If you need to run logic when the server starts or stops, use the following events:

### On start

**Side:** server

```kotlin
@SubscribeEvent
fun onServerStart(event: ServerEvent.Starting) {
    val server = event.server
}
```

:::advice
A server `.reload.kts` runs before the server itself, so when a world opens this event reaches it. After `/reload`, however, the server is already running and the event does not fire again.
:::

### On stop

**Side:** server

```kotlin
@SubscribeEvent
fun onServerStop(event: ServerEvent.Stoping) {
    val server = event.server
}
```

## Ticks

### Server tick

**Side:** server

If you need to run logic every server tick (20 ticks per second), use the `TickEvent.Server` event:

```kotlin
@SubscribeEvent
fun onServerTick(event: TickEvent.Server) {
    val server = event.server
}
```

:::advice
If you need to run logic every `X` ticks, you can create a simple counter:

```kotlin
var ticker = 0

@SubscribeEvent
fun onServerTick(event: TickEvent.Server) {
    if (ticker++ % 5 == 0) { // Every 5 ticks
        event.server.doSomething()
    }
}
```
:::

### Client tick

**Side:** client

The same for the game client: fires 20 times per second, even in the main menu.

```kotlin
@file:ClientSide

@SubscribeEvent
fun onClientTick(event: TickEvent.Client) {
    val minecraft = event.minecraft
}
```

### Entity tick

**Side:** both sides

Fires every tick for every living entity.

```kotlin
@SubscribeEvent
fun onEntityTick(event: TickEvent.Entity) {
    val entity = event.entity
}
```

- `event.entity` (LivingEntity) - the entity being updated.
