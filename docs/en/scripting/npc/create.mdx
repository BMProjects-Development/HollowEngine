<center><h1>Creating NPCs</h1></center>

Create an NPC, then choose its name, model, dimension, and other settings.

---

The examples use a server `.node.kts`: `npc`, `pos`, `rotation`, and `@State` are already imported. For the complete `main` example, create `hollowengine/scripts/examples/create_npc.node.kts` and run `/he scripting run scripts/examples/create_npc.node.kts main`. Choose coordinates with solid ground in a loaded chunk.

## `npc()`

The `npc()` function creates an `NpcEntity` in the selected world and assigns its model. If you pass the `id` of an existing living NPC, it returns that NPC and keeps its current settings.

```kotlin
val guide = npc(
    pos = pos(10, 64, 10),
    name = "Guide",
)
```

## Signature

```kotlin
fun npc(
    pos: Vec3,
    name: String = "NPC",
    model: String = "hollowengine:models/entity/player_model.gltf",
    rotation: Vec2 = rotation(0, 0),
    world: String = "minecraft:overworld",
    attributes: Map<String, Float> = emptyMap(),
    transform: TrsTransformF = TrsTransformF(),
    nameplateMode: NameplateMode = NameplateMode.SHOW,
    inverseHeadRotation: Boolean = false,
    inventorySize: Int = NpcInventory.DEFAULT_SIZE,
    id: String? = null,
): NpcEntity
```

| Parameter | Type | Default | Purpose |
|-----------|------|---------|---------|
| `pos` | `Vec3` | - | Spawn position. |
| `name` | `String` | `"NPC"` | Name shown above the NPC. |
| `model` | `String` | `"hollowengine:models/entity/player_model.gltf"` | Resource location of the `.gltf` model. |
| `rotation` | `Vec2` | `rotation(0, 0)` | Initial yaw/pitch. |
| `world` | `String` | `"minecraft:overworld"` | Dimension id where the NPC is added. |
| `attributes` | `Map<String, Float>` | `emptyMap()` | Base attribute values by registry id. |
| `transform` | `TrsTransformF` | `TrsTransformF()` | Model translation, rotation, and scale relative to the NPC; passed to `TransformComponent`. |
| `nameplateMode` | `NameplateMode` | `NameplateMode.SHOW` | Initial nameplate visibility mode. |
| `inverseHeadRotation` | `Boolean` | `false` | Not applied by the current implementation. Configure head rotation in model metadata. |
| `inventorySize` | `Int` | `36` | Number of slots in [`npc.inventory`](/docs/hollowengine/scripting/npc/inventory). Can also be changed later with `npc.inventory.resize(...)`. |
| `id` | `String?` | `null` | The NPC's own id, such as `"village:blacksmith"`. When a living NPC already has it, `npc()` returns that NPC and ignores the other arguments, see [NPCs Outside the World](/docs/hollowengine/scripting/npc/registry#ids-one-npc-per-name). |

:::warning
The `inverseHeadRotation` parameter is not applied yet. `transform` is passed to `TransformComponent`. The selected model’s metadata defines its animator and head rotation, so configure a custom model separately. The [Body](/docs/hollowengine/world/colliders#the-body-of-an-entity) component controls how the NPC pushes and blocks others.
:::

## `pos()` and `rotation()` helpers

```kotlin
val blockCenter = pos(10, 64, 10)      // Vec3(10.5, 64.0, 10.5)
val exactPos = pos(10.0, 64.0, 10.0)  // Vec3(10.0, 64.0, 10.0)

val rot = rotation(90, 0)
```

`pos(Int, Int, Int)` adds `0.5` to X/Z so the NPC spawns in the center of the block.
`pos(Double, Double, Double)` uses exact coordinates.

## Examples

### Minimal NPC

```kotlin
@State
suspend fun main() {
    val npc = npc(pos(0, 64, 0))
    npc.say("Hello!")
}
```

### Custom model and world

Prepare `hollowengine/assets/project/models/entity/trader.gltf` and its textures for this example. The identifier `project:models/entity/trader.gltf` refers to that file. Choose an existing dimension; this example uses the Overworld. If you do not have a custom resource yet, keep the default built-in model.

```kotlin
@State
suspend fun main() {
    val trader = npc(
        pos = pos(120.0, 70.0, -32.0),
        name = "Trader",
        model = "project:models/entity/trader.gltf",
        rotation = rotation(180, 0),
        world = "minecraft:overworld",
    )
}
```

### Attributes

```kotlin
val guard = npc(
    pos = pos(0, 64, 0),
    name = "Guard",
    attributes = mapOf(
        "minecraft:generic.max_health" to 40f,
        "minecraft:generic.movement_speed" to 0.25f,
        "minecraft:generic.attack_damage" to 6f,
    ),
)
```

Attribute names must match the attribute registry ids in the current Minecraft/NeoForge version.

Any registered attribute can be added to an individual NPC, including attributes absent from its entity type's defaults. Added attributes and their permanent modifiers are saved with the NPC. The entity editor's attribute picker searches by name or registry ID; added attributes can be removed, while required attributes can be reset to their type's defaults.

## What is assigned automatically

After creation, the NPC receives:

- `Model(model)` - the model component;
- the selected model’s animator from its `.hemeta`; the built-in model uses `hollowengine:standard_player` for idle and walking;
- `TransformComponent(...)` - base model transform;
- a nameplate initialized from `name` and `nameplateMode`;
- a record in the [NPC registry](/docs/hollowengine/scripting/npc/registry), and its body in the selected world.

This means a regular NPC can already stand, walk, and rotate its head without manual animator setup.
