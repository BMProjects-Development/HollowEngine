<center><h1>Utility Methods</h1></center>

*Small helper functions for `NpcEntity` that don't belong to a bigger topic.*

---

For movement, looking, using blocks, and interacting with entities, see [Movement and Interaction](/docs/hollowengine/scripting/npc/movement).
For giving, taking, and gathering items, see [Inventory and Item Collection](/docs/hollowengine/scripting/npc/inventory).
For finding nearby players, NPCs, and items, see [Finding Entities and Items](/docs/hollowengine/scripting/npc/search).

## `npc.dropItem(item)`

Drops an item from the NPC's position.

```kotlin
npc.dropItem(item("minecraft:diamond", 1))
```

## `npc.say(text)`

Sends a message to every player on the server in the format `[NPC Name]: text`.

```kotlin
npc.say("Hello there!")
```

## `npc.despawn()`

Removes the NPC from the world with `Entity.RemovalReason.DISCARDED`.

```kotlin
npc.despawn()
```

Because `NpcEntity` inherits from Minecraft entities, standard methods such as `remove(...)`, `discard()`, `teleportTo(...)`, `setItemInHand(...)`, and other Minecraft API methods are also available.

## Hitbox

NPCs have a convenient `hitboxMode` property:

```kotlin
npc.hitboxMode = HitboxMode.PULLING   // normal collision and pushing
npc.hitboxMode = HitboxMode.EMPTY     // passable entity
npc.hitboxMode = HitboxMode.BLOCKING  // can be walked on top of, like a block
```

Import the enum:

```kotlin
import ru.hollowhorizon.hollowengine.common.npcs.HitboxMode
```

## Seating and standing up

```kotlin
npc.seat()
npc.standup()
```

`seat()` creates/uses a helper seat entity, while `standup()` stops riding.

## Attack target

`NpcEntity` has the standard `Mob` target.
To clear it, use:

```kotlin
npc.clearTarget()
```

To assign a target, use the standard Minecraft API property/method:

```kotlin
npc.target = player
```

## Attributes

You can apply attributes by registry id:

```kotlin
npc.setAttributes(
    mapOf(
        "minecraft:generic.max_health" to 40f,
        "minecraft:generic.movement_speed" to 0.25f,
    )
)
```

Names depend on the current Minecraft/NeoForge version and must exist in the attribute registry. The vanilla `/attribute` command is a quick way to look up valid ids in-game.

## Utilities

### `wait(time)`

Suspends the current coroutine for the given number of ticks.

```kotlin
wait(20)      // 1 second
wait(5.sec)  // 5 seconds
```

For waits that must keep counting down even across a server restart, see the "Waiting that survives a restart" section in [States and Coroutines](/docs/hollowengine/scripting/node/states#waiting-that-survives-a-restart).

### `Int.sec` / `Double.sec`

Converts seconds to ticks:

```kotlin
wait(2.sec)
wait(0.5.sec)
```

### `item(id, count)`

Creates an `ItemStack`:

```kotlin
val diamond = item("minecraft:diamond", count = 3)
val stick = item("minecraft:stick")
```

:::warning
The old `item(id, count, nbt: String)` overload that took a raw NBT string is gone (calling it is now a compile error). Item data is described through Minecraft's data components instead. To customize an item after creating it, use `ItemStack.set(...)`:

```kotlin
import net.minecraft.core.component.DataComponents

val namedStick = item("minecraft:stick")
namedStick.set(DataComponents.CUSTOM_NAME, "Magic Stick".literal)
```

This works for any data component, not just names, enchantments, lore, food, and so on all use the same `set(DataComponents.X, value)` pattern.
:::

### `uuid(value)`

```kotlin
val id = uuid("00000000-0000-0000-0000-000000000000")
```

## What is no longer documented as the main API

Old Katari/block-doc methods such as `npc.playAnimation(...)`, `npc.stopAnimation(...)`, `npc.setSkin(...)`, and separate `attack(...)` wrappers should not be treated as the main v2.3 API.

- For animations, use [`play`](/docs/hollowengine/scripting/animations) or the action-based [`startAnimation`](/docs/hollowengine/scripting/npc/actions).
- For held items, use the standard Minecraft API: `setItemInHand(...)`, or [`equip`](/docs/hollowengine/scripting/npc/inventory).
- For appearance, use [`entity.materials`](/docs/hollowengine/scripting/models).
