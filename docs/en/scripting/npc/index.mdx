<center><h1>NPCs in Kotlin Scripts</h1></center>

Create characters for your map: NPCs can talk, walk to a destination, use items, and take part in story scenes.

Start with a `.node.kts` file under `hollowengine/scripts`. It already provides `npc()`, `pos()`, `move()`, and other NPC helpers. You can also call `MinecraftServer` methods directly from the script.

An NPC is a regular Minecraft entity of type `NpcEntity`, so you can work with it through HollowEngine helpers (`npc()`, `move`, `lookAt`, `say`) and through the standard `Entity` / `LivingEntity` / `PathfinderMob` API.

## Quick example

```kotlin
@State
suspend fun main() {
    val guide = npc(
        pos = pos(0, 64, 0),
        name = "Guide",
        model = "hollowengine:models/entity/player_model.gltf",
    )

    val player = playerList.players.firstOrNull() ?: return

    guide.lookAt(player)
    guide.say("Welcome!")
    guide.move(player, dist = 2.0, speed = 1.0)
}
```

This example does one thing at a time, which is perfectly fine for simple scenes. An NPC can also walk, look around, and use its hands **at the same time**, gather items on its own, carry an inventory, and remember its own data, see [Actions and Concurrency](/docs/hollowengine/scripting/npc/actions) for the mental model behind that.

:::advice
`move(...)`, `lookAt(...)`, `useBlock(...)`, and `destroyBlock(...)` are `suspend` functions. Call them from `@State suspend fun`, `async { ... }`, or another coroutine.
:::

## Lifecycle

NPCs are usually created inside a node state:

```kotlin
@State
suspend fun main() {
    val npc = npc(pos(10, 64, 10), name = "Guard")
    npc.say("Stay close.")
}
```

An NPC outlives the chunk it stands in: it stays in the [NPC registry](/docs/hollowengine/scripting/npc/registry) until it dies or is despawned. To find it again after a world or script reload, give it an `id` in `npc(...)`, or store its UUID through `stateTag()` and look it up with `npcs[uuid]`.

## Attaching persistent behavior

For behavior that should live with the NPC itself instead of a story state, attach a [node script](/docs/hollowengine/scripting/node) directly to the entity with `@file:Attach`:

```kotlin
@file:Attach(NpcEntity::class)

onInteract { event ->
    event.player.send("Welcome, traveler!")
}

onHurt {
    println("The NPC flinches")
}
```

Attach it with `/he scripting attach <entity> <path>`, or automatically on spawn from a reloadable script. The node survives a server restart together with the NPC.
