<center><h1>Animator Editor</h1></center>

*The visual editor for `.animator` files: the stack of layers, the state graph and the parameters of whatever is selected.*

---

## What it edits

An animator is how a model animates itself: a list of layers, on top of which a server script adds one-off clips of its own. A `.animator` file holds the whole stack, and the editor shows the whole stack.

To make a model use one, name the file in its [metadata](/docs/hollowengine/scripting/models):

```toml
animation-controller = "project:models/entity/guide.animator"
```

Keep the file next to your models or animations. The engine looks for `.animator` under the `models` and `animations` folders. Create it like any other file: right-click a folder in the project tree, `guide.animator`. An empty file is an empty animator, and the editor opens straight away.

![Controller](/hollowengine/pictures/animation_controller/controller.webp)

## Layers

The list of layers is on the left. The **Add** button at the end opens a menu where you can create a **Controller** (a state machine) or a **Clip** (a single animation).

- Clicking a layer opens it: a controller brings up its graph, a clip only its parameters.
- The cross on the right deletes the layer along with the layout of its graph.
- The panel border can be dragged, and the panel itself folded away with the button above the grid.

The order in the list means nothing - blending is governed by the **priority** in the layer's parameters: layers are applied from the lowest to the highest.

![Layer](/hollowengine/pictures/animation_controller/layer.webp)

## The state graph

Every node is a state: a name, a clip, a playback mode. The entry state is marked with an icon in its bottom-right corner.

| Action | How |
|--------|-----|
| Select | click a node, an arrow or its label |
| Move a node | drag it |
| Create a transition | `Ctrl` + drag from one node to another |
| Move around | drag empty space |
| Zoom | mouse wheel |
| Node menu | right-click a node |
| Graph menu | right-click empty space |
| Clear the selection | click empty space |

Right-clicking a node gives a list of actions: "Make entry state", "Turn into any-state" and "Delete". Right-clicking empty space gives "Add state", "Add any-state" and "Reset view".

The minimap in the bottom-right corner shows the whole graph: hovering an icon names the state, clicking takes you to it.

![Nodes and minimap](/hollowengine/pictures/animation_controller/nodes_and_minimap.webp)

### Any state

The "Any State" node is where transitions allowed from every state come from. A transition drawn out of it to some state fires no matter which animation was playing. Which is exactly why a transition **into** any-state is impossible, while one **out of** it is not.

![Any State](/hollowengine/pictures/animation_controller/any_state.webp)

## Parameters

The right-hand panel shows what is selected, and appears together with a selection.

**A layer** - name, priority, weight, fade in and out, blending (overwriting / `override` or additive / `additive`). A clip layer also has its animation, mode and speed.
![Layer Inspector](/hollowengine/pictures/animation_controller/layer_inspector.webp)
**A state** - name, animation, playback mode, speed. Below them is the list of its transitions: clicking a `from → to` row selects that transition in the graph. The same place holds the "Make entry state" and "Delete state" buttons.
![State Inspector](/hollowengine/pictures/animation_controller/state_inspector.webp)
**A transition** - condition, crossfade duration, priority and exit time.
![Transition Inspector](/hollowengine/pictures/animation_controller/transition_inspector.webp)

:::advice
Fade in and out belong to a layer, not to a state: a smooth change between animations is made by adjusting the duration of the transition.
:::

## Expressions

Weight, speed, duration and condition are [expressions](/docs/hollowengine/scripting/animations), not numbers. The fields come with highlighting, completion (including after a dot: `q.` offers the members of `q`) and diagnostics.

Besides `q.` (entity state), `v.`/`t.` (your own variables) and `math.` there is `d.` - the [synced entity data](/docs/hollowengine/scripting/npc/data#syncing-to-the-client), addressed by its path inside the NBT: `d.emotion.happy > 0.5`.

```text
horizontal_speed > 0.02
is_alive != 0.0 && is_sneaking != 0.0
movement_animation_speed / 1.43
```

## Shortcuts

| Key | Action |
|-----|--------|
| `Delete` | delete the selected state or transition |
| `Escape` | clear the selection |
| `F` | reset the view |
| `E` | make the selected state the entry state |
| `Insert` or `Ctrl + N` | a new state in the middle of the view |

---

## Saving

The file saves itself automatically about a second after the last edit. An animator built in code works exactly the same way, except that a resource pack can override it.

Reload resources (`F3 + T`) for the game to apply the changes.
