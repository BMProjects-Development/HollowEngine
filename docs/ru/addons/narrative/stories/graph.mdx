<center><h1>Нодовая система</h1></center>

## Узлы и связи

Файл `.story` хранит узлы и связи, которые можно редактировать в IDE. У графа один узел **Начало**. Движок компилирует граф в Kotlin и выполняет шаги по связям, начиная с этого узла.

- **Связи хода** задают, какой шаг выполняется дальше. У выбора или условия может быть несколько отдельных выходов.
- **Связи значений** передают данные на вход узла. Это может быть NPC, позиция или число. Блок значения, например сравнение, вычисляется каждый раз при чтении. Результат блока действия доступен после его выполнения.

Нажмите правой кнопкой мыши по холсту, чтобы создать блок по имени или категории. Потяните связь из порта в свободное место, чтобы увидеть подходящие блоки. Дважды нажмите по связи, чтобы добавить точку перенаправления. Такие точки и группы помогают расположить узлы и связи, сохраняя поведение истории.

## Текст диалога

У узла **Фраза** есть поля говорящего и текста. Для реплики рассказчика оставьте поле говорящего пустым. Можно указать имя или передать сущность через связь. Текст реплики также можно передать строкой через связь значения.

### Оформление

Используйте разметку `<b>Жирный текст</b>`, `<color=#ff8800>Оранжевый</color>`, `<wave>Движущийся текст</wave>` или `<br>` для переноса строк. Разметка также работает в тексте вариантов узла **Выбор**.

## Переменные и выражения

Откройте **Переменные** в инспекторе, чтобы добавить значение, которое сохранится с запуском истории. Задайте имя, тип Kotlin и начальное выражение. Например, создайте `trust` типа `Float` с начальным значением `0.0f`. Для записи используйте **Изменить переменную**, для чтения - связь значения или выражение вроде `trust > 10`.

В инспекторе ниже показана переменная `npc`. У неё тип `NpcEntity?`, поэтому начальное значение можно оставить пустым.

![Инспектор истории с переменной npc, её типом NpcEntity? и списком импортов](/hollowengine/pictures/narrative/story-variables.png)

В полях Kotlin указывайте выражения ожидаемого типа, например `true` для условия или `listOf(1, 2)` для списка. Добавьте импорт в разделе **Импорты**, если используете имя, недоступное по умолчанию. Тип с `?`, например `String?`, допускает пустое значение. Проверьте его наличие или задайте запасное значение перед передачей во вход, который требует заполненного значения.

Обобщённые блоки выводят типы по входам и связям. Например, для списка целых чисел узел **Для каждого** выдаёт элемент типа `Int`. Посмотрите тип в подсказке порта. Если редактору не хватает информации, укажите более конкретный вход, явный тип или блок приведения.

## Проверка графа

Откройте вкладку **Проблемы** в окне **Консоль**. Выберите сообщение об ошибке истории, чтобы перейти к нужному узлу. Проверьте обязательные входы, типы и порядок вычислений в ветках. Недостижимые шаги могут отмечаться предупреждением. Ошибки проверки графа останавливают компиляцию.
