## Условия и циклы

**Условие** выбирает ветку по булеву значению. В этом примере `trust` имеет тип `Float` и начинается с `0.0f`. Добавьте переменную в инспекторе в разделе **Переменные**. [Переменные и выражения](/docs/hollowengine/addons/narrative/stories/graph#variables-and-expressions)

![В инспекторе переменная trust имеет тип Float и начальное значение 0.0f](/hollowengine/pictures/narrative/trust-variable.png)

**Изменить переменную** сохраняет результат `trust + 1`. Затем **Условие** проверяет `trust > 10` и выбирает одну из двух реплик.

![Граф увеличивает trust на единицу и выбирает ветку по условию trust > 10](/hollowengine/pictures/narrative/trust-branch.png)

**Для каждого** повторяет последовательность для каждого элемента списка. Текущий элемент доступен внутри цикла. После последнего элемента история продолжится.

## Выбор

**Выбор** ведёт по разным веткам в зависимости от ответа. Поле **Показывать, если** позволяет скрыть вариант, когда условие ложно. Если сцену смотрят несколько игроков, они голосуют в общем опросе.

После объединения веток можно прочитать результат действия, только если оно выполнилось на каждом пути к этому месту. Если разные ветки получают нужное значение по-разному, запишите его в общую переменную.

## Функции

**Функция** позволяет переиспользовать последовательность шагов. У неё могут быть типизированные параметры, результаты и именованные выходы хода. **Вызов** выполняет функцию и получает её результаты. Блок **Запуск выхода** выполняет последовательность, которую передал вызывающий граф, после чего функция продолжается.

Функции можно вызывать внутри одной истории и из других файлов `.story`. Для вызовов между файлами редактор сам добавляет импорты и сообщает о циклических зависимостях.

Эта функция принимает игрока и строку. В блоке **Код** она использует оба параметра, чтобы показать уведомление через `sendToast`.

![Тело функции с параметрами player и text и вызовом sendToast в блоке «Код»](/hollowengine/pictures/narrative/function-body.png)

При вызове игрок берётся из блока **Контекст истории**, а сообщение задаётся в самом вызове.

![Вызов функции с игроком из контекста истории и сообщением в поле text](/hollowengine/pictures/narrative/function-call.png)

## Параллельные ветки истории

В нодовом редакторе **Параллельно** запускает задачу движения, пока основная ветка выполняет **Фразу**. После реплики **Отменить задачу** получает результат блока **Параллельно** и останавливает задачу движения.

![Параллельная ветка движения, реплика и отмена задачи в основной ветке](/hollowengine/pictures/narrative/parallel-movement.png)

Этапы Kotlin могут запускать именованные ветки, которые возобновляются после перезапуска. Запускайте их через `async("name") { ... }` и координируйте через `all`, `race` или `any`. [Асинхронные действия](/docs/hollowengine/addons/narrative/kotlin/async)
