<center><h1>Асинхронные действия</h1></center>

Запускайте несколько действий параллельно, пока история ждёт. Именованные ветки входят в [аддон Narrative](/docs/hollowengine/addons/narrative) и сохраняют прогресс вместе с основным запуском.

## Ветки истории и `async`

В [этапе Kotlin](/docs/hollowengine/addons/narrative/kotlin) задайте каждой ветке стабильное имя, как в примере ниже. Ветка это что-то вроде фонового действия, например, вы можете внутри такой ветке дать NPC задачу ходить по определённому маршруту, пока в основной части идёт диалог, а по его завершению - отменить ветку.

```kotlin
@State
suspend fun main() {
    val bell = async("bell") {
        wait(40, "before-bell")
        println("Звонок")
    }
    val gate = async("gate") {
        wait(100, "before-gate")
        println("Ворота открываются")
    }
    all(bell, gate)
}
```

`async` сразу возвращает объект для управления веткой. После восстановления тот же вызов находит уже созданную ветку. Когда запустивший её этап завершается, его активные ветки останавливаются. Вызовите `cancel()`, прежде чем использовать то же имя для новой ветки.

| Вызов             | Чего ждёт                                                                                         |
|-------------------|---------------------------------------------------------------------------------------------------|
| `handle.await()`  | Ждёт завершения и возвращает результат ветки или выбрасывает исключение при ошибке или остановке. |
| `handle.join()`   | Ждёт завершения ветки.                                                                            |
| `all(a, b)`       | Ждёт завершения всех переданных веток.                                                            |
| `race(a, b)`      | Возвращает первую завершившуюся ветку и отменяет остальные.                                       |
| `any(2, a, b, c)` | Возвращает две первые разные ветки, которые завершились, и отменяет остальные.                    |

Если сохранение ветки не нужно - используйте обычные корутины (`server.coroutineScope.launch { ... }`).
