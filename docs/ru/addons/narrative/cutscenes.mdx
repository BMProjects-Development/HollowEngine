<center><h1>Катсцены</h1></center>

Запишите движение камеры в редакторе и запустите сцену для выбранного игрока. На таймлайне можно также настроить поле зрения, время суток и погоду.

:::advice
Редактор катсцен входит в [аддон Narrative](/docs/hollowengine/addons/narrative).
:::

## Создание катсцены

1. Откройте **Окна > Сцена**, щёлкните правой кнопкой по строке **Мир** и выберите **Создать катсцену**. Например, для имени `intro` IDE создаст файл `hollowengine/cutscenes/intro.dat` с первым ключом камеры из текущего ракурса игрока.
2. Вкладка файла показывает камеру катсцены рядом с панелью **Окно игры**. В ней можно управлять игроком и одновременно следить за кадром катсцены. Существующие `.dat` открываются из дерева проекта.
3. Поставьте курсор на нужное время. В режиме **Орбита** удерживайте СКМ, чтобы повернуть камеру вокруг блока под курсором. `Shift` + СКМ сдвигает кадр, колесо плавно перемещает камеру вдоль указателя. В режиме **Полёт** щёлкните по предпросмотру. `WASD` перемещает камеру, `Пробел` или `E` поднимает её, `Shift` или `Q` опускает. Для обзора удерживайте ПКМ.

В одиночном мире и у операторов на сервере с HollowEngine предпросмотр подгружает чанки вокруг камеры. Область загрузки ограничена дальностью прорисовки на сервере и радиусом в восемь чанков.
4. Нажмите `I` в предпросмотре и выберите положение, поворот, поле зрения или все параметры. Кнопка захвата на таймлайне дополнительно записывает время суток и погоду. Перемещение курсора времени возвращает камеру к анимации.
5. Проверьте движение на таймлайне. Рамка и траектория камеры видны в **Окне игры**. Сохраните файл через `Ctrl + S`.

При запуске из скрипта дорожки вычисляются на клиенте выбранного игрока. Движок локально управляет его камерой, HUD, отрисовкой руки, временем суток и погодой. После остановки возвращаются обычная игровая камера и окружение.

## Что лежит в файле?

Все координаты хранятся **относительно начала координат** сцены. 
Файл описывает *форму* движения; куда её поставить, решает скрипт при запуске.

Поля начала координат двигают всю сцену. Кнопка **Перепривязать** делает обратное: сцена остаётся на
месте, меняются только числа, относительно которых она записана.

Катсцены старого формата переносятся при загрузке: начало координат ставится в первый ключ позиции,
ключи пересчитываются относительно него, а старые функции плавности превращаются в кривые. Картинка
при этом не меняется.

## Свойства и каналы

Таймлайн анимирует **свойства**. У камеры это `Transform` (Translation, Rotation) и `Lens` (FOV),
а в `World / Environment` находятся время суток и погода. Каждое свойство раскладывается на
**каналы**, и у каждого канала свои ключи: X можно двигать и сглаживать, не задевая Y и Z.

Время суток является непрерывным значением в 24 000 игровых тиков. Если в режиме кривых выбрана
только эта дорожка, шкала значений показывается в 24-часовом формате. Погода дискретна (`Ясно`,
`Дождь`, `Гроза`): она меняется строго на ключе и намеренно не показывается в редакторе кривых.

Скрытие свойства или канала сразу меняет результат в предпросмотре. Блокировка защищает ключи свойства от записи и редактирования.

### Поворот: Эйлер или кватернион

Поворот хранится **углами** (Pitch/Yaw/Roll в градусах). Это важно: кватернион не помнит, как в него
пришли, поэтому камера, повёрнутая четыре раза по 90°, вернулась бы как 0/90/180/-90 да ещё с
выдуманным roll. Записанный угол считается дальше - 0, 90, 180, 270 - и кривая через шов ±180° не
идёт в обход. В настройках свойства можно переключиться на **кватернион** (X/Y/Z/W); переключение
пересчитывает кривые, направляющие сбрасываются.

## Кривые

Интерполяция - это **пресет кривой**. Пресет пишет реальные направляющие, которые потом можно настроить
руками; отдельного «режима плавности» больше нет. Кроме кубических пресетов есть **Удержание**
(значение держится до следующего ключа) и **Линейная**.

Пресеты доступны в инспекторе и по правому клику на ключе.

Направляющие хранятся **относительно своего ключа**, поэтому переезд ключа по времени и перепривязка
их не ломают. Режимы:

- **Авто** - считаются по соседним ключам и выпрямляются на экстремумах, так что камера не пролетает
  мимо своих же ключей;
- **Зеркальные** - противоположная повторяет и направление, и длину;
- **Связанные** - противоположная повторяет направление, сохраняя свою длину;
- **Свободные** - каждая сама по себе.

При перетаскивании направляющей по умолчанию работает зеркальный режим; `Shift` сохраняет длину
противоположной, `Ctrl` двигает только ту, за которую вы тянете. Направляющая, смотрящая в прямой
сегмент, нарисована блёкло - как только её потянули, сегмент становится сплайном.

### Редактор кривых

Кнопки **Ключи / Кривые** на панели инструментов переключают режим. Свойства объединяют строки каналов. У каждого канала свои ключи, цвет и видимость.

Навигация, выделение, копирование и трансформации ключей описаны в [общем руководстве по таймлайну](/docs/hollowengine/ide/timeline). Сочетания переназначаются через **Помощь > Горячие клавиши**. В текущей раскладке колесо масштабирует время, а Ctrl + колесо прокручивает его; S масштабирует выбранные ключи. Сглаживание доступно в меню и настройках ключей, а отдельное сочетание для него можно назначить самостоятельно.

Клик по дорожке выбирает кривые для графика, не выключая их влияние на сцену. Список дорожек можно расширять за разделитель и прокручивать. Правой кнопкой можно двигать график; клик без перетаскивания открывает контекстное меню.

## Запуск и остановка

Для примеров на Kotlin добавьте [зависимость от Narrative](/docs/hollowengine/addons/narrative) и используйте серверный `.node.kts`. Аддон добавляет импорты этих функций в ноды. В [графе истории](/docs/hollowengine/addons/narrative/stories/blocks) можно использовать блок `cutscene`.

```kotlin
player.playCutscene("intro")

// Повторяется, пока её не остановят.
player.playCutscene("ambient_pan", loop = true)

player.stopCutscene()
```

`playCutscene` заменяет текущую катсцену игрока. Используйте путь относительно `hollowengine/cutscenes`; расширение `.dat` писать необязательно. `stopCutscene()` сразу возвращает обычную игровую камеру.

### Куда поставить сцену

```kotlin
// Вокруг позиции - например, угла структуры. yaw разворачивает сцену целиком.
player.playCutsceneAt("chapter_1/arrival", structurePos, yaw = 90f)

// Вокруг НПС; сцена едет за ним, пока он идёт.
player.playCutsceneNear("chapter_1/greeting", npc, follow = true)

// Вокруг самого игрока, где бы он ни стоял.
player.playCutsceneHere("ambient_pan", loop = true)
```

`rotate = false` оставит сцене её записанный разворот и только перенесёт её. Если сущность не найдена,
катсцена играет там, где была записана.

## Простой триггер сцены

```kotlin
@file:Attach(NpcEntity::class)

import net.minecraft.server.level.ServerPlayer

onInteract { event ->
    val player = event.player as? ServerPlayer ?: return@onInteract
    player.playCutscene("chapter_1/arrival")
    player.send("Добро пожаловать в долину.")
}
```

Для зацикленной камеры в зоне запустите её при входе игрока и вызовите `stopCutscene()` при выходе. Не запускайте одну и ту же катсцену каждый тик: достаточно одного вызова.
