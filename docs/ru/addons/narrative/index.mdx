<center><h1>Аддон Narrative</h1></center>

Собирайте истории с развилками, показывайте диалоги и проигрывайте движения камеры с помощью HollowEngine Narrative.

## Что добавляет аддон

- Визуальный редактор [графов `.story`](/docs/hollowengine/addons/narrative/stories) с вариантами ответа, типизированными связями, пользовательскими функциями и выражениями Kotlin.
- Серверное выполнение историй с [сохранением прогресса и возвратом к контрольным точкам](/docs/hollowengine/addons/narrative/stories/playback). В скриптах Kotlin можно определять [возобновляемые этапы](/docs/hollowengine/addons/narrative/kotlin).
- Интерфейс реплик и вариантов ответа, блоки для NPC и мира, а также [катсцены](/docs/hollowengine/addons/narrative/cutscenes) с таймлайном камеры.

NPC, навигация, каналы действий и обработчики событий `.node.kts` входят в сам HollowEngine. Скриптовые функции `move`, `lookAt` и `useBlock` предоставляет аддон.

## Установка и подключение

Поместите `HollowEngineNarrative-*.jar` в `mods/` или `hollowengine/addons/` на сервере и клиентах. Для работы необходим аддон для компилятора той же версии (нодовая система компилирует истории).

Добавьте `hollowengine-narrative` в раздел "**Зависит от аддонов**" в настройках проекта IDE.

```properties
dependsOn=hollowengine-narrative
```

![В настройках проекта в разделе «Зависит от аддонов» отмечен hollowengine-narrative](/hollowengine/pictures/narrative/project-dependency.png)

## Перенос проекта с прошлой версии

Расширение `.story` теперь обозначает граф в формате JSON. Соберите старые текстовые истории заново в редакторе графов. Для реплик используйте **Фраза**, для ответов - **Выбор**. Старый текстовый формат больше не поддерживается и не импортируется.

Вместо вызовов `DialogueController` используйте `launchStory("key") { scene(...) }` или запускайте файл командой `/he story`. Запуск истории теперь сам хранит свой прогресс. В [примере взаимодействия с NPC](/docs/hollowengine/addons/narrative/stories/npc-interaction) показано, как запустить отдельную историю для каждого игрока.

Перенесите прежние состояния нод на этапы Narrative. Вызов этапа теперь возвращает управление вызывающей функции. Отмечайте места возобновления через `checkpoint("name")`, храните NBT отрезка в `segmentTag()`, а общие значения запуска - в `saved(...)`. Замените `runOnce(...)` на `once(...)`. Проверьте перенесённую историю новым запуском.
