<center><h1>Аддоны</h1></center>

*Расширяйте HollowEngine собственным кодом, скриптами и ресурсами или ставьте аддоны других авторов.*

Аддон - это jar, который HollowEngine загружает сам, рядом с движком. Он может добавлять команды, события, редакторы, библиотеки, скрипты и ассеты. Аддон, которому хватает Minecraft и движка, работает на Fabric и NeoForge из одного jar; аддон, написанный под API конкретного загрузчика, [объявляет это](/docs/hollowengine/addons/creating) и работает только на нём.

## Встроенные аддоны

Эти аддоны поставляются с релизами HollowEngine:

| Аддон | Id | Что добавляет |
| --- | --- | --- |
| [Компилятор Kotlin](/docs/hollowengine/addons/compiler) | `hollowengine-compiler` | Компилирует `.kts` скрипты. Нужен, чтобы писать и править скрипты. |
| [MCP-сервер](/docs/hollowengine/addons/mcp) | `hollowengine-mcp` | Позволяет AI-агентам для кода работать со скриптами в запущенной игре. |
| [Физика](/docs/hollowengine/addons/physics) | `hollowengine-physics` | Физика рэгдоллов для моделей на движке Jolt. |
| [Media](/docs/hollowengine/addons/media) | `hollowengine-media` | Воспроизведение видео в экранах, UI и по команде. |
| [Narrative](/docs/hollowengine/addons/narrative) | `hollowengine-narrative` | Визуальные графы, диалоги, возобновляемые этапы и катсцены. |

## Установка аддона

Скопируйте jar аддона в любую из папок:

- `mods/` - обычный выбор для распространяемых аддонов и модпаков;
- `hollowengine/addons/` - удобно при разработке или когда аддоны нужно держать отдельно от модов.

HollowEngine проверяет и отслеживает обе папки. Если установлено несколько копий одного аддона, выбор идёт между теми, что сделаны под текущий загрузчик и сторону: побеждает более новая версия, а при равных версиях - копия из `hollowengine/addons/`. Правило одно и при запуске, и во время игры, поэтому результат не зависит от того, когда скопировали jar: более новая копия сразу заменяет работающую, а после удаления работающей запускается оставшаяся. Проигравшие копии видны в списке как `duplicate`.

Аддон без нативных библиотек можно скопировать и загрузить прямо во время игры. Аддон с библиотеками, которые загружают нативный код (Физика и Видео), намеренно не загружается на лету: лог просит перезапуск, и аддон становится доступен при следующем запуске.

## Управление аддонами

Операторы (уровень прав 2) управляют аддонами командами:

```text
/he addons list
/he addons info <addon-id>
/he addons enable <addon-id>
/he addons disable <addon-id>
/he addons reload <addon-id>
```

`list` показывает id, версию, состояние и имя файла каждого аддона, а для любого состояния, кроме `loaded` - причину. `info` добавляет загрузчик, сторону и зависимости. Отключённые id запоминаются в `hollowengine/addons/.disabled-addons`.

| Состояние | Что значит |
| --- | --- |
| `loaded` | Работает. |
| `disabled` | Выключен командой `/he addons disable`. |
| `inactive` | Сделан для другой стороны: клиентский аддон на выделенном сервере или наоборот. |
| `incompatible` | Сделан под другой загрузчик модов. |
| `missing mods` | Не установлен мод, который ему нужен. |
| `waiting for dependencies` | Не работает аддон, от которого он зависит; причина указана для каждого. |
| `restart required` | Запустится при следующем запуске игры: в нём нативные библиотеки, startup- или mixin-скрипты. |
| `rejected` | Его встроенные библиотеки конфликтуют с библиотеками игры или другого аддона. |
| `failed` | Его код упал при загрузке; ошибка показана и записана в лог. |
| `duplicate` | Используется другая копия того же аддона. |

Jar с описанием аддона, который не удалось прочитать, попадает в список как `unreadable` с текстом ошибки.

Включение, отключение и перезагрузка аддона запускают или останавливают его код, команды и скрипты. Аддоны, которые от него зависят, останавливаются и запускаются вместе с ним, и ответ команды их называет. Датапаки всех запущенных серверов перезагружаются, чтобы его команды появились или исчезли, а если у аддона есть `assets/`, перезагружаются и клиентские ресурсы.

Отключение аддона из `mods/` останавливает его код и скрипты, но не ресурсы: они принадлежат загрузчику модов, и он продолжает отдавать их, пока jar не удалён.
