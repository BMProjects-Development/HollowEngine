<center><h1>Аддон освещения</h1></center>

Размещайте цветные точечные источники и прожекторы в мире, прикрепляйте их к анимированным костям и освещайте блоки и сущности через Iris.

Рендерер `hollowengine-lighting` включает [irl-core](https://github.com/quaIett/irl-core) 1.1.7 для Minecraft 1.21.1 под лицензией MIT. Форматы GPU-буферов, атласы теней и имена сэмплеров сохранены. Уже пропатченные шейдерпаки с этим контрактом IRLights работают без конвертации.

## Установка

Установите аддон и Iris для Minecraft 1.21.1 на клиент. После первой установки перезапустите Minecraft: объявления из встроенных `.mixin.kts` применяются до загрузки игровых классов. Скрипты уже скомпилированы, поэтому для игры аддон компилятора не нужен.

Описания источников входят в общий API HollowEngine. Сервер с обновлённым движком сохраняет и синхронизирует их без рендера. Чтобы увидеть цветной свет, каждому зрителю нужны рендерер и совместимый шейдерпак. Удаление рендера сохраняет данные источников.

Соберите аддон командой `./gradlew :addons:lighting:addonJar`. Jar появится в `build/addons/lighting/libs/`. Задача `buildAddons` собирает его в `build/addon-jars/`, а `buildAndCollect` также включает в `merged/`. Один jar подходит для Fabric и NeoForge.

## Шейдерпаки и патчи

Уже пропатченный шейдерпак IRLights можно сразу выбрать в Iris. Для чистого шейдерпака используйте клиентские команды:

```text
/hollowlights packs
/hollowlights patches
/hollowlights check "BSL_v10.1.5.zip" bsl.irlights
/hollowlights patch "BSL_v10.1.5.zip" bsl.irlights
```

Замените имя шейдерпака на то, которое показала команда `packs`. Команда `check` проверяет точки вставки без записи файлов. Команда `patch` создаёт новую папку в `shaderpacks/`, сохраняя оригинал и существующие результаты. После этого выберите новый шейдерпак в Iris.

В комплект входят патчи для Bliss, BSL, Complementary Reimagined, IterationRP, Photon, Rethinking Voxels и Solas. Точная версия шейдерпака указана в заголовке `@packversion` каждого патча. Для совместимости нужны подходящий контракт IRLights и совпадающие точки вставки в GLSL. Дополнительные оригинальные `.irlights` кладите в `hollowengine/lighting/patches/`. Сами шейдерпаки с аддоном не распространяются.

Аддон владеет привязками IRLights: SSBO 7 со светом, кластерным SSBO 6 и UBO 7 с общими настройками. Используйте один рендерер IRLights одновременно: реестры источников независимых модов не объединяются.

## Создание источников

Выберите сущность или объект мира и добавьте компонент **Источник света** в инспекторе. **Точечный свет** светит во все стороны, а **Прожектор** создаёт конус вдоль локальной оси -Z. Поворот объекта мира разворачивает его прожектор.

Крепление **Источник света** в риге работает на всей модели или отдельной кости. Оно следует анимации и продолжает работать за пределами экрана. Как и сбор источников при рендере в IRLights, крепления передают последнюю завершённую позу в сбор света следующего кадра.

Этот полный пример серверного `.kts` ставит создание объекта в очередь сервера. Координаты заданы явно:

```kotlin
import ru.hollowhorizon.hollowengine.common.attachments.api.set
import ru.hollowhorizon.hollowengine.common.entities.objects.WorldObjectEntity
import ru.hollowhorizon.hollowengine.common.lighting.LightComponent
import ru.hollowhorizon.hollowengine.common.lighting.LightKind
import ru.hollowhorizon.hollowengine.common.lighting.LightSpec
import ru.hollowhorizon.hollowengine.common.utils.currentServerOrNull
import ru.hollowhorizon.hollowengine.common.utils.math.Vec3f

val server = checkNotNull(currentServerOrNull())
server.execute {
    val level = server.overworld()
    val lamp = WorldObjectEntity(level)
    lamp.setPos(0.5, 70.0, 0.5)
    lamp set LightComponent(
        light = LightSpec(kind = LightKind.SPOT, color = Vec3f(1f, 0.7f, 0.3f), radius = 16f),
        rotation = Vec3f(-90f, 0f, 0f),
    )
    level.addFreshEntity(lamp)
}
```

## Настройки и ограничения

Цвет задаётся в линейном RGB. Радиус и смещение измеряются в блоках, повороты и полные углы конуса в градусах. При передаче в IRLights внутренний угол ограничивается внешним. Размер источника влияет на мягкость теней. Освещение можно применять ко всему, только к сущностям или только к блокам.

Включите тени для перекрытия света блоками и сущностями. **Яркость объёмного луча** делает луч видимым, плотность и анизотропия меняют его вид. Для маски проекции добавьте изображение в ресурсы проекта или ресурспак и выберите его идентификатор, например `example:textures/lights/window.png`. Массив масок вмещает до 16 разных изображений.

Общие настройки находятся в `config/hollowengine-lighting.json`: качество теней `0..3`, бюджет статических запеканий, радиус теней от блоков, число передаваемых на GPU источников, блики и объёмный свет. После редактирования выполните `/hollowlights reload`. Команда также перезагружает маски и кэши теней; перезагрузка ресурспаков сбрасывает их автоматически.

Рендеру нужен OpenGL 4.3. Исходный лимит GPU составляет 2048 источников, по умолчанию передаётся до 256. Слоты теней и сбор блоков имеют отдельные бюджеты. Блоки отбрасывают тени в пределах `shadowBlockRadius`, даже если радиус освещения больше. Доступные эффекты зависят от патча IRLights. Ванильный рендер без Iris и непропатченные шейдерпаки эти данные света не используют.

При отключении аддона шейдерпак, созданный его патчером, переключается на записанный оригинал. Если выбран независимо пропатченный шейдерпак, шейдеры отключаются до освобождения GPU-ресурсов. Описания источников остаются в мире.
