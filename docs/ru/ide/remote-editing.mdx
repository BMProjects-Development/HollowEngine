# Удалённое редактирование

Подключитесь к выделенному серверу, чтобы открыть его проект в IDE HollowEngine. Вы сможете править скрипты и другие текстовые файлы прямо в игре, создавать папки, переименовывать, перемещать и удалять файлы проекта.

## Кто получает доступ

На выделенном сервере удалённое редактирование по умолчанию выключено. Откройте `config/hollowengine/remote-project.toml` в рабочей папке сервера. Настройки действуют при любом значении `online-mode`.

:::warning
Токен даёт доступ к файлам проекта и позволяет запускать и останавливать серверные скрипты. Передавайте его только доверенным редакторам. При `online-mode=false` обычное соединение Minecraft может передавать токен без шифрования. Для доступа через Интернет используйте защищённый туннель или VPN.
:::

Замените прежнюю настройку `editors` на `token` и `allowlist`. Сгенерируйте случайный секрет из 32 байт, например в шестнадцатеричном виде, и вставьте его в `token`. Пустой токен или `enabled = false` закрывает доступ всем.

```toml
enabled = true
token = ""
allowlist = ["127.0.0.1", "::1"]
```

В примере подключаться можно с машины сервера. Укажите нужные IPv4, IPv6 или диапазоны CIDR, например `192.168.1.0/24`. При пустом `allowlist` подать токен можно с любого IP. Если игрок подключается через прокси, список сверяется с адресом соединения, который видит сервер.

После переподключения введите токен снова. Когда сервер применяет новый токен или список адресов, ранее выданные допуски сбрасываются. Тот же допуск используется для `/he scripting`. Для работы со скриптами в инспекторе сущностей также нужны права на редактирование сущностей.

## Как открыть серверный проект

1. Подключитесь к серверу с той же версией HollowEngine, что и на клиенте, и откройте **Окна > Проект**.
2. В списке рядом с названием проекта выберите **Открыть доступ к проекту сервера**. Скопируйте токен, полученный от администратора, и нажмите **Вставить токен и подключиться**.
3. Раскройте нужную папку и дважды щёлкните по файлу. IDE загружает содержимое папок по мере раскрытия.
4. Нажмите `Ctrl + S`, чтобы сохранить правки. Серверная вкладка помечена словом **сервер**. Она сохраняет файл на сервер даже после того, как вы переключили дерево на **Локальный**.

В дереве доступны папки `scripts`, `assets`, `data` и `META-INF`. Для каждого файла действует лимит 2 МиБ. IDE выбирает редактор по типу файла, включая форматы установленных на клиенте аддонов. Например, с Narrative файл `.story` открывается как граф, а в текстовом режиме доступна подсветка JSON. Предпросмотр серверных 3D-моделей пока недоступен. В одиночной игре переключатель скрыт.

## Если файл изменил другой редактор

При сохранении через IDE сервер уведомляет подключённых редакторов. Вкладка без несохранённых правок сразу обновится. Если у вас есть свои правки, они останутся во вкладке, а IDE покажет конфликт. Для текстового файла можно выбрать **Разрешить конфликт > Открыть версию с сервера** и перенести нужные изменения вручную. Чтобы отправить свои правки, выберите **Оставить мои правки для следующего сохранения** и нажмите `Ctrl + S`. Чтобы принять изменения другого редактора, выберите **Заменить мои правки версией с сервера**.

Если файл изменили напрямую на диске сервера, обновите дерево и открытые вкладки через **Обновить раскрытые папки** в контекстном меню проекта. Если серверная версия успела измениться после обновления, IDE снова покажет конфликт при сохранении.
