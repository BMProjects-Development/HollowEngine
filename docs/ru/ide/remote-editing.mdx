# Удалённое редактирование

Подключитесь к выделенному серверу, чтобы открыть его проект в IDE HollowEngine. Вы сможете править скрипты и другие текстовые файлы прямо в игре, создавать папки, переименовывать, перемещать и удалять файлы проекта.

## Кто получает доступ

На выделенном сервере с `online-mode=true` удалённое редактирование по умолчанию выключено. Настройки находятся в файле `config/hollowengine/remote-project.toml` в рабочей папке сервера.

:::warning
Выдавайте доступ только тем, кому готовы доверить запуск кода на сервере. Всякие дяди-васи могут спокойно написать Kotlin-скрипт, который снесёт вам Сервер Windows или установит **Биткоин Добывалка 2004 (не вирус)**, особенно на `online-mode=false` (Без лицензии - а это значит, что с таким ником/uuid зайти может кто угодно и никакие плагины на `/login <Пароль> <Пароль>` вас, вероятно, не спасут).
:::

Задайте `enabled = true` и добавьте UUID нужных игроков в список `editors`. UUID операторов тоже нужно указать явно. При пустом списке доступ закрыт для всех.

На выделенном сервере этот же список даёт игрокам право запускать и останавливать серверные скрипты из IDE или через `/he scripting`. Для работы со скриптами в инспекторе сущностей также нужны права на редактирование сущностей.

```toml
enabled = true
editors = ["01234567-89ab-cdef-0123-456789abcdef"]
```

Замените UUID в примере на UUID нужного игрока (не ник). Чтобы отключить удалённое редактирование для всех, задайте `enabled = false`.

Для проверки на одном компьютере можно запустить выделенный сервер из среды разработки с `online-mode=false` и `server-ip=127.0.0.1`. Подключитесь к `127.0.0.1` и укажите в `editors` UUID, который сервер видит в этом режиме.

## Как открыть серверный проект

1. Подключитесь к серверу с той же версией HollowEngine, что и на клиенте, и откройте **Окна > Проект**.
2. В списке рядом с названием проекта выберите **Сервер**. Список появляется, когда сервер предоставил вам доступ.
3. Раскройте нужную папку и дважды щёлкните по файлу. IDE загружает содержимое папок по мере раскрытия.
4. Нажмите `Ctrl + S`, чтобы сохранить правки. Серверная вкладка помечена словом **сервер**. Она сохраняет файл на сервер даже после того, как вы переключили дерево на **Локальный**.

В дереве доступны папки `scripts`, `assets`, `data` и `META-INF`. В редакторе можно открыть текстовый файл размером до 2 МиБ. В одиночной игре переключатель скрыт.

## Если файл изменил другой редактор

При сохранении через IDE сервер уведомляет подключённых редакторов. Вкладка без несохранённых правок сразу обновится. Если у вас есть свои правки, они останутся во вкладке, а IDE покажет конфликт. Откройте **Разрешить конфликт > Открыть версию с сервера** и перенесите нужные изменения вручную. Когда всё готово, выберите **Оставить мои правки для следующего сохранения** и нажмите `Ctrl + S`.

Если файл изменили напрямую на диске сервера, обновите дерево и открытые вкладки через **Обновить раскрытые папки** в контекстном меню проекта. Если серверная версия успела измениться после обновления, IDE снова покажет конфликт при сохранении.
