# Таймлайн

Катсцены, VFX и монтажи используют общее окно **Таймлайн**. Оно следует за активным редактором: набор дорожек зависит от открытого ассета. Значения времени задаются в секундах.

## Навигация и выделение

Ниже приведены стандартные сочетания. Их можно изменить в [настройках клавиш IDE](/docs/hollowengine/ide).

| Действие                                   | Управление                                |
|--------------------------------------------|-------------------------------------------|
| Играть / пауза                             | `Space`                                   |
| В начало                                   | `Home`                                    |
| Центрировать на курсоре времени            | `NumPad 0`                                |
| Ключи / кривые                             | `Ctrl + Tab`                              |
| Масштаб по времени                         | Колесо                                    |
| Прокрутка по времени                       | `Ctrl` + колесо                           |
| Вертикальная прокрутка дорожек или графика | `Shift` + колесо                          |
| Масштаб значений в графике                 | `Alt` + колесо                            |
| Перемещение холста                         | Средняя кнопка мыши                       |
| Масштабирование перетаскиванием            | `Ctrl` + средняя кнопка мыши              |
| Предыдущий / следующий ключ                | Стрелка вниз / вверх                      |
| Сдвинуть выбранное по времени              | Стрелки влево / вправо; `Shift` - крупнее |

Зажав левую кнопку мыши можно выделить несколько ключей; Клики с `Ctrl` или `Shift` добавляют ключ к остальным. `Ctrl` + перетаскивание ключа создаёт его копию. `Ctrl + C`, `Ctrl + X`, `Ctrl + V` копируют, вырезают и вставляют ключи относительно курсора времени. Удержание `Alt` при перемещении отключает привязку к сетке.

Привязка к кадрам включается кнопкой на панели; рядом задаётся FPS сетки, по умолчанию `20`. Это точность редактирования, а не частота рендеринга. Если ключи не выделены, стрелки влево и вправо двигают курсор времени; удержание прокручивает время до отпускания клавиши.

Клик по дорожке определяет, какие кривые видны на графике. Это отличается от отключения видимости дорожки: скрытая дорожка перестаёт влиять на предпросмотр. `F` вписывает видимые кривые.

## Запись и кривые

Кнопка записи включает автоключи там, где редактор их поддерживает. Изменение свойства или работа манипулятором записывает значение на текущем времени. Для явной вставки используйте кнопку ключа у поля или `I` в окне просмотра с Gizmo для позиции, поворота, масштаба или всех трансформаций.

В графике выделенные ключи и направляющие можно перемещать (`G`), вращать (`R`) и масштабировать (`S`). `X` ограничивает действие временем, `Y` - значением; повторное нажатие снимает ограничение. `Enter` или ЛКМ подтверждает, `Escape` или ПКМ отменяет действие. В Инспекторе доступны точные значения выбранных ключей и настройки направляющих. Интерполяция и режимы направляющих подробнее описаны в [катсценах](/docs/hollowengine/world/cutscenes).

## События и секции

В **монтажах и VFX** есть именованные события и секции. Добавьте их через контекстное меню соответствующей дорожки; параметры выбранного элемента появятся в Инспекторе.

Событие отмечает момент, к которому можно перейти по имени. В монтажах оно также вызывает зарегистрированные скриптом обработчики. Секция - непересекающийся участок времени с правилами входа и выхода:

| Правило           | Когда проверяется    | Результат                          |
|-------------------|----------------------|------------------------------------|
| Пропустить        | При входе            | Перейти в конец секции.            |
| Повторить         | При выходе           | Вернуться в начало секции.         |
| Перейти к событию | При входе или выходе | Продолжить с именованного события. |

Правила проверяются по порядку, срабатывает первое с истинным условием. Пустое условие всегда истинно. Если ничего не сработало, воспроизведение идёт дальше. Условия используют язык выражений своего редактора; например, `d.waiting` позволяет повторять участок ожидания, пока скрипт не изменит данные.

В Инспекторе корня монтажа или VFX поле **Данные предпросмотра** позволяет задать тестовые значения:

```text
d.waiting = true;
d.charge = 0.5;
```

Они используются только в предпросмотре. Кнопка сброса заново применяет значения и запускает предпросмотр с начала. Для VFX реальные значения приходят из объекта управления эффектом, для монтажа - из данных сущности.
