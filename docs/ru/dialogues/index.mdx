<center><h1>Диалоговая система</h1></center>

*Ветвящиеся сцены на компактном языке с запуском из Kotlin-скриптов.*

![Диалог](/hollowengine/titles/dialogues/index.webp)

:::advice
Диалоги входят в [аддон Narrative](/docs/hollowengine/addons/narrative). Скриптам папки `hollowengine` для работы с ними нужен `dependsOn=hollowengine-narrative` в `plugin.properties` проекта.
:::

Сценарии диалогов пишутся в `.story` файлах. Они лежат рядом с Kotlin-скриптами в `hollowengine/scripts`, но используют отдельный построчный язык. Встроенная IDE поддерживает его подсветку, диагностику, автодополнение и навигацию.

Например, файл `hollowengine/scripts/stories/gate.story` имеет адрес `project:stories/gate.story`.

## Первый диалог

```story
# Начало

Стражник: Стой. У тебя {money} монет.[-] Проход стоит 20.

@choice "Заплатить 20 монет" id=pay if=money>=20
    @set money = money - 20
    Стражник: Можешь проходить.
@choice "Уйти" id=leave
    Стражник: Возвращайся, когда будешь готов.
```

Соседние блоки `@choice` образуют одно меню. Выполняется только выбранный блок. Параметр `if=` скрывает недоступный вариант, а `id=` задаёт стабильный идентификатор, не зависящий от текста и перевода.

## Запуск из Kotlin

```kotlin
import ru.hollowhorizon.hollowengine.addons.narrative.dialogue.DialogueCharacter
import ru.hollowhorizon.hollowengine.addons.narrative.dialogue.DialogueController

val gateDialogue = DialogueController("project:stories/gate.story")

@State
suspend fun talkToGuard() {
    gateDialogue.start(player) {
        character("Стражник", DialogueCharacter.of(guard))
        put("money", 35)
    }
}
```

Первый участник автоматически доступен как `player`. Остальные персонажи привязываются под именами, используемыми в story-файле.
