*Основные конструкции `.story` файлов.*

![Диалог](/hollowengine/titles/dialogues/syntax.webp)

## Структура файла

Каждая непустая строка является меткой, командой, репликой персонажа или текстом рассказчика. Отступы открывают блоки условий, циклов, вариантов ответа и асинхронных дорожек.

```story
# Начало
// Комментарий на отдельной строке
@if hasPass
    Стражник: Всё в порядке. // Комментарий в конце строки
```

`//` начинает комментарий в начале содержимого или после пробельного символа. Пустые строки и комментарии не влияют на выполнение. Поддерживаются пробелы и табуляция, но в одном файле лучше использовать единый стиль.

## Текст диалога

Имя говорящего перед `:` должно состоять из одного слова. Разрешены буквы, цифры, `_` и `-`. Если отображаемое имя содержит пробелы, используйте короткое сценарное имя.

```story
Дорога исчезает в тумане.
Стражник: С возвращением, {player.name}.
Стражник: У тебя {money} монет.[-] Ты всё ещё хочешь войти?
Стражник: Подожди здесь.[wait 750ms] Теперь можем продолжить.
```

- `{выражение}` вставляет вычисленное значение.
- `[-]` приостанавливает реплику до ввода участников.
- `[команда аргументы]` выполняет встроенную функцию. Запись `[@wait 750ms]` тоже допустима.
- `\n` и `\t` вставляют перенос строки и табуляцию. Обратная косая черта экранирует следующий символ, например `\{`, `\[`, `\"` или `\\`.

Встроенные вызовы работают только в репликах. Варианты ответа поддерживают подстановки, но не выполняют команды в квадратных скобках.

### Форматирование

Реплики и подписи вариантов ответа поддерживают вложенную разметку. Теги не входят в число символов тайпрайтера:

```story
Виталик: Я теперь <b>жирный</b>, бойся меня!
Виталик: <color=gold>Золотой и <i>золотой курсив</i>.</color>
Виталик: <wave amplitude=2 speed=3>Эта фраза идёт волной.</wave>
@choice "<b>Ответить уверенно</b>" id=confident
```

| Тег | Результат |
| --- | --- |
| `<b>`, `<strong>` | Жирный текст |
| `<i>`, `<em>` | Курсив |
| `<u>` | Подчёркивание |
| `<s>`, `<strike>` | Зачёркивание |
| `<color=red>`, `<color=#55FFFF>` | Именованный цвет или `#RGB[A]` / `#RRGGBB[AA]` |
| `<gradient from=#FF5555 to=#5555FF speed=0.25>` | Градиент между двумя цветами |
| `<rainbow>`, `<pulse>`, `<wave>`, `<shake>`, `<wiggle>`, `<swing>`, `<glitch>` | Анимированные эффекты Hollow UI |
| `<br>` | Перенос строки |

У анимаций можно переопределять параметры эффектов, например `<wave amplitude=4 frequency=1.5 speed=2>` или `<glitch frequency=3 intensity=2 chromatic=false>`. Все параметры необязательны. Неизвестный либо некорректный тег показывается буквально, чтобы опечатка не удаляла текст. Незакрытый известный тег действует до конца текущей реплики; это позволяет окружать разметкой подстановки и паузы.

Для буквальных зарезервированных символов используйте `&lt;`, `&gt;`, `&amp;`, `&quot;` и `&apos;`. Например, `&lt;b&gt;текст&lt;/b&gt;` покажет `<b>текст</b>` без выделения.

Стандартное окно диалога уже использует `FormattedText(...)`. В собственной `.ui.kts` разметке вызывайте `FormattedText(line.text, visibleCharacters = line.visibleLength)` либо `FormattedTextSpans(...)`, если реплика должна делить один inline-поток с префиксом. Чат сохраняет жирность, курсив, линии и цвет, а эффекты движения отображает как обычный текст.

## Переменные и выражения

```story
@set visits = visits + 1
@set admitted = true
@set greeting = "С возвращением"
```

Переменная хранит строку, число или логическое значение и входит в контрольную точку. Списки существуют как временные выражения и аргументы, поэтому сохранить их через `@set` нельзя.

| Синтаксис | Значение |
| --- | --- |
| `true`, `false` | Логические значения |
| `12`, `-2.5` | Числа |
| `500ms`, `2s`, `2sec`, `1.5min`, `1h` | Длительности в миллисекундах |
| `"текст"`, `[10, 64, -5]` | Строка и список |
| `!ready`, `-price` | Логическое и числовое отрицание |
| `*`, `/`, `%`, `+`, `-` | Арифметика с обычным приоритетом |
| `==`, `!=`, `<`, `<=`, `>`, `>=` | Сравнение |
| `&&`, `||` | Логические операции с коротким замыканием |
| `(выражение)` | Явная группировка |
| `items[0]`, `items.size`, `text.size` | Индекс и размеры |
| `Стражник.name`, `Стражник.uuid` | Имя и UUID привязанного персонажа |

В условиях ложными считаются `false`, `0` и пустая строка. Оператор `+` складывает числа, объединяет строки и добавляет значения к спискам.

:::warning
Чтение неизвестной переменной или свойства завершает диалог с ошибкой. Передавайте начальные значения в блоке `start` до их использования.
:::

## Аргументы функций

Позиционные аргументы должны идти перед именованными:

```story
@play-sound minecraft:entity.villager.yes 1.0 pitch=0.8
@camera [10, 70, 5] [90, 15] time=2s fov=60
@look-at Стражник {player}
```

Слова без кавычек считаются строками. Строки с пробелами заключаются в кавычки. Числа, логические значения, длительности и списки сохраняют тип. Оберните выражение в `{...}`, если аргумент нужно вычислить.

Именованное условие записывается компактно или заключается в кавычки:

```story
@choice "Купить" if=money>=20
@choice "Купить со скидкой" if="money >= price && reputation > 5"
```

Параметр `tag=` зарезервирован у любого вызова. Он помечает действие для обработчиков и не входит в сигнатуру функции.

## Команды Minecraft

`@command` запускает команду Minecraft с уровнем разрешений 4 и поддерживает подстановки:

```story
@command title @a actionbar Баланс: {money}
```
