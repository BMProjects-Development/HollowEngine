<center><h1>Собственные Story-команды</h1></center>

*Открывайте story-файлам переиспользуемые действия на Kotlin.*

![Диалог](/hollowengine/titles/dialogues/custom-commands.webp)

Команда может быть глобальной или локальной. Оба способа используют `StoryFunctionRegistry`, поэтому сигнатуры, автодополнение и привязка аргументов работают одинаково.

## Глобальные команды из reload.kts

Используйте `RegisterStoryFunctionsEvent`, если команда нужна всем диалогам:

```kotlin
import net.minecraft.network.chat.Component
import ru.hollowhorizon.hollowengine.common.dialogue.RegisterStoryFunctionsEvent
import ru.hollowhorizon.hollowengine.common.dialogue.lang.string

@SubscribeEvent
fun registerDialogueCommands(event: RegisterStoryFunctionsEvent) {
    event.functions.unregister("announce")
    event.functions.add("announce", string("text")) { args ->
        val message = Component.literal(args.string("text"))
        players.forEach { it.sendSystemMessage(message) }
    }
}
```

```story
@announce "Ворота закрываются"
```

Событие повторно вызывается при перезагрузке story-функций. Обработчик должен быть идемпотентным, поэтому сначала один раз вызовите `unregister`, затем добавьте все перегрузки этого скрипта. Используйте уникальное имя команды, чтобы не удалить чужие перегрузки.

## Локальные команды контроллера

```kotlin
val gateDialogue = DialogueController("project:stories/gate.story") {
    functions.add("guard-log", string("text")) { args ->
        server.sendSystemMessage(Component.literal("[Gate] ${args.string("text")}"))
    }
}
```

Локальные функции хранятся в дочернем реестре. Они наследуют глобальные команды, но не попадают в другие контроллеры.

## Типизированная регистрация

Для одной, двух или трёх обязательных переменных сигнатуру можно вывести из Kotlin-типов:

```kotlin
functions.add<String, Float>(
    "change-reputation",
    params = listOf("faction", "amount"),
) { faction, amount ->
    updateReputation(players, faction, amount)
}
```

| Kotlin-тип | Story-тип |
| --- | --- |
| `String` | Текст |
| `Float`, `Int`, `Double` | Число |
| `Long` | Длительность в миллисекундах |
| `Boolean` | Логическое значение |
| `List<*>` | Список |

Для необязательных аргументов, значений по умолчанию, персонажей и более длинных сигнатур используйте полные дескрипторы.

## Полные сигнатуры и значения по умолчанию

```kotlin
import kotlinx.coroutines.delay
import net.minecraft.network.chat.Component
import ru.hollowhorizon.hollowengine.common.dialogue.lang.number
import ru.hollowhorizon.hollowengine.common.dialogue.lang.string
import kotlin.time.Duration.Companion.milliseconds

functions.add(
    "notify",
    string("text"),
    number("time", default = 2_000f),
) { args ->
    val message = Component.literal(args.string("text"))
    players.forEach { it.sendSystemMessage(message) }
    delay(args.millis("time").milliseconds)
}
```

Доступны дескрипторы `string`, `number`, `boolean`, `list`, `actor` и `any`. Большинство принимает `optional = true`, а `string`, `number` и `boolean` поддерживают значение по умолчанию.

`StoryArguments` предоставляет `string`, `number`, `int`, `bool`, `list`, `millis`, `actor`, `entity` и `vec3`, а также nullable-варианты для пропущенных значений. Под одним именем можно зарегистрировать несколько перегрузок с разными списками параметров.

## Контекст команды

Обработчик является приостанавливаемым extension на `StoryCallContext`:

- `session` предоставляет переменные и персонажей.
- `server` открывает серверный API и миры.
- `players` содержит участников в сети.
- `state` является `CompoundTag` текущего вызова.
- `checkpoint()` запрашивает немедленное сохранение после изменения `state`.

Команда может вызывать suspend API. Исключение завершает диалог с `DialogueResult.Failed` и сохраняет контрольную точку.

## Защита побочных эффектов от повтора

После остановки сервера оператор может выполниться повторно. Запоминайте завершённые побочные эффекты, если дублирование опасно:

```kotlin
functions.add("grant-key") { _ ->
    if (!state.getBoolean("granted")) {
        players.forEach(::grantGateKey)
        state.putBoolean("granted", true)
        checkpoint()
    }
}
```

После успешного завершения состояние вызова удаляется.

## Метки действий

Любая команда принимает зарезервированный аргумент `tag=`:

```story
@notify "Глава началась" tag=chapter-start
```

```kotlin
gateDialogue.onStart("chapter-start") { event ->
    println("Started ${event.function}")
}

gateDialogue.onEnd("chapter-start") { event ->
    println("Finished with ${event.reason}")
}
```

Глобальные обработчики используют `DialogueEvent.ActionStarted` и `DialogueEvent.ActionEnded`.
