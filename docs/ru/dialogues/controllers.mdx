<center><h1>Контроллеры и прогресс</h1></center>

*Запуск сессий, привязка персонажей, локализация и сохранение прогресса.*

![Диалог](/hollowengine/titles/dialogues/control.webp)

## Участники и персонажи

```kotlin
val dialogue = DialogueController("project:stories/gate.story")

val result = dialogue.start(player, companion) {
    character("Стражник", DialogueCharacter.of(guard))
    character("Торговец", DialogueCharacter.of("Странствующий торговец"))
    put("money", 35)
    put("hasPass", false)
}
```

Первый участник доступен как `player`. Строковый персонаж может говорить, но команды сущностей требуют `DialogueCharacter.of(entity)`.

Один контроллер представляет одну сессию и не запускается дважды одновременно. Для общей сцены передавайте несколько игроков в один `start`, а для независимых разговоров создавайте отдельные контроллеры.

`start` возвращает `DialogueResult`. `launchIn(scope, players...)` запускает без блокировки вызывающей функции. `startHeadless()` выполняет мировую логику без участников.

## Начальные переменные

Для строк, чисел и логических значений используйте `put`, для прямого доступа используйте `variables`:

```kotlin
dialogue.start(player) {
    put("name", player.name.string)
    put("money", 35)
    put("hasPass", false)
    variables { this["visits"] = StoryNumber(3f) }
}
```

Значения остаются до перезаписи, нормального завершения story-файла или вызова `reset()`.

## Голосование

По умолчанию меню бессрочно ждёт каждого участника в сети. Тайм-аут задаётся в builder:

```kotlin
val dialogue = DialogueController("project:stories/council.story") {
    votePolicy = VotePolicy(timeoutMillis = 15_000, abstainOnTimeout = true)
}
```

Побеждает большинство, ничья разрешается случайно, а при отсутствии голосов выбирается первый вариант. Стабильные `id` доступны через `onChoice` и `DialogueEvent.Chosen`.

## Локализация

Переводы являются полными story-файлами:

```text
stories/gate.story
stories/gate.ru_ru.story
```

```kotlin
val dialogue = DialogueController("project:stories/gate.story") {
    locale = "ru_ru"
}
```

Сначала движок ищет локализованный файл, затем возвращается к базовому. Сохраняйте одинаковые `id` вариантов между переводами.

## Контрольные точки

Контроллер хранит метку, стек вызовов, переменные, именованные дорожки и состояние функции. Нормальное завершение очищает их. Выход игроков, отмена и ошибки сохраняют контрольную точку.

- `save(key, tag)` записывает прогресс в `CompoundTag`.
- `load(key, tag)` восстанавливает его перед следующим `start`.
- `reset()` удаляет прогресс и переменные.
- `checkpoint()` возвращает текущий снимок.

```kotlin
dialogue.onCheckpointRequest { controller ->
    controller.save("gate-dialogue", persistentTag)
}

dialogue.load("gate-dialogue", persistentTag)
dialogue.start(player) {
    character("Стражник", DialogueCharacter.of(guard))
}
```

Собственные команды вызывают `checkpoint()` у `StoryCallContext`, чтобы немедленно запустить сохранение. Контрольные точки используют метку и смещение, поэтому правки выше стабильной метки не сдвигают место продолжения.

## События и редактор

Контроллер предоставляет `onDialogStart`, `onDialogEnd`, `onChoice`, `onStart(tag)` и `onEnd(tag)`. Глобальные обработчики используют `DialogueEvent.Started`, `Ended`, `Chosen`, `ActionStarted` и `ActionEnded`.

Встроенная IDE подсвечивает `.story`, проверяет отступы и сигнатуры, дополняет команды и переходит из `@jump` или `@call` к целям.
