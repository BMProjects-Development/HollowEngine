<center><h1>Встроенные команды</h1></center>

*Функции, доступные любому story-файлу без дополнительной регистрации.*

![Диалог](/hollowengine/titles/dialogues/commands.webp)

Аргументы могут быть позиционными или именованными. Длительности принимают миллисекунды без суффикса, а также `ms`, `s`, `sec`, `min` и `h`.

## Общие и визуальные команды

| Команда | Аргументы | Поведение |
| --- | --- | --- |
| `@wait` | `time` | Приостанавливает выполнение. Остаток ожидания переживает восстановление. |
| `@play-sound` | `name [volume] [pitch]` | Проигрывает звук всем участникам. |
| `@fade-in` | `[time=500ms] [color="#000000"]` | Затемняет экран выбранным цветом. |
| `@fade-out` | `[time=500ms] [color="#000000"]` | Убирает затемнение. |
| `@hide-hud` | `[only=...] [except=...]` | Скрывает весь HUD, выбранные слои или всё, кроме выбранных слоёв. |
| `@show-hud` | без аргументов | Восстанавливает состояние HUD до диалога. |
| `@camera` | `location rotation [time=1s] [fov=70]` | Перемещает камеру. Поворот задаётся как `[yaw, pitch]` или `[yaw, pitch, roll]`. |
| `@release-camera` | `[time=1s]` | Возвращает камеру игроку. |
| `@cutscene` | `name [time]` | Запускает катсцену. При наличии `time` story-файл ждёт указанное время. |

```story
@hide-hud except=chat
@fade-in 750ms color="#120A1F"
@camera [10, 70, 5] [90, 15] time=2s fov=60
@fade-out 750ms
@show-hud
```

`@hide-hud` принимает списки и строки с именами через запятую. Команды камеры и затемнения ждут завершения перехода.

## Команды NPC

| Команда | Аргументы | Поведение |
| --- | --- | --- |
| `@walk-to` | `who position-or-character [speed=...] [distance=...] [timeout=15s] [facing=...]` | Перемещает NPC и ждёт прибытия. `timeout=0` отключает ограничение. Список позиций `[[x, y, z], [x, y, z]]` NPC проходит по очереди и останавливается только в последней. `facing=` — персонаж или позиция, на которые NPC смотрит по пути; идёт он тогда боком или задом. |
| `@stop-walking` | `who` | Останавливает навигацию NPC. |
| `@look-at` | `who position [time=1500ms]` или `who character` | Смотрит на позицию или следит за персонажем. |
| `@stop-looking` | `who` | Сбрасывает цель взгляда. |
| `@play-once` | `who animation [fade=330ms]` | Проигрывает анимацию один раз и ждёт завершения. |
| `@play-looped` | `who animation [fade=330ms]` | Запускает зацикленную анимацию. |
| `@play-clamped` | `who animation [fade=330ms]` | Удерживает последнюю позу. |
| `@play-ping-pong` | `who animation [fade=330ms]` | Запускает цикл вперёд и назад. |
| `@stop-animation` | `who animation [fade=330ms]` | Останавливает анимацию. |

```story
@walk-to Стражник [100, 64, 120] speed=1.2 distance=2 timeout=10s
@walk-to Стражник [[100, 64, 120], [110, 64, 120], [110, 64, 135]]
@walk-to Стражник [96, 64, 120] facing=player
@look-at Стражник player
@play-once Стражник hello fade=250ms
```

Для движения и анимаций нужен персонаж с сущностью. Команды движения и взгляда требуют именно NPC HollowEngine.

Затемнение, HUD, камера и катсцены восстанавливаются при завершении диалога или смерти участника.
