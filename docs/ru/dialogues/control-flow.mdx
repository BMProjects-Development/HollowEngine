<center><h1>Управление потоком</h1></center>

*Ветвления, циклы, вызовы секций и параллельные действия.*

![Диалог](/hollowengine/titles/dialogues/flow.webp)

## Условия и циклы

```story
@if money >= 20 && hasPass
    Стражник: Можешь войти.
@else-if money >= 20
    Стражник: Тебе всё ещё нужен пропуск.
@else
    Стражник: Возвращайся с двадцатью монетами.

@while attempts < 3
    @set attempts = attempts + 1
    Стражник: Попытка {attempts}.
```

`@else-if` и `@elseif` равнозначны. `@else-if` или `@else` должны идти сразу после своей цепочки `@if` на том же уровне отступа.

## Варианты ответа

```story
@choice "Купить пропуск" id=buy if="money >= price"
    @set money = money - price
    @jump #Оплачено
@choice "Спросить о городе" id=city
    @call #ОГороде
@choice "Уйти" id=leave
    @jump #Конец
```

Текст варианта заключается в кавычки. Соседние варианты с одинаковым отступом образуют одно меню. `if=` управляет видимостью, а `id=` задаёт стабильный ключ для Kotlin и переводов.

При нескольких участниках побеждает вариант с большинством голосов. Ничья разрешается случайно, а при отсутствии голосов выбирается первый вариант. Настройка тайм-аута описана на странице [Контроллеры и прогресс](/docs/hollowengine/dialogues/controllers).

## Метки, переходы и вызовы

```story
# Начало
Стражник: Выбери тему.
@call #Слухи
@jump #Конец

# Слухи
Стражник: Говорят, старая шахта снова открыта.
@return
```

Имя метки состоит из одного слова. `@jump` сбрасывает стек вызовов. `@call` запоминает следующую строку, а `@return` возвращается к ней. Возврат из внешнего story-файла завершает диалог.

Цель может находиться в другом файле. Межфайловая метка необязательна:

```story
@call project:stories/common.story#Приветствие
@jump project:stories/chapter_2.story#Начало
```

## Асинхронные дорожки

`@async` запускает работу параллельно:

```story
@async name=терпение
    @wait 20s
    @sync
    Стражник: Время вышло. Уходи.
    @jump #Конец

Стражник: Только быстро.

@choice "Извиниться" id=apologise
    @cancel терпение
@choice "Продолжить разговор" id=talk
    @await терпение
```

До `@sync` внутри асинхронного блока нельзя размещать реплики и варианты ответа. При достижении `@sync` дорожка прерывает текущую реплику или меню, а остаток блока становится основным потоком.

- `@async name=track` запускает именованный блок. Повторный запуск заменяет старую задачу.
- `@async name=bell play-sound minecraft:block.note_block.bell` представляет однострочную форму.
- `@await trackA trackB` ждёт указанные дорожки. `@await` без имён ждёт все активные дорожки.
- `@cancel track` отменяет именованную дорожку.

Давайте длительным задачам имена, чтобы их можно было дождаться, отменить и восстановить.
