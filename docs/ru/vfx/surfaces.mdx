<center><h1>Поверхности и материалы</h1></center>

Выберите, как будет выглядеть эффект: спрайт частицы, объёмная модель, шлейф или луч. Эти узлы рисуют результат и задают, как он смешивается с изображением мира.

Узлы-рендереры превращают симуляцию в пиксели. Рендерер прямо под [эмиттером](/docs/hollowengine/vfx/emitters) рисуется на каждой частице; в любом другом месте - один раз там, где стоит.

## Узлы-рендереры

| Узел | Что рисует |
| --- | --- |
| **Плоскость** | Текстурированный квадрат. По умолчанию смотрит на камеру, поэтому это стандартный спрайт частицы. |
| **Куб**, **Сфера**, **Цилиндр** | Примитивный меш. Меши рисуются инстансингом, поэтому их много можно позволить. |
| **Модель** | Модель из проекта. **Запускать вместе с моделью** проигрывает анимацию с начала, **Поворачивать по движению** ориентирует её по скорости частицы, а **Светящийся** игнорирует освещение мира. |
| **Шлейф** | Лента, идущая за узлом или за каждой частицей под эмиттером. |
| **Луч** | Лента между двумя точками: этим узлом и **Целевым узлом** либо фиксированной точкой **Конец**. |

У мешей есть **Сегменты** для гладкости и **Закрытые торцы** для цилиндров.

### Ориентация

Плоскости выбирают, как поворачиваться:

- **Как повёрнут** использует только поворот узла и частицы;
- **К камере** - билборд;
- **К камере вокруг оси** поворачивается только вокруг фиксированной оси, например для травинок и высокого пламени;
- **По движению** выравнивает спрайт по скорости частицы, подходит для искр и дождя.

Ось задана в пространстве частиц: эмиттера для локальных, мира для мировых.

### Шлейфы и лучи

Шлейф оставляет точки за своей головой. **Длина во времени** - сколько живёт точка, **Шаг** - на сколько должна сместиться голова, чтобы добавилась новая точка, а **Точек** ограничивает длину. **Ширина** читается вдоль ленты: `p.progress` равен `0` у головы и `1` у хвоста, поэтому `1 - p.progress` сужает ленту. **Оттенок** на ленте - градиент от головы к хвосту.

Текстура ленты либо **Растягивается** один раз на всю длину, либо **Повторяется** каждые **Длина текстуры** блоков. **Прокрутка текстуры** сдвигает текстуру вдоль ленты каждую секунду.

Луч добавляет **Дрожание** - шум, который отталкивает середину луча в сторону, пока концы остаются на месте, с настройками детализации (волн на блок) и **Скорости дрожания**. `hollowengine:lightning` собран из лучей.

## Материал

У каждого рендерера есть секция **Материал**.

| Настройка | Значение |
| --- | --- |
| **Текстура** | Ресурс текстуры, например `project:textures/spark.png`. |
| **Оттенок** | Умножает цвет. На частице умножает цвет частицы. |
| **Наложение** | Как поверхность смешивается с кадром; см. ниже. |
| **Освещается миром** | Применяет освещение в позиции поверхности. |
| **Скрывать обратную сторону** | Пропускает грани, повёрнутые от камеры. |
| **Прячется за геометрией** | Тест глубины: блоки и сущности спереди скрывают поверхность. |
| **Пишет глубину** | Скрывает ли поверхность то, что нарисовано после неё. |
| **Область текстуры** | Часть текстуры со спрайтом, от `0` до `1`. [Атлас кадров](/docs/hollowengine/vfx/emitters#frame-atlas) режется из этой области. |
| **Мягкое пересечение** | Гасит поверхность у геометрии; см. ниже. |
| **Свечение** | Добавляет ореол; см. ниже. |

### Наложение

| Режим | Для чего |
| --- | --- |
| `OPAQUE` | Сплошные поверхности. Альфа только вырезает дырки. |
| `BLEND` | Обычная прозрачность: дым, пыль, облака. Сортируется по глубине. |
| `ADDITIVE` | Огонь, искры, лазеры. Добавляет цвет поверхности к кадру. |
| `MULTIPLY` | Тени, пятна, копоть. Умножает то, что позади. |

### Мягкие частицы и свечение

**Мягкое пересечение** задаёт расстояние в блоках, на котором поверхность гаснет рядом с геометрией сцены. Это убирает жёсткий край там, где частица пересекает землю или блок. `0` отключает эффект.

**Свечение** добавляет размытый ореол цвета поверхности с учётом глубины сцены. `0` отключает его; большие значения усиливают ореол. **Аддитивное смешивание** меняет саму поверхность и само по себе не включает проход свечения. Обе настройки можно использовать вместе. Вклад свечения не ограничивается единицей в буфере `RGBA16F`.

HollowEngine не применяет тонмаппинг после добавления свечения, поэтому эффект выглядит так, как его задал автор. Подбирайте силу на глаз.

:::advice
Свечение использует глубину кадра, поэтому светящаяся поверхность остаётся скрытой за блоками. Оно стоит дополнительных проходов в кадре; применяйте его на немногих поверхностях, где оно нужно.
:::

## Свои шейдеры

Секция **Шейдер** рендерера принимает либо [граф материала](/docs/hollowengine/vfx/material-graph), либо core-шейдер. Оставьте её пустой для встроенного. Собственный core-шейдер участвует в проходе свечения, только если объявляет `GlowPass` и использует значение `Glow`; мягкие пересечения он тоже должен реализовать сам. О том, что получает core-шейдер, см. [Экран, небо и тряска](/docs/hollowengine/vfx/screen#writing-a-core-shader).

## Шейдерпаки

Эффекты работают с шейдерпаками Iris. Если пак включён, HollowEngine рисует плоскости, меши и ленты после финального прохода пака, поверх готового кадра с глубиной сцены, поэтому они выглядят одинаково с любым паком. Модели остаются в обычном проходе пака.
