<center><h1>Экран, небо и тряска</h1></center>

*Эффекты, которые действуют на весь кадр, небо или камеру.*

Эти узлы не рисуют частицы. Они меняют вид мира, пока узел включён, поэтому включайте и выключайте их дорожкой **Включён** узла на Таймлайне.

## Эффект экрана

Экранный эффект можно собрать без GLSL: создайте `.material`, выберите назначение **Post** и укажите файл в поле **Шейдер** узла. См. [граф экранного эффекта](/docs/hollowengine/vfx/material-graph). Описанный ниже вариант с core-шейдером также поддерживается.

Узел **Эффект экрана** рисует шейдер на весь экран поверх кадра. Поле **Шейдер** принимает `namespace:path` core-шейдера (`assets/namespace/shaders/core/path.json`). Встроенные шейдеры:

| Шейдер | Эффект |
| --- | --- |
| `hollowengine:vfx/post/grayscale` | Обесцвечивает кадр. |
| `hollowengine:vfx/post/chromatic_aberration` | Разводит цветовые каналы. |
| `hollowengine:vfx/post/impact` | Искажение от удара. |

Секция **Uniform'ы** перечисляет uniform'ы шейдера, прочитанные из его json, и каждый принимает [значение](/docs/hollowengine/vfx/values). Ничего не затухает с расстоянием само; напишите спад сами, например `1 - n.camera_distance / 32` для **Strength**, чтобы далёкий взрыв едва подкрашивал экран.

## Небо

Узел **Небо** рисует шейдер на дальней плоскости, поэтому он виден только там, где ничего нет спереди: местность, сущности и облака остаются поверх. Позиция узла задаёт направление неба, на которое нацелен шейдер.

Используйте вершинный шейдер `hollowengine:vfx/sky/sky`: он передаёт фрагментному шейдеру `skyDirection` - луч взгляда. Движок также задаёт:

| Uniform | Значение |
| --- | --- |
| `SkyCenter` | Направление на узел. |
| `NodeOffset` | Узел относительно камеры, в блоках. |
| `EffectTime` | Секунды с запуска эффекта. |
| `InvViewProjMat` | Обратная матрица вида-проекции, нужна `sky.vsh`. |

`hollowengine:sky_strike` - законченный пример: кольцо ударной волны и звёзды на небе.

## Тряска камеры

Узел **Тряска камеры** трясёт камеру всех, кто видит эффект.

| Настройка | Значение |
| --- | --- |
| **Сила** | Умножает размах. Сюда стоит положить спад по расстоянию, например `1 - n.camera_distance / 24`. |
| **Частота** | Тряск в секунду. |
| **Размах** | Наибольший размах в градусах по тангажу, рысканью и крену. |

## Написание core-шейдера

Шейдеры экрана, неба и поверхностей - обычные core-шейдеры Minecraft: `.json` рядом с вершинным и фрагментным шейдерами в `assets/<namespace>/shaders/core/`. Для своего проекта кладите их в `hollowengine/assets/project/shaders/core/` и пишите в поле `project:`. После изменения шейдера перезагрузите ресурсы через `F3 + T`.

Объявленные в json uniform'ы и сэмплеры появляются в секциях **Uniform'ы** и **Текстуры** узла со значениями по умолчанию из json. Json ищется при каждой загрузке эффекта, а отсутствующий файл отмечается в Инспекторе.

Что получает каждый вид узла:

| Узел | Атрибуты | Сэмплеры |
| --- | --- | --- |
| Эффект экрана | `Position`, `UV0` | `SceneColor`, `SceneDepth`; `ScreenSize` - размер кадра |
| Небо | `Position` | по умолчанию нет; uniform'ы выше задаёт движок |
| Плоскость | `Position`, `UV0`, `InstanceCenter`, `InstanceRight`, `InstanceUp`, `InstanceColor`, `InstanceUv`, `InstanceLight`, `InstanceBlend`, `InstanceMaterial` | `Sampler0`, `Sampler2`, `SceneColor`, `SceneDepth` |
| Куб, Сфера, Цилиндр, Модель | `Position`, `UV0`, `Normal`, `InstanceX`, `InstanceY`, `InstanceZ`, `InstanceOrigin`, `InstanceColor`, `InstanceUv`, `InstanceLight` | как у Плоскости |
| Шлейф, Луч | ванильный формат частиц: `Position`, `UV0`, `Color`, `UV2` | как у Плоскости |

Шейдеры мешей и лент получают **Мягкое пересечение** и **Свечение** материала в uniform'ах `Softness` и `Glow`. Подключите `hollowengine_vfx.glsl` через `#moj_import <hollowengine_vfx.glsl>`, чтобы получить `hollowengine_soft_fade` - он считает коэффициент мягкого пересечения.

Чтобы свой шейдер светился, объявите `GlowPass` в его json и используйте `Glow`. Шейдер без этого в проходе свечения не участвует.

:::advice
Если только вам не нужен шейдер, которого граф не выразит, предпочитайте [граф материала](/docs/hollowengine/vfx/material-graph). Он сам берёт на себя атрибуты, инстансинг и свечение.
:::
