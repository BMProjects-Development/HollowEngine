<center><h1>Визуальные эффекты (VFX)</h1></center>

*Частицы, шлейфы, лучи, экранные эффекты, небо и тряска камеры в одном редактируемом файле.*

VFX-эффект хранится в файле `.vfx` и собирается из дерева узлов. Один эффект может сочетать частицы, геометрические поверхности, шлейфы, лучи, экранные эффекты, небо и тряску камеры. Встроенный редактор открывает `.vfx` как отдельный документ IDE.

## Создание и размещение файла

Создайте пустой файл `hollowengine/assets/project/vfx/sparks.vfx` через пункт **New File** в контекстном меню панели **Проект** или в проводнике. Пустой `.vfx` открывается как новый эффект; редактор запишет его структуру при сохранении.

Откройте файл двойным щелчком в дереве проекта. В окне **Сцена** щёлкните правой кнопкой по корню эффекта и выберите **Добавить узел**. Начните с **Эмиттера**: он создаётся с дочерней плоскостью, которая рисует его частицы. Настраивайте выбранный узел в **Инспекторе**, а ключи анимации в окне **Таймлайн**. Окна **Сцена**, **Инспектор** и **Таймлайн** можно открыть через меню **Окна**.

Эффект доступен как ресурс `project:vfx/sparks.vfx`. При запуске можно также написать сокращённое имя `project:sparks`. После изменения ресурса используйте **Файл > Перезагрузить клиентские ресурсы** или `F3 + T`, чтобы обновить эффект в игре. Редактор сам сохраняет изменённый `.vfx` после короткой паузы; `Ctrl + S` сохраняет сразу.

## Типы узлов

| Узел | Назначение |
| --- | --- |
| Группа | Объединяет дочерние узлы под одной трансформацией. |
| Эмиттер | Создаёт и симулирует частицы; дочерние узлы рисуют каждую из них. |
| Плоскость, Куб, Сфера, Цилиндр | Рисуют плоский спрайт или примитивный меш. |
| Модель | Рисует модель, при желании с анимацией. |
| Шлейф, Луч | Рисуют ленту за движущимся узлом или луч между двумя точками. |
| Эффект экрана | Рисует шейдер на весь экран поверх кадра. |
| Небо | Рисует шейдер только на небе. |
| Тряска камеры | Трясёт камеру тех, кто видит эффект. |
| Декаль | Проецирует изображение или видео на поверхности; см. [Декали](/docs/hollowengine/world/decals). |
| Звук | Воспроизводит аудио в позиции узла; громкость и высота тона принимают выражения и ключи. См. [Звуки](/docs/hollowengine/scripting/sounds). |

У каждого узла есть название, переключатель «Включён» и трансформация (позиция, поворот, масштаб) относительно родителя. Выключенные узлы и их дети пропускаются.

### Кто что рисует

Эмиттер только симулирует частицы. То, что вы видите, рисуют рендереры под ним:

- Рендерер, лежащий **прямо** под эмиттером, рисуется на каждой частице. Его собственное размещение прибавляется к каждой частице, а размер, поворот и цвет берутся из секции **Партикл** этого рендерера.
- Рендерер в любом другом месте рисуется один раз там, где стоит. Положите его в группу, чтобы нарисовать, например, статичную сферу или луч.

У одного эмиттера может быть несколько рендереров, например мягкая плоскость свечения и резкое ядро. У каждого свой вид.

## Встроенные примеры

С HollowEngine поставляется несколько эффектов, которые можно открыть, запустить и скопировать в свой проект:

| Эффект | Что показывает |
| --- | --- |
| `hollowengine:example` | Минимальная пара эмиттеров с силой и шумом. |
| `hollowengine:explosion` | Эмиттеры, шлейф, ударная волна из сферы и экранный эффект. |
| `hollowengine:fireworks` | Эмиттер ракеты с саб-эмиттером, который взрывается при смерти. |
| `hollowengine:lightning` | Лучи, шлейф и экранный эффект. |
| `hollowengine:magic_shield` | Вложенные группы плоскостей, шлейфов и сфера. |
| `hollowengine:soul` | Модель, шлейф и экранный эффект. |
| `hollowengine:sky_strike` | Шейдер неба, лучи и тряска камеры. |

Запустить любой можно так: `/he vfx ~ ~1 ~ hollowengine:fireworks`.

:::advice
Формат эффектов ещё не финальный. Файлы меняются между версиями HollowEngine без миграций, поэтому после обновления движка перепроверяйте свои эффекты.
:::
