<center><h1>Значения, кривые и выражения</h1></center>

Сделайте размер частицы случайным, меняйте её цвет со временем или вычисляйте скорость по формуле. Числовое поле VFX позволяет выбрать подходящий способ задания значения.

Большинство числовых полей редактора VFX хранят **значение**. Небольшой переключатель на поле меняет его вид:

| Вид | Значение |
| --- | --- |
| **Число** | Константа. |
| **Диапазон** | Случайное число между двумя границами. |
| **Кривая** | Кривая, которую читает источник, например прогресс частицы. |
| **Выражение** | Формула на языке выражений. |

Цвет дополнительно может быть **Один цвет**, **Градиент** с точками или **По каналам** - кривые красного, зелёного, синего и альфы.

## Кривые

Нажмите на поле кривой, чтобы открыть редактор кривой. Добавляйте и перетаскивайте ключи, а пресеты (**Затухание**, **Нарастание**, **Ровно**, **Множитель**) используйте как отправную точку.

Кривая читает **источник**:

| Источник | Идёт от |
| --- | --- |
| **По времени жизни** | `0` при рождении до `1` при смерти. |
| **Возраст, с** | Возраст частицы в секундах. |
| **Возраст эмиттера, с** | Секунды с запуска эмиттера. |
| **Время эффекта, с** | Секунды с запуска эффекта. |
| **Скорость** | Текущая скорость частицы. |
| **Случайно для партикла** | Число, неизменное всю жизнь частицы. |
| **Случайное число родителя** | Случайное число родительской частицы внутри саб-эмиттера. Вне него `0`. |

Так частица может уменьшаться к концу жизни без ключей на Таймлайне. Дорожки Таймлайна нужны, чтобы анимировать свойства узла по времени эффекта.

## Выражения

Выражения используют тот же язык, что анимации и условия диалогов, с переменными, специфичными для эффектов:

| Префикс | Переменные |
| --- | --- |
| `p.` (`particle`) | `age`, `lifetime`, `progress` (или `t`), `x`, `y`, `z`, `velocity_x`/`velocity_y`/`velocity_z` (или `vx`, `vy`, `vz`), `speed`, `random`, `index`, `parent_random` |
| `e.` (`emitter`) | `age`, `count`, `time`, `partial_tick`, `game_time`, `random` |
| `n.` (`node`) | `camera_distance` |
| `d.` (`data`) | Значения, отправленные работающему эффекту из скрипта; см. [Запуск эффектов](/docs/hollowengine/vfx/playback#passing-data-to-an-effect). |
| `math.` | Математические функции. Внутри выражения префикс можно опустить. |

Отсутствующее значение `d.` читается как `0`.

```text
p.progress * 2                  вдвое больше к концу жизни
1 - n.camera_distance / 24      гаснет с расстоянием до камеры
sin(p.age * 360) * 0.2          колеблется раз в секунду
d.charge * 4                    управляется скриптом
```

:::advice
`sin`, `cos` и `tan` принимают **градусы**, как в Molang. `cos(6.28 * x)` близок к `1` при любом `x`; пишите `cos(360 * x)`.
:::

### Какие часы использовать

- `p.progress` и `p.age` идут для каждой частицы. На узле, который не является частицей, `p.age` - время Таймлайна, повторяющееся на каждом цикле эффекта.
- `e.time` - время с запуска эффекта, оно **не** сбрасывается при повторе эффекта. Для повторяющегося рисунка на зацикленном эффекте используйте `p.age`.
- `e.game_time` и `e.partial_tick` следуют мировым часам.

Поле выражения подсказывает об ошибках по мере ввода. Выражение, которое нельзя прочитать, считается равным `0`.
