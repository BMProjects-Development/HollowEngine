<center><h1>Знакомство с HollowEngine</h1></center>

**Разбираемся, как создать свои первые скрипты в HollowEngine.**

## Установка и запуск

Скачайте HollowEngine и [аддон компилятора Kotlin](/docs/hollowengine/addons/compiler) из одного [релиза проекта](https://github.com/HollowHorizon/HollowEngine/releases). Выберите файлы для вашей версии Minecraft и положите оба `.jar` в папку `mods`. Компилятор нужен, чтобы писать и изменять скрипты.

Готовый проект может работать без компилятора, если при [экспорте](/docs/hollowengine/project-export) в него включены скомпилированные скрипты. Сам HollowEngine по-прежнему нужен.

Скачав мод и запустив игру, нажмите логотип HollowEngine в левом верхнем углу экрана. Он откроет рабочее пространство IDE с четырьмя меню:

- Файл: Раздел с полезными функциями - открытие папки мода, перезагрузки клиентских и серверных ресурсов.
- Окна: Раздел с разными окнами движка, здесь уже лежит основной функционал движка - файлы проекта, катсцены, редакторы и т.п.
- Инструменты: Режим редактора, трансформации, UI-профилировщик и масштаб интерфейса.
- Помощь: Раздел с полезной информацией вроде ссылок на сообщество проекта или документацией.

![Рабочее пространство IDE HollowEngine](/hollowengine/pictures/ide/workspace.webp)

Подробнее про работу в редакторе расписано в разделе [Работа с IDE](/docs/hollowengine/ide). Если вам понадобится добавить свои ресурсы (модели, текстуры, звуки), обратите внимание на раздел с [ассетами](/docs/hollowengine/assets), там разобраны файлы проекта и то, как их указывать.

## Проверяем, работает ли компилятор?

Зайдя в мир, можем проверить, работает ли компилятор. Для этого откройте **Окна > Терминал**, перейдите на вкладку **Логи** и включите режим Kotlin-скриптов в строке ввода.
Введите код и нажмите кнопку запуска справа от строки ввода. Он отправит сообщение вашему игроку:

```kotlin
player?.let {
    it.sendSystemMessage("Привет, ${it.name.string}!".literal)
}
```

В главном меню игрока ещё нет, поэтому `player` равен `null` и сообщение не отправится. Для этой проверки войдите в мир.

![Первый скрипт](/hollowengine/pictures/guide/first-script.webp)

После компиляции в чате должно появиться ваше сообщение:

![Результат первого скрипта](/hollowengine/pictures/guide/first-script-result.webp)

При наличии проблем, напишите в [Telegram](https://t.me/hollowengine_community) приложив логи (файл `logs/latest.log`) или скриншот ошибки.

## Создаём и настраиваем первого NPC

Самый простой способ создать NPC - использовать **Инструмент Разработчика**, посмотрите вкладку мода в креативе.
На правую кнопку мыши он создаёт NPC. После чего можно также нажать ПКМ по NPC, чтобы перейти к его редактированию. (Кроме того, на Shift + ПКМ по воздуху можно аналогично настроить ещё самого себя 👀)

![Первый NPC](/hollowengine/pictures/guide/first-npc.webp)

Там можно настроить его имя, параметры, атрибуты, модель, скрипты и многое другое.

## Создаём скрипт и привязываем его к NPC

Создадим простой скрипт, который сделает, чтобы NPC нападал на игрока, когда игрок подходит близко.

В дереве **Проект** создайте папку `scripts/examples`, затем через её контекстное меню создайте [скрипт-ноду](/docs/hollowengine/scripting/node) `guard.node.kts`. Полный путь от папки игры: `hollowengine/scripts/examples/guard.node.kts`.

![Скрипт-нода](/hollowengine/pictures/guide/node-script.webp)

Изначально такая нода прикрепляется к серверу и запускается вместе с ним (после прикрепления командой). Нам нужно, чтобы нода имела доступ к NPC и прикреплялась к нему.
Укажите в начале файла, к кому прикрепляется скрипт:

```kotlin
@file:Attach(NpcEntity::class)
```

![NPC-нода](/hollowengine/pictures/guide/npc-node.webp)

Теперь напишем сам скрипт:

```kotlin
@file:Attach(NpcEntity::class)

val npc = this@NpcEntity
val radius by editor.property("Радиус атаки", min = 1.0, max = 32.0) { 10 }
val goBack by editor.property("Вернуться назад?") { true }
var startPos = Vec3.ZERO

onStart {
    startPos = npc.position()
}

onUpdate(every = 20.ticks) {
    val target = npc.level().players()
        .filter { it.isAlive && !it.isSpectator && !it.abilities.instabuild }
        .filter { npc.distanceTo(it) < radius }
        .minByOrNull { it.distanceTo(npc) }

    npc.setTarget(target)
    if (target == null) {
        if (goBack) {
            npc.navigation.moveTo(startPos.x, startPos.y, startPos.z, 1.0)
        } else {
            npc.navigation.stop()
        }
    }
}
```

`NpcEntity`, `Vec3`, `onStart`, `onUpdate` и `.ticks` импортируются в node-скриптах автоматически. `this@NpcEntity` - сущность, к которой вы прикрепили файл. Раз в секунду скрипт выбирает ближайшего живого игрока в радиусе; творческий режим и наблюдатели пропускаются. Если подходящего игрока нет, цель атаки сбрасывается и NPC возвращается к месту запуска. После перезагрузки ноды это место берётся заново.

После чего его можно прикрепить к уже созданному NPC. Для этого в его редакторе перейдите в раздел скриптов и найдите там ранее созданный:

![Прикрепляем скрипт](/hollowengine/pictures/guide/attach-script.webp)

При первом прикреплении дождитесь компиляции. После неё в редакторе появятся параметры **Радиус атаки** и **Вернуться назад?**. Измените радиус и проверьте, на каком расстоянии NPC замечает игрока.

![Прикрепили скрипт](/hollowengine/pictures/guide/attached-script.webp)

:::warning
В выживании NPC нападёт, как только вы войдёте в радиус. Настройте его в творческом режиме, затем переключитесь в выживание для проверки.
:::

## Создаём диалог при взаимодействии

Создайте `hollowengine/scripts/examples/npc_dialogue.node.kts`. Он будет запускать диалог по ПКМ. Для спокойной проверки открепите `guard.node.kts` от этого NPC или используйте другого персонажа.

```kotlin
// Говорим, что этот скрипт прикрепляется к NPC
@file:Attach(NpcEntity::class)

import net.minecraft.server.level.ServerPlayer

// Указываем название и описание для редактора
editor.name("Диалог при взаимодействии")
editor.description("ПКМ по нпс воспроизводит диалог.")

// Создаём ещё несколько параметров для редактора.
// Здесь мы указываем `assets = listOf("story")`, чтобы в редакторе появилась возможность выбрать любые `.story` скрипты.
// `restart=true` перезапускает скрипт при изменении, иначе эта переменная обновится, а переменная `dialogue` - нет (см. ниже)
val story by editor.property<String>("Файл истории", assets = listOf("story"), restart = true) {
    "scripts/examples/npc_dialogue.story"
}
val speaker by editor.property<String>("Имя NPC в скрипте самой истории", restart = true) { "Guide" }
val fromTheStart by editor.property<Boolean>("Всегда запускать сначала?") { true }

val npc = this@NpcEntity
// Создаём контроллер диалога, он общий для всех игроков, если нужен индивидуальный - используй HashMap
// Путь, указываемый в редакторе, начинается с папки `scripts`, а контроллер диалога принимает уже относительно этой папки, так что убираем лишнее
val dialogue = DialogueController(story.removePrefix("scripts/"))

onInteract { event ->
    if (dialogue.isRunning) return@onInteract
    // Получаем серверного игрока
    val player = event.player as? ServerPlayer ?: return@onInteract
    // Если в настройках указано начинать диалог всегда заново (например, если игрок умер во время диалога), то сбрасываем этот диалог
    if (fromTheStart) dialogue.reset()
    dialogue.start(player) {
        // Добавляем персонажа, нашего NPC. По умолчанию это Guide
        character(speaker, DialogueCharacter.of(npc))
        // Можем добавить переменную, которую можно использовать в истории, например, имя игрока:
        put("name", player.name.string)
    }
}

// При сохранении NPC записываем в файл его сущности текущий прогресс диалога
onSave { context -> dialogue.save("dialogue", context.tag) }
onLoad { context -> dialogue.load("dialogue", context.tag) }
```

Контроллер общий для этого NPC: пока разговор идёт, повторный ПКМ ничего не запускает. Если несколько игроков должны разговаривать независимо, каждому нужен свой контроллер и отдельное сохранение прогресса; подробнее в [контроллерах диалогов](/docs/hollowengine/dialogues/controllers).

Создайте рядом `hollowengine/scripts/examples/npc_dialogue.story` и вставьте текст:

```story
// Пример диалога для scripts/examples/npc_dialogue.node.kts.

# Start

Guide: Привет, {name}! Я NPC управляемый скриптом через диалог.
Guide: Хочешь узнать, как я работаю?

@choice "Да, расскажи мне"
    Guide: Мой скрипт, npc_dialogue.node.kts, слушает <b>onInteract</b> и начинает эту историю.
    Guide: Всё, что я пишу есть в файле <wave>npc_dialogue.story</wave>, рядом с этим же скриптом.
@choice "Может потом"
    Guide: Хорошо, возвращайся, когда будет время.
```

В папке проекта должны получиться эти файлы:

```text
hollowengine/scripts/examples/
├─ guard.node.kts
├─ npc_dialogue.node.kts
└─ npc_dialogue.story
```
