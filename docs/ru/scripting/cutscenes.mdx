## Создание катсцены

1. Открой **Windows > Cutscenes** и создай новую катсцену.
2. Поставь начало координат сцены (раздел **Начало координат**) - проще всего кнопкой **Перенести сюда**.
3. Добавь ключевые кадры кнопкой записи: движок запишет текущую позу камеры, время суток и погоду в активный слой каждого свойства.
4. Задай длительность и проверь сцену в предпросмотре таймлайна.
5. Сохрани катсцену. Например, `intro` будет записана в `hollowengine/cutscenes/intro.dat`.
6. Запусти её для игрока из серверного скрипта.

Дорожки вычисляются на клиенте получившего игрока. Пока активна катсцена, движок может локально
управлять камерой, HUD, отрисовкой руки, временем суток и погодой. Серверный мир не меняется, а после
остановки катсцены или предпросмотра прежние время и погода клиента восстанавливаются.

## Что лежит в файле?

Все координаты хранятся **относительно начала координат** сцены. 
Файл описывает *форму* движения; куда её поставить, решает скрипт при запуске.

Поля начала координат двигают всю сцену. Кнопка **Перепривязать** делает обратное: сцена остаётся на
месте, меняются только числа, относительно которых она записана.

Катсцены старого формата переносятся при загрузке: начало координат ставится в первый ключ позиции,
ключи пересчитываются относительно него, а старые функции плавности превращаются в кривые. Картинка
при этом не меняется.

## Объекты, свойства и слои

Таймлайн анимирует **свойства**. У камеры это `Transform` (Translation, Rotation) и `Lens` (FOV),
а в `World / Environment` находятся время суток и погода. Каждое свойство раскладывается на
**каналы**, и у каждого канала свои ключи: X можно двигать и сглаживать, не задевая Y и Z.

Время суток является непрерывным значением в 24 000 игровых тиков. Если в режиме кривых выбрана
только эта дорожка, шкала значений показывается в 24-часовом формате. Погода дискретна (`Ясно`,
`Дождь`, `Гроза`): она меняется строго на ключе и намеренно не показывается в редакторе кривых.

У свойства может быть несколько **слоёв**. Слой - это полный набор кривых плюс то, как он ложится на
слои под собой:

| Смешивание | Что делает |
| --- | --- |
| **Перезапись** | Заменяет значение снизу. Первый слой всегда такой - под ним ничего нет. |
| **Сложение** | Прибавляет: тряска, отклонения, поправки. |
| **Вычитание** | Обратное сложению. |
| **Умножение** | Масштабирует; предлагается только там, где это будет полезно, например фильтры и эффекты. |

Кнопка `+` на строке свойства добавляет слой и открывает его настройки: имя, режим смешивания, вес,
видимость и блокировку. Шестерёнка на строке свойства открывает настройки самого свойства -
**ограничения** (минимум и максимум по каждому каналу, которыми зажимается итог после всех слоёв) и
представление поворота. Клик по строке слоя делает его активным: именно туда пишет запись позы.

Скрытие слоя, канала или целой группы убирает влияение на результат - предпросмотр сразу это
показывает.

### Поворот: Эйлер или кватернион

Поворот хранится **углами** (Pitch/Yaw/Roll в градусах). Это важно: кватернион не помнит, как в него
пришли, поэтому камера, повёрнутая четыре раза по 90°, вернулась бы как 0/90/180/-90 да ещё с
выдуманным roll. Записанный угол считается дальше - 0, 90, 180, 270 - и кривая через шов ±180° не
идёт в обход. В настройках свойства можно переключиться на **кватернион** (X/Y/Z/W); переключение
пересчитывает кривые, направляющие сбрасываются.

## Кривые

Интерполяция - это **пресет кривой**. Пресет пишет реальные направляющие, которые потом можно настроить
руками; отдельного «режима плавности» больше нет. Кроме кубических пресетов есть **Удержание**
(значение держится до следующего ключа) и **Линейная**.

Пресеты доступны в инспекторе и по правому клику на ключе.

Направляющие хранятся **относительно своего ключа**, поэтому переезд ключа по времени и перепривязка
их не ломают. Режимы:

- **Авто** - считаются по соседним ключам и выпрямляются на экстремумах, так что камера не пролетает
  мимо своих же ключей;
- **Зеркальные** - противоположная повторяет и направление, и длину;
- **Связанные** - противоположная повторяет направление, сохраняя свою длину;
- **Свободные** - каждая сама по себе.

При перетаскивании направляющей по умолчанию работает зеркальный режим; `Shift` сохраняет длину
противоположной, `Ctrl` двигает только ту, за которую тянешь. Направляющая, смотрящая в прямой
сегмент, нарисована блёкло - как только её потянули, сегмент становится сплайном.

### Редактор кривых

Кнопки **Ключи / Кривые** на панели инструментов (или `Ctrl+Tab`) переключают режим.

- Ключевые кадры живут только на строках каналов: свойство и слой - это папки. Стрелки в списке
  раскрывают свойство на слои, а слой - на каналы; у каждого канала свой цвет и переключатель видимости.
- Колесо - прокрутка по времени, `Ctrl` + колесо - масштаб по времени, `Shift` + колесо - масштаб по
  значению, `Alt` + колесо - сдвиг по значению. Ось значений едет пружиной, а не рывком.
- Средняя **или правая** кнопка мыши - перетаскивание холста (по времени и по значению). Правая
  кнопка без движения открывает контекстное меню, так что одна кнопка делает и то, и другое.
- Левая кнопка по пустому месту - рамка выделения; `Ctrl` или `Shift` добавляют к выделенному.
- `Ctrl` + перетаскивание ключа клонирует выделение и тащит копии, оставляя оригиналы на месте.
- `Ctrl+C` / `Ctrl+X` / `Ctrl+V` - копировать, вырезать и вставить ключи. Вставка кладёт их на те же
  каналы, самый ранний - на позицию курсора времени, остальные сохраняют расстояния.
- `F` - вписать видимые кривые, `S` - сгладить выделение.
- Клик по строке в списке дорожек выбирает, **что показывает график**; `Ctrl` добавляет к выбору,
  повторный клик по тому же - снимает. Это отдельная вещь от глаза: скрытая дорожка пропадает и из
  превью, а разгрузить график этой ценой не должно быть нужно.
- Список дорожек слева тянется за разделитель и прокручивается, если названия не влезают.

## Запуск и остановка

```kotlin
player.playCutscene("intro")

// Повторяется, пока её не остановят.
player.playCutscene("ambient_pan", loop = true)

player.stopCutscene()
```

`playCutscene` заменяет текущую катсцену игрока. Используй путь относительно `hollowengine/cutscenes`; расширение `.dat` писать необязательно. `stopCutscene()` сразу возвращает обычную игровую камеру.

### Куда поставить сцену

```kotlin
// Вокруг позиции - например, угла структуры. yaw разворачивает сцену целиком.
player.playCutsceneAt("chapter_1/arrival", structurePos, yaw = 90f)

// Вокруг НПС; сцена едет за ним, пока он идёт.
player.playCutsceneNear("chapter_1/greeting", npc, follow = true)

// Вокруг самого игрока, где бы он ни стоял.
player.playCutsceneHere("ambient_pan", loop = true)
```

`rotate = false` оставит сцене её записанный разворот и только перенесёт её. Если сущность не найдена,
катсцена играет там, где была записана.

## Простой триггер сцены

```kotlin
@State
suspend fun onInteract(player: ServerPlayer) {
    player.playCutscene("chapter_1/arrival")
    player.send("Добро пожаловать в долину.")
}
```

Для зацикленной камеры в зоне запусти её при входе игрока и вызови `stopCutscene()` при выходе. Не запускай одну и ту же катсцену каждый тик: достаточно одного вызова.
