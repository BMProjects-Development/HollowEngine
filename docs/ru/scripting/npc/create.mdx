<center><h1>Создание NPC</h1></center>

*Актуальная сигнатура и поведение функции `npc()` в Kotlin-архитектуре v2.3.*

---

## `npc()`

Функция `npc()` создаёт `NpcEntity`, добавляет его в мир и сразу назначает базовые компоненты модели, хитбокса и анимаций.

```kotlin
val guide = npc(
    pos = pos(10, 64, 10),
    name = "Guide",
)
```

## Сигнатура

```kotlin
fun npc(
    pos: Vec3,
    name: String = "NPC",
    model: String = "hollowengine:models/entity/player_model.gltf",
    rotation: Vec2 = rotation(0, 0),
    world: String = "minecraft:overworld",
    size: Pair<Float, Float> = 0.6f to 1.8f,
    attributes: Map<String, Float> = emptyMap(),
    textures: Map<String, String> = emptyMap(),
    transform: Transform = Transform(),
    nameplateMode: NameplateMode = NameplateMode.SHOW,
    inverseHeadRotation: Boolean = false,
    inventorySize: Int = NpcInventory.DEFAULT_SIZE,
): NpcEntity
```

| Параметр | Тип | По умолчанию | Назначение |
|----------|-----|--------------|------------|
| `pos` | `Vec3` | — | Позиция появления NPC. |
| `name` | `String` | `"NPC"` | Имя над головой NPC. |
| `model` | `String` | `"hollowengine:models/entity/player_model.gltf"` | Resource location `.gltf` модели. |
| `rotation` | `Vec2` | `rotation(0, 0)` | Начальный yaw/pitch. |
| `world` | `String` | `"minecraft:overworld"` | ID измерения, куда будет добавлен NPC. |
| `size` | `Pair<Float, Float>` | `0.6f to 1.8f` | Ширина/высота хитбокса. В v2.3 параметр есть в сигнатуре, но для точной настройки лучше использовать компоненты. |
| `attributes` | `Map<String, Float>` | `emptyMap()` | Базовые значения атрибутов через registry id. |
| `textures` | `Map<String, String>` | `emptyMap()` | Карта текстур по слоям/материалам. В v2.3 низкоуровневая настройка текстур всё ещё лучше делается через компоненты/модель. |
| `transform` | `Transform` | `Transform()` | Локальная трансформация модели. В v2.3 не стоит полагаться на него как на стабильный публичный способ настройки. |
| `nameplateMode` | `NameplateMode` | `NameplateMode.SHOW` | Начальный режим отображения неймплейта. |
| `inverseHeadRotation` | `Boolean` | `false` | Зарезервировано для особенностей поворота головы/модели. |
| `inventorySize` | `Int` | `36` | Количество слотов в [`npc.inventory`](/docs/hollowengine/scripting/npc/inventory). Можно изменить позже через `npc.inventory.resize(...)`. |

:::caution
Часть параметров уже присутствует в сигнатуре, но ещё не является полноценным стабильным пользовательским API. В v2.3 надёжно применяются позиция, поворот, мир, модель, имя, `nameplateMode`, атрибуты, базовый хитбокс и стандартный аниматор. Для тонкой настройки модели, текстур, анимаций и хитбокса лучше явно назначать компоненты.
:::

## Помощники `pos()` и `rotation()`

```kotlin
val blockCenter = pos(10, 64, 10)      // Vec3(10.5, 64.0, 10.5)
val exactPos = pos(10.0, 64.0, 10.0)  // Vec3(10.0, 64.0, 10.0)

val rot = rotation(90, 0)
```

`pos(Int, Int, Int)` добавляет `0.5` к X/Z, чтобы NPC появился в центре блока.
`pos(Double, Double, Double)` использует точные координаты.

## Примеры

### Минимальный NPC

```kotlin
@State
suspend fun main() {
    val npc = npc(pos(0, 64, 0))
    npc.say("Hello!")
}
```

### Своя модель и мир

```kotlin
@State
suspend fun main() {
    val trader = npc(
        pos = pos(120.0, 70.0, -32.0),
        name = "Trader",
        model = "my_mod:models/entity/trader.gltf",
        rotation = rotation(180, 0),
        world = "minecraft:overworld",
    )
}
```

### Атрибуты

```kotlin
val guard = npc(
    pos = pos(0, 64, 0),
    name = "Guard",
    attributes = mapOf(
        "minecraft:generic.max_health" to 40f,
        "minecraft:generic.movement_speed" to 0.25f,
        "minecraft:generic.attack_damage" to 6f,
    ),
)
```

Названия атрибутов должны совпадать с registry id атрибутов в текущей версии Minecraft/NeoForge.

## Что назначается автоматически

После создания NPC получает:

- `Model(model)` — компонент модели;
- `HitboxComponent(HitboxMode.PULLING)` — стандартное поведение хитбокса;
- `StandardPlayerAnimatorPreset.create()` — стандартную player-like locomotion анимацию;
- `TransformComponent(...)` — базовую трансформацию модели;
- `customName` и `isCustomNameVisible`;
- саму сущность в выбранном мире через `level.addFreshEntity(...)`.

Это значит, что обычный NPC уже умеет стоять, ходить и поворачивать голову без ручной настройки аниматора.
