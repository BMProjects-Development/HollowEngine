<center><h1>Создание NPC</h1></center>

Создадим NPC, а затем разберём, как задать ему имя, модель, измерение и другие настройки.

---

Примеры используют серверный `.node.kts`: функции `npc`, `pos` и `rotation`, а также `@State` уже импортированы. Для полного примера с `main` создайте файл `hollowengine/scripts/examples/create_npc.node.kts` и запустите `/he scripting run scripts/examples/create_npc.node.kts main`. Координаты замените на точку с опорой под ногами в загруженном чанке.

## `npc()`

Функция `npc()` создаёт сущность `NpcEntity` в выбранном мире и назначает ей модель. Если передать `id` уже существующего живого NPC, функция вернёт его, сохранив прежние настройки.

```kotlin
val guide = npc(
    pos = pos(10, 64, 10),
    name = "Guide",
)
```

## Сигнатура

```kotlin
fun npc(
    pos: Vec3,
    name: String = "NPC",
    model: String = "hollowengine:models/entity/player_model.gltf",
    rotation: Vec2 = rotation(0, 0),
    world: String = "minecraft:overworld",
    attributes: Map<String, Float> = emptyMap(),
    transform: TrsTransformF = TrsTransformF(),
    nameplateMode: NameplateMode = NameplateMode.SHOW,
    inverseHeadRotation: Boolean = false,
    inventorySize: Int = NpcInventory.DEFAULT_SIZE,
    id: String? = null,
): NpcEntity
```

| Параметр              | Тип                  | По умолчанию                                     | Назначение                                                                                                                                 |
|-----------------------|----------------------|--------------------------------------------------|--------------------------------------------------------------------------------------------------------------------------------------------|
| `pos`                 | `Vec3`               | Отсутствует                                      | Позиция появления NPC.                                                                                                                     |
| `name`                | `String`             | `"NPC"`                                          | Имя над головой NPC.                                                                                                                       |
| `model`               | `String`             | `"hollowengine:models/entity/player_model.gltf"` | Resource location `.gltf` модели.                                                                                                          |
| `rotation`            | `Vec2`               | `rotation(0, 0)`                                 | Начальный yaw/pitch.                                                                                                                       |
| `world`               | `String`             | `"minecraft:overworld"`                          | ID измерения, куда будет добавлен NPC.                                                                                                     |
| `attributes`          | `Map<String, Float>` | `emptyMap()`                                     | Базовые значения атрибутов через registry id.                                                                                              |
| `transform`           | `TrsTransformF`      | `TrsTransformF()`                                | Сдвиг, поворот и масштаб модели относительно NPC; передаются в `TransformComponent`.                           |
| `nameplateMode`       | `NameplateMode`      | `NameplateMode.SHOW`                             | Начальный режим отображения неймплейта.                                                                                                    |
| `inverseHeadRotation` | `Boolean`            | `false`                                          | В текущей реализации не применяется. Настройку поворота головы задавайте в метаданных модели.                                                                                   |
| `inventorySize`       | `Int`                | `36`                                             | Количество слотов в [`npc.inventory`](/docs/hollowengine/scripting/npc/inventory). Можно изменить позже через `npc.inventory.resize(...)`. |
| `id` | `String?` | `null` | Собственный id NPC, например `"village:blacksmith"`. Если живой NPC с таким id уже есть, `npc()` возвращает его и игнорирует остальные аргументы, см. [NPC вне мира](/docs/hollowengine/scripting/npc/registry#ids-one-npc-per-name). |

:::warning
Параметр `inverseHeadRotation` пока не применяется. `transform` передаётся в компонент `TransformComponent`. Аниматор и поворот головы определяются метаданными выбранной модели, поэтому своя модель должна быть настроена отдельно. То, как NPC толкает и блокирует других, задаёт компонент [Тело](/docs/hollowengine/world/colliders#the-body-of-an-entity).
:::

## Помощники `pos()` и `rotation()`

```kotlin
val blockCenter = pos(10, 64, 10)      // Vec3(10.5, 64.0, 10.5)
val exactPos = pos(10.0, 64.0, 10.0)  // Vec3(10.0, 64.0, 10.0)

val rot = rotation(90, 0)
```

`pos(Int, Int, Int)` добавляет `0.5` к X/Z, чтобы NPC появился в центре блока.
`pos(Double, Double, Double)` использует точные координаты.

## Примеры

### Минимальный NPC

```kotlin
@State
suspend fun main() {
    val npc = npc(pos(0, 64, 0))
    npc.say("Hello!")
}
```

### Своя модель и мир

Для этого примера подготовьте модель `hollowengine/assets/project/models/entity/trader.gltf` и её текстуры. Идентификатор `project:models/entity/trader.gltf` указывает на этот файл. Выберите существующее измерение; пример использует обычный мир. Если своего ресурса пока нет, оставьте встроенную модель по умолчанию.

```kotlin
@State
suspend fun main() {
    val trader = npc(
        pos = pos(120.0, 70.0, -32.0),
        name = "Trader",
        model = "project:models/entity/trader.gltf",
        rotation = rotation(180, 0),
        world = "minecraft:overworld",
    )
}
```

### Атрибуты

```kotlin
val guard = npc(
    pos = pos(0, 64, 0),
    name = "Guard",
    attributes = mapOf(
        "minecraft:generic.max_health" to 40f,
        "minecraft:generic.movement_speed" to 0.25f,
        "minecraft:generic.attack_damage" to 6f,
    ),
)
```

Названия атрибутов должны совпадать с registry id атрибутов в текущей версии Minecraft/NeoForge.

Отдельному NPC можно добавить любой зарегистрированный атрибут, в том числе отсутствующий в стандартном наборе его типа сущности. Добавленные атрибуты и их постоянные модификаторы сохраняются вместе с NPC. В редакторе выбор атрибутов поддерживает поиск по названию и registry ID: добавленные атрибуты можно удалить, а обязательные - сбросить к стандартным значениям типа.

## Что назначается автоматически

После создания NPC получает:

- `Model(model)` - компонент модели;
- аниматор выбранной модели из её `.hemeta`; у встроенной модели это `hollowengine:standard_player` для покоя и ходьбы;
- `TransformComponent(...)` - базовую трансформацию модели;
- `customName` и `isCustomNameVisible`;
- запись в [реестре NPC](/docs/hollowengine/scripting/npc/registry) и тело в выбранном мире.

Это значит, что обычный NPC уже умеет стоять, ходить и поворачивать голову без ручной настройки аниматора.
