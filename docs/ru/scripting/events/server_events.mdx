<center><h1>Сервер и тики</h1></center>

Запустите логику при старте и остановке сервера или выполняйте действие каждый тик. Такие обработчики подходят для общих систем мира.

Это отдельные примеры обработчиков для `.reload.kts`. Добавьте нужные импорты в начало своего файла. Для событий клиента поставьте `@file:ClientSide` перед импортами; серверные и клиентские обработчики держите в разных файлах.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.server.ServerEvent
import ru.hollowhorizon.hollowengine.common.events.tick.TickEvent
```

## Жизненный цикл

Если вам нужно выполнить действие при запуске или остановке сервера, то вам помогут следующие события:

### При запуске

**Сторона:** сервер

```kotlin
@SubscribeEvent
fun onServerStart(event: ServerEvent.Starting) {
    val server = event.server
}
```

:::advice
Серверный `.reload.kts` запускается раньше самого сервера, поэтому при открытии мира это событие до него дойдёт. А вот после `/reload` сервер уже работает, и событие повторно не сработает.
:::

### При остановке

**Сторона:** сервер

```kotlin
@SubscribeEvent
fun onServerStop(event: ServerEvent.Stoping) {
    val server = event.server
}
```

## Тики

### Тик сервера

**Сторона:** сервер

Если вам нужно выполнять действие каждый тик сервера (20 тиков в секунду), то вам подойдёт событие `TickEvent.Server`:

```kotlin
@SubscribeEvent
fun onServerTick(event: TickEvent.Server) {
    val server = event.server
}
```

:::advice
Если вам нужно выполнять действие каждые `X` тиков вы можете создать простой счётчик:

```kotlin
var ticker = 0

@SubscribeEvent
fun onServerTick(event: TickEvent.Server) {
    if (ticker++ % 5 == 0) { // Каждые 5 тиков
        event.server.doSomething()
    }
}
```

:::

### Тик клиента

**Сторона:** клиент

То же самое для клиента игры: срабатывает 20 раз в секунду, даже в главном меню.

```kotlin
@file:ClientSide

@SubscribeEvent
fun onClientTick(event: TickEvent.Client) {
    val minecraft = event.minecraft
}
```

### Тик сущности

**Сторона:** обе стороны

Срабатывает каждый тик каждой живой сущности.

```kotlin
@SubscribeEvent
fun onEntityTick(event: TickEvent.Entity) {
    val entity = event.entity
}
```

- `event.entity` (LivingEntity) - обновляемая сущность.
