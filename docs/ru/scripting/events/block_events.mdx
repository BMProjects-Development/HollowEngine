<center><h1>Блоки</h1></center>

Отреагируйте на установку, разрушение или обновление блока. У отменяемых событий можно запретить действие, например защитить постройки от разрушения.

Это отдельные примеры обработчиков для `.reload.kts`. Добавьте нужные импорты в начало своего файла. Для событий клиента поставьте `@file:ClientSide` перед импортами; серверные и клиентские обработчики держите в разных файлах.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.blocks.BlockEvent
```

## Размещение

**Сторона:** обе стороны

*Это событие можно отменить (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockPlace(event: BlockEvent.Placed) {
    val block = event.state
}
```

- `event.state` (BlockState) - текущее состояние блока.
- `event.pos` (`BlockPos`) - координаты блока.
- `event.player` (Player) - игрок, поставивший блок.

## Ломание

**Сторона:** сервер

*Это событие можно отменить (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockBreak(event: BlockEvent.Break) {
    val block = event.state
}
```

- `event.state` (BlockState) - текущее состояние блока.
- `event.pos` (`BlockPos`) - координаты блока.
- `event.player` (Player) - игрок, сломавший блок.
- `event.level` (Level) - мир, где был сломан блок.

## Обновление

**Сторона:** сервер

*Это событие можно отменить (`event.isCanceled = true`).*

```kotlin
@SubscribeEvent
fun onBlockUpdate(event: BlockEvent.NeighborNotify) {
    val block = event.state
}
```

- `event.state` (BlockState) - текущее состояние блока.
- `event.pos` (`BlockPos`) - координаты блока.
- `event.directions` (`EnumSet<Direction>`) - список, со сторонами, которые были обновлены.
