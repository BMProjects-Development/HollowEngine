<center><h1>Миры</h1></center>

Выполните действие при сохранении или выгрузке измерения. Например, запишите данные своей системы перед остановкой мира.

Это отдельные примеры обработчиков для `.reload.kts`. Добавьте нужные импорты в начало своего файла. Для событий клиента поставьте `@file:ClientSide` перед импортами; серверные и клиентские обработчики держите в разных файлах.

```kotlin
import ru.hollowhorizon.hollowengine.common.events.level.LevelEvent
```

## Сохранение

**Сторона:** сервер

```kotlin
@SubscribeEvent
fun onSave(event: LevelEvent.Save) {
    val level = event.level
}
```

- `event.level` (Level) - сохраняемое измерение.

## Загрузка

**Сторона:** сервер

```kotlin
@SubscribeEvent
fun onLoad(event: LevelEvent.Load) {
    val level = event.level
}
```

- `event.level` (Level) - загружаемое измерение.
