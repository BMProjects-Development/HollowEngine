## Что модель приносит с собой

Файл модели - `.gltf`, `.glb`, Blockbench `.geo.json` или `.obj` - лежит в обычной структуре ассетов и указывается через resource location:

```kotlin
val guide = npc(
    pos = pos(10.0, 64.0, 10.0),
    model = "project:models/entity/guide.gltf",
)
```

Всё остальное, что движку нужно знать о модели, лежит рядом - в файле с тем же именем плюс `.hemeta`:

```text
assets/project/models/entity/
├─ guide.gltf
└─ guide.gltf.hemeta
```

`.hemeta` - это TOML конфиг. Все поля необязательные, а модель вообще без `.hemeta` работает ровно как раньше:

```toml
preload = true
frustum-culling = false
animation-controller = "project:models/entity/guide.animator"

[materials]
skin = "Body"
cape = "material_3"
```

| Поле | Описание |
|------|-------|
| `preload` | Загружает модель при загрузке ресурсов, а не когда её впервые используют. Полезно для частоиспользуемых моделей. По умолчанию выключено, чтобы не занимать ресурсы моделями, которые используются пару раз в сборке/карте. |
| `frustum-culling` | Разрешает отсекать модель за пределами камеры. По умолчанию включено. Установите `false`, если GPU-анимация через skinning или morph targets уводит вершины за рассчитанные границы модели. Отключает только frustum culling; distance culling сущности продолжает работать. |
| `animation-controller` | Аниматор, который модель носит по умолчанию, см. [Редактор аниматоров](/docs/hollowengine/scripting/animator-editor). |
| `[materials]` | Новые имена для материалов модели, см. ниже. |

## Имена материалов

Каждая поверхность модели - это материал: базовая текстура, карта нормалей, specular и цвет-множитель. Скрипты обращаются к ним **по имени**.

Имя приходит из файла модели. У материалов glTF есть имя, которое задал художник; безымянные становятся `material_0`, `material_1` и так далее, в порядке файла. У модели Blockbench `.geo.json` материал один, и он называется `texture`.

Работать с этим можно, но скрипту приходится знать, как именно экспортировали каждую модель. Секция `[materials]` снимает эту зависимость, переименовывая материалы при загрузке:

```toml
[materials]
skin = "material_0"
```

`skin` - новое имя, `"material_0"` - имя, которое у материала уже есть (в файлах модели). 
Есть уже несколько предопределённых имён:

| Имя | Смысл |
|-----|-------|
| `skin` | Основная текстура тела. Ей же отвечает собственный скин игрока. |
| `cape` | Плащ. Он же плащ игрока. |
| `elytra` | Текстура элитр. |

У встроенных моделей нпс уже есть `skin`, но нет `cape` и `elytra`. Но они есть у ванильной модели игрока, так что вы можете их поменять при необходимости.

## Переодевание сущности

`entity.materials` - это Map из имени материала в то, что на нём должно быть:

```kotlin
val guide = npc(pos(0, 64, 0), name = "Guide", model = "project:models/entity/guide.gltf")

guide.materials["skin"] = texture("project:textures/entity/guide_night.png")
guide.materials["skin"] = skin("Notch") // Скин игрока "Notch"
guide.materials["cape"] = cape("Notch") // Накидка игрока "Notch"

guide.materials.reset("skin") // вернуть текстуру из модели
guide.materials.clear() // вернуть модель целиком
```

### Источники

Значение - не путь к текстуре, а *источник*, описывающий, откуда берётся внешний вид:

| Источник | Что даёт |
|----------|----------|
| `texture(texture, normal, specular, color)` | Текстуры из ресурспака. Все аргументы, кроме первого, необязательные; `color` - это `#rrggbb` или `#aarrggbb`, он подкрашивает материал. |
| `skin(player)` | Скин игрока, по нику или uuid. |
| `cape(player)` | Его плащ. |
| `elytra(player)` | Его текстура элитр. |

```kotlin
guide.materials["skin"] = texture(
    texture = "project:textures/entity/guide.png",
    normal = "project:textures/entity/guide_n.png",
    color = "#ffddaa",
)
```

:::advice
`skin("Notch")` для игрока, которого сейчас нет на сервере, требует его загрузки в первый раз. Пока он скачивается, сущность носит дефолтный скин модели, поэтому в своих проектах лучше использовть готовые скины в ресурсах проекта, а не брать "Скины по нику".
:::

## Игроки

Скин игрока меняется точно так же вне зависимости от наличия кастомной модели. Если кастомной модели нет - меняется стандартная:

```kotlin
player.materials["skin"] = texture("project:textures/entity/disguise.png")
player.materials["cape"] = cape("Notch")
```

Форма скина (wide/slim) - **не** материал! Чтобы поменять тип скина можно использовать:

```kotlin
player.arms = PlayerArms.SLIM
player.arms = null
```
