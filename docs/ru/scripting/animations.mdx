## Откуда берётся анимация

Модель анимирует себя сама. Всё, что происходит без участия скрипта - ходьба, простой, поворот головы - описано **аниматором**, который модель называет в своём `.hemeta`:

```toml
animation-controller = "hollowengine:standard_player"
```

NPC, созданный через `npc()`, использует встроенную модель игрока, а та уже называет стандартный аниматор и процедурный поворот головы и глаз. Всё это работает само, писать ничего не нужно.

Скрипт добавляет сверху **клипы**: разовый жест, зацикленные анимации, позу, которую нужно удержать. Об этом и текущая страница. Про сам файл метаданных смотрите в разделе [Модели и материалы](/docs/hollowengine/scripting/models).

## Проигрывание клипа

Эти функции работают на любой `Entity`, не только на NPC, но для этого у этой сущности или игрока должна быть модель.

```kotlin
entity.play("wave")                 // разово, без ожидания
entity.playLooped("idle_alt")       // зациклено
entity.playClamped("sit")           // удерживает последний кадр
entity.playPingPong("breathe")      // вперёд-назад
entity.stopAnimation("wave")        // плавно убрать раньше времени

val finished = entity.playAndWait("wave") // suspend: ждёт реального конца клипа
```

`playAndWait` - обычная `suspend`-функция: скрипт стоит, пока клип не доиграет. У `NpcEntity` есть ещё фоновая форма `startAnimation(...)`, которая работает на канале `ANIMATION` (см. [Действия и конкурентность](/docs/hollowengine/scripting/npc/actions)), поэтому может играть одновременно с движением и взглядом:

```kotlin
val walking = npc.startMove(player)
npc.startAnimation("walk_wave") // играет параллельно с ходьбой выше
walking.await()
```

`entity.stopAllAnimations()` убирает разом все клипы, запущенные таким способом.

:::advice
У `play`/`playOnce`/`playLooped`/`playClamped`/`playPingPong` одинаковые необязательные `fadeIn`/`fadeOut` (в секундах, по умолчанию `0.33`). Последние четыре - это просто `play(...)` с фиксированным `playMode`.
:::

## Режимы проигрывания

| Режим | Поведение |
|-------|-----------|
| `AnimationPlayMode.Once` | Проигрывает клип один раз, после чего слой убирается. |
| `AnimationPlayMode.Loop` | Зацикливает клип. Для простоя, ходьбы, моргания и других фоновых анимаций. |
| `AnimationPlayMode.ClampForever` | Удерживает последний кадр. Для поз вроде `sit`, `sleep`, `death`. |
| `AnimationPlayMode.PingPong` | Играет вперёд и назад без рывка в начало. |

```kotlin
entity.play("cheer", playMode = AnimationPlayMode.Loop, fadeIn = 0.1, fadeOut = 0.25)
```

## Свой аниматор

Аниматор - это ассет, а не серверный скрипт: стек слоёв с автоматом состояний, процедурными костями, масками и весами. Собирается он в [редакторе аниматоров](/docs/hollowengine/scripting/animator-editor): создайте `.animator` рядом с моделью и сошлитесь на него из `.hemeta`:

```toml
animation-controller = "project:models/entity/guide.animator"
```

Второй способ - зарегистрировать аниматор из кода и сослаться на него по id. Так сделан стандартный аниматор игрока:

```kotlin
AnimatorAssets.register(StandardPlayerAnimatorPreset.ID.rl, StandardPlayerAnimatorPreset.create())
```

```toml
animation-controller = "hollowengine:standard_player"
```

Рассматривайте `StandardPlayerAnimatorPreset` как готовый пример: он собирает автоматический locomotion и процедурный слой взгляда - примерно то, что нужно почти любой гуманоидной модели. Собственный аниматор регистрируйте под своим id до загрузки моделей.

:::advice
Если сущности нужно просто проиграть клип по событию, используйте `play(...)` из скрипта: собственный аниматор для этого не нужен.
:::
