<center><h1>Введение в скриптинг</h1></center>

*Для всех ваших нужд и сомнительных идей!*
![Scripting](/docs/title-scripting.webp)

Скрипты HollowEngine пишутся на Kotlin и размещаются в `hollowengine/scripts`. Их можно редактировать во внешнем редакторе, но встроенная IDE мода уже предоставляет подсветку, диагностику и автодополнение.

![Kotlin-скрипт во встроенном редакторе](/hollowengine/pictures/ide/code-editor.webp)

## Типы скриптов

- [Простой](/docs/hollowengine/scripting/simple) (`.kts`): одноразовый запуск или общий код, например функции и утилиты.
- [Перезагружаемый](/docs/hollowengine/scripting/reload) (`.reload.kts`): обработчики игровых событий. По умолчанию работает на сервере и перезапускается при открытии мира и `/reload`. С аннотацией `@file:ClientSide` работает на клиенте и перезапускается по `F3 + T`.
- [Startup](/docs/hollowengine/scripting/startup) (`.startup.kts`): выполняется один раз при запуске игры. Здесь регистрируются предметы, блоки, вкладки творческого режима и всё остальное, что Minecraft позволяет добавить только при загрузке.
- [Node](/docs/hollowengine/scripting/node) (`.node.kts`): coroutine-обработчики, которые можно прикреплять к серверу или сущности. Подходят для периодических действий, собственных данных, событий сущности и состояний.
- [UI-скрипты](/docs/hollowengine/scripting/ui) (`.ui.kts`): клиентские объявления экранов и HUD-оверлеев. При перезагрузке ресурсов они компилируются заново. Серверные скрипты открывают объявления по id и обновляют их состояние через `UiSession`.
- [Story](/docs/hollowengine/dialogues) (`.story`): ветвящиеся диалоговые сценарии с компактным синтаксисом, переменными, вариантами ответа, управляющими конструкциями и командами для NPC и экранных эффектов. Kotlin-скрипты создают и запускают сессии диалогов.

Типы скриптов отличаются базовым классом, доступным API, стороной выполнения и условиями запуска:

| Тип                                    | Где выполняется             | Когда (пере)запускается                          |
|----------------------------------------|-----------------------------|--------------------------------------------------|
| `.kts`                                 | там, где его запустили      | командой `/hollowengine scripting run`           |
| `.reload.kts`                          | сервер                      | при открытии мира и по `/reload`                 |
| `.reload.kts` с `@file:ClientSide`     | клиент                      | при запуске игры, по `F3 + T` и смене ресурспака |
| `.startup.kts`                         | клиент и сервер             | один раз при запуске игры                        |
| `.node.kts`                            | сервер                      | командой или из другого скрипта                  |
| `.ui.kts`                              | клиент                      | при перезагрузке клиентских ресурсов             |

Для UI-скриптов на клиенте нужен аддон Kotlin scripting compiler. Все скрипты, кроме startup, можно перекомпилировать и обновлять без перезахода в игру или мир.

:::advice
Скрипт любого типа удобно создавать прямо в IDE: правый клик по папке `scripts` в дереве проекта → **New Script**. Файл сразу создаётся с рабочим примером. Подробнее в разделе [Работа с IDE](/docs/hollowengine/ide).
:::
