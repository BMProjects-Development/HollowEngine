<center><h1>Примеры UI</h1></center>

Соберём экран подтверждения, HUD-подсказку и окно с ожиданием ответа. Клиентские объявления храните в `.ui.kts`, серверные действия - в `.node.kts`. В каждом примере указано, какую часть куда вставить.

## Серверный экран подтверждения

`hollowengine/scripts/confirm.ui.kts`:

```kotlin
val Message = dataKey<String>("message") { "Вы уверены?" }

screen("mypack:confirm") {
    title = "Подтверждение"
    content {
        Column(modifier = Modifier.padding(16.px).gap(12.px)) {
            Text(data[Message])
            Row(modifier = Modifier.gap(8.px)) {
                Box(id = "confirm-accept", modifier = Modifier.input(hoverable = true, clickable = true).onClick { send { putString("action", "accept") } }) { Text("Да") }
                Box(id = "confirm-cancel", modifier = Modifier.input(hoverable = true, clickable = true).onClick { send { putString("action", "cancel") } }) { Text("Нет") }
            }
        }
    }
}
```

Создайте `hollowengine/scripts/confirm.node.kts` и прикрепите его к NPC. На клиенте уже должен быть загружен `confirm.ui.kts` (нажмите `F3 + T`). Ключ `Message` объявляем и на сервере с тем же именем и типом:

```kotlin
@file:Attach(NpcEntity::class)

import net.minecraft.server.level.ServerPlayer

val Message = dataKey<String>("message") { "Вы уверены?" }

onInteract { event ->
    val player = event.player as? ServerPlayer ?: return@onInteract
    player.openUi("mypack:confirm") {
        put(Message, "Удалить один камень из инвентаря?")
        onEvent { payload ->
            when (payload.getString("action")) {
                "accept" -> {
                    player.takeItems(itemFilter(item("minecraft:stone")), 1)
                    close()
                }
                "cancel" -> close()
            }
        }
    }
}
```

По ПКМ откроется подтверждение. «Да» удаляет до одного камня, если он есть, «Нет» и Escape закрывают экран без удаления. Для другого игрока откроется отдельная сессия. Неизвестное событие игнорируется.

## Клиентская HUD-подсказка

```kotlin
val Hint = dataKey<String>("hint") { "" }

overlay("mypack:block_hint") {
    anchor(after("crosshair"))
    autoShow = true
    content {
        data.find(Hint)?.takeIf(String::isNotBlank)?.let { hint ->
            Box(modifier = Modifier.padding(4.px).background(UiColor(0f, 0f, 0f, 0.55f))) { Text(hint) }
        }
    }
}
```

Этот оверлей показывается через `autoShow` и не вызывает `send`, поэтому серверная сессия ему не нужна. Серверный вариант использует `player.showOverlay("mypack:block_hint")` и `UiSession.put(Hint, value)`.

## Ожидание выбора в suspend-функции

В UI API нет `ui.await(player)`. Экран может отправлять несколько событий, а его жизненным циклом управляет `UiSession`. Если серверу нужен один выбор, используйте coroutine-адаптер.

UI-объявление отправляет выбор:

```kotlin
screen("mypack:quest_choice") {
    title = "Странник просит о помощи"
    content {
        Column(modifier = Modifier.padding(16.px).gap(8.px)) {
            Text("Принять задание?")
            Box(id = "choice-accept", modifier = Modifier.input(hoverable = true, clickable = true).onClick { send { putString("choice", "accept") } }) { Text("Принять") }
            Box(id = "choice-decline", modifier = Modifier.input(hoverable = true, clickable = true).onClick { send { putString("choice", "decline") } }) { Text("Отказаться") }
        }
    }
}
```

В серверном скрипте один раз добавьте импорты и адаптер:

```kotlin
import kotlin.coroutines.resume
import kotlinx.coroutines.suspendCancellableCoroutine
import net.minecraft.server.level.ServerPlayer

private enum class QuestChoice { ACCEPT, DECLINE }

private suspend fun ServerPlayer.chooseQuest(): QuestChoice? = suspendCancellableCoroutine { continuation ->
    var session: UiSession? = null

    fun finish(choice: QuestChoice?) {
        if (!continuation.isActive) return
        continuation.resume(choice)
        session?.close()
    }

    session = openUi("mypack:quest_choice") {
        onEvent { payload ->
            when (payload.getString("choice")) {
                "accept" -> finish(QuestChoice.ACCEPT)
                "decline" -> finish(QuestChoice.DECLINE)
            }
        }
        onClose { if (continuation.isActive) continuation.resume(null) }
    }
    continuation.invokeOnCancellation { session?.close() }
}
```

После этого suspend-функция обрабатывает результат напрямую. Escape и закрытие сервером возвращают `null`. Отмена корутины закрывает сессию и прерывает ожидание с отменой:

```kotlin
when (player.chooseQuest()) {
    QuestChoice.ACCEPT -> println("Игрок принял задание")
    QuestChoice.DECLINE -> println("Игрок отказался от задания")
    null -> println("Выбор закрыт без ответа")
}
```

Проверяйте выбор на сервере. Неизвестный payload не закрывает экран.
