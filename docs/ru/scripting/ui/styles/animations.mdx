<center><h1>Анимации и трансформации</h1></center>

Для переходов, keyframes, трансформаций и фильтров используйте API модификаторов и HSS. Движок стилей не изменился; удалён только старый синтаксис XML-атрибутов.

## Переходы

Переход интерполирует style property при смене вычисленного значения, обычно между базовым селектором и `:hover`, `:active` или `:selected`.

```css
.card { transitions: background 120ms ease-out, scale 120ms ease-out; }
.card:hover { background: #5F8CCD; scale: 1.04; }
```

Kotlin-эквивалент: `Modifier.transition(UiTransition("scale", 120, TransitionEasing.EASE_OUT))`. Переход задаётся на базовом узле, а не внутри правила состояния.

## Keyframes

Для повторяющейся или многоэтапной анимации используйте `@keyframes`:

```css
@keyframes attention {
    0%, 100% { translate-y: 0; }
    50% { translate-y: -3; }
}

.notification { animations: attention 700ms ease-in-out infinite; }
```

Кадр может задавать одну ось (`translate-y`, `scale-x`, `rotate-z`), оставляя две другие такими, какими их выставил базовый стиль.

Из Kotlin ту же именованную анимацию запускайте явно:

```kotlin
Box(modifier = Modifier.animation("attention", durationMillis = 700, iterationCount = Float.POSITIVE_INFINITY)) {
    Text("Новая награда")
}
```

## 2D/3D-трансформации и фильтры

`translate`, `rotate`, `scale`, `perspective` и `pivot` объединяются в трансформацию. В HSS им соответствуют `translate`, `rotate`, `scale`, `perspective`, `transform-origin` и `backface-visibility`. `filter` и `backdrop-filter` поддерживают blur, grayscale и shader-эффекты.

Анимируйте только видимые узлы и сохраняйте стабильные id элементов в списках. Для движения интерфейса используйте transition, keyframe или текстовый эффект. `rebuildEveryFrame` перекомпоновывает всю поверхность и предназначен для содержимого, которое читает игровое состояние в каждом кадре.
