<center><h1>HSS-файлы</h1></center>

HSS является языком таблиц стилей для общего оформления UI. `.ui`-файлы и атрибут `style` больше не поддерживаются. Подключайте таблицу стилей из Kotlin через `Modifier.style`.

```kotlin
Column(id = "shop", modifier = Modifier.style("mypack:ui/styles/shop.hss")) {
    Text("Магазин", tags = listOf("title"))
}
```

```css
#shop { padding: 16px; gap: 8px; background: #141824; }
#shop .title { foreground: #FFD166; font-size: 18px; }
.button:hover { background: #5F8CCD; }
```

Resource location разрешается так же, как другие ассеты. Используйте `id` для селектора `#id`, а `tags = listOf("tag")` для `.tag`.

HSS хорошо подходит для палитр, повторяющейся геометрии, переходов и псевдосостояний. Вычисляемые Kotlin-значения и поведение оставляйте в `Modifier`. Свойства HSS по-прежнему работают с тем же layout и renderer, но больше не записываются XML-атрибутами.

Таблицы стилей живут в файлах: скрипт подключает их по resource location, поэтому оформление экрана остаётся читаемым и перезагружается отдельно от кода. Собрать таблицу стилей из строки прямо в скрипте больше нельзя.

## Селекторы

| Селектор | Что выбирает |
| --- | --- |
| `box`, `text`, `image` | Узлы этого типа |
| `.tag` | Узлы с таким тегом |
| `#id` | Узел с таким id |
| `:hover`, `:active`, `:focus`, `:selected`, `:disabled`, `:dragging` | Узлы в этом состоянии; имя может быть любым, в том числе своим через `Modifier.state("expanded")` |
| `[attribute]`, `[attribute="value"]` | Узлы с атрибутом |
| `.panel .title` | Потомок совпадения на любой глубине |

Состояние в любом звене цепочки делает всё правило зависимым от состояния, поэтому родитель может перекрашивать своих детей:

```css
.button .icon { tint: #8E99AB; }
.button:hover .icon { tint: #FFFFFF; }
```

Правила состояний складываются друг с другом и накладываются поверх всего остального, поэтому `.button:hover .icon` меняет `tint`, выставленный самому узлу из Kotlin.

## Рецепт декорации

```css
.quest-card {
    padding: 12px;
    gap: 6px;
    background: linear-gradient(135deg, #14203D, #2B4D78);
    border: 1px #8FB8FFB3;
    border-radius: 8px;
    box-shadow: 0px 3px 8px #00000073;
    transition: background 120ms ease-out, scale 120ms ease-out;
}

.quest-card:hover {
    background: linear-gradient(135deg, #1C2D54, #39649B);
    scale: 1.03;
}
```

HSS поддерживает градиенты, текстурные фоны, `image-fit`/nine-slice, `clip`, фигуры, тени, прозрачность, tint, фильтры, трансформации и скроллбары. Для текстуры используйте `background: image("namespace:textures/...")`. Для масштабируемой рамки укажите `image-fit: 9-slice 16px`.

`@keyframes` задаёт повторно используемые кадры анимации. Селектор кадра - `from`, `to` или процент от одной итерации; список через запятую (`0%, 100%`) отдаёт один блок нескольким смещениям. Пропущенный крайний кадр подразумевается: без `0%`/`100%` отрезок идёт от собственного значения узла или к нему. Из Kotlin именованную анимацию запускает `Modifier.animation(name, durationMillis, iterationCount, easing)`; общую анимацию можно назначить и правилом HSS.

## Полный справочник свойств

Там, где ожидается длина, HSS принимает `px`, `%`, число без суффикса (пиксели), `fill`, `fit` и `auto`. Цвет: `#RRGGBB`, `#RRGGBBAA`, `rgb(r,g,b)`, `rgba(r,g,b,a)`, `white`, `black` или `transparent`. Четыре значения отступов идут в порядке `top right bottom left`.

### Размер, отступы и layout

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `size` | `<width> <height>` | Ширина и высота одновременно |
| `width`, `height` | длина | Одно измерение |
| `min-size`, `max-size` | `<width> <height>` | Минимальные или максимальные размеры |
| `min-width`, `min-height`, `max-width`, `max-height` | длина | Одна граница размера |
| `aspect-ratio` | число или `width / height` | Сохраняет требуемое соотношение |
| `padding`, `margin` | 1–4 длины | Внутренние или внешние отступы |
| `padding-left/top/right/bottom`, `margin-left/top/right/bottom` | длина | Одна сторона отступа |
| `padding-x`, `padding-y`, `margin-x`, `margin-y` | длина | Горизонтальные или вертикальные отступы. `*-horizontal`, `*-vertical`, `*-inline`, `*-block` являются алиасами |
| `gap` | длина | Расстояние между детьми в row/column |
| `grow` | неотрицательное число | Доля свободного места row/column |
| `position` | `<x> <y> [z]` | Позиция в free/stacked-контейнере |
| `align` | `<horizontal> [vertical]` | Выравнивание текущего узла |
| `align-items` | `<horizontal> [vertical]` | Выравнивание детей контейнера |
| `align-x`/`align-horizontal`, `align-y`/`align-vertical` | значение выравнивания | Одна ось выравнивания узла |
| `align-self`, `justify-self`, `justify`/`justify-content` | значение выравнивания | Точное выравнивание |

Значения выравнивания: `auto`, `start`/`flex-start`, `center`, `end`/`flex-end`, `stretch`, `space-between`, `space-around`, `space-evenly`, а также `justify` там, где оно применимо.

### Фон, границы, изображения и фигуры

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `background` | цвет, `none`, `image(...)`, `url(...)`, `shader(...)`, `linear-gradient(...)` или `radial-gradient(...)` | Основной фон |
| `background-image` | ресурс изображения | Сокращение для фона-изображения |
| `foreground` или `color` | цвет | Наследуемый цвет текста |
| `image` | ресурс изображения | Контент-изображение `Image`-узла |
| `shader` | имя шейдера | Контентный шейдер |
| `border` | `<width> [colour]` | Толщина и цвет границы |
| `border-width`, `border-color`, `border-radius` | inset, цвет, число | Части границы по отдельности |
| `border-top`, `border-right`, `border-bottom`, `border-left` | `<width> [color]` | Толщина одной стороны; цвет общий для всей границы |
| `shadows` (`shadow`, `box-shadow`) | `inset? <x> <y> <blur> [spread] <color>`, через запятую | Одна или несколько внешних/внутренних теней; `none` очищает |
| `opacity`, `tint` | число, цвет | Общая прозрачность или tint изображения |
| `image-fit` или `fit` | `stretch`, `contain`/`fit`, `cover`/`zoom`, `none`, `9-slice`, `3-slice-vertical`, `3-slice-horizontal` | Режим масштабирования изображения |
| `image-slice` или `slice` | 1–4 длины | Края nine-/three-slice; можно написать после `image-fit` |
| `image-uv` или `uv` | `none` или `<x> <y> <ширина> <высота>` | Участок исходной текстуры, в её собственных координатах: `px`/число без суффикса — пиксели текстуры, `%` — доля размера. `image-fit`, обрезка `cover` и nine-slice считаются от этого прямоугольника, поэтому один атлас питает много узлов |
| `shape` | `path("...")`, `svg-path("..." [, viewBox])` или `svg("namespace:path")` | Векторная форма узла |
| `shape-fill`/`fill`, `shape-stroke`/`stroke`, `shape-stroke-width`/`stroke-width` | paint, paint, длина | Рендеринг фигуры |
| `clip` или `clip-path` | boolean, `path(...)`, `svg-path(...)` или `svg(...)` | Обрезает детей по границам или векторной форме |
| `layer` | целое число | Локальный порядок рисования |

`linear-gradient(angle?, colour [stop], colour [stop], ...)` принимает градусы и stop offset от `0..1` или в процентах. `radial-gradient(radius? at x y?, colour [stop], ...)` принимает радиус и центр как длины или проценты.

### Трансформации и фильтры

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `translate`, `rotate` | `<x> [y] [z]` | Смещение в пикселях или поворот в градусах |
| `scale` | `<x> [y] [z]` | Масштаб по осям; отсутствующий y равен x |
| `translate-x/y/z`, `rotate-x/y/z`, `scale-x/y/z` | число | Одна ось, не трогая две другие, удобно внутри `@keyframes` |
| `transform` | `translate(...) scale(...) rotate(...) perspective(...)` | Объединяет 2D/3D-трансформации; `none` сбрасывает всё |
| `pivot` или `transform-origin` | именованная точка или `<x> <y> [z]` | Центр трансформации; есть `top-left`, `center`, `bottom-right` |
| `perspective` | число | Дистанция 3D-перспективы |
| `backface-visibility` | `visible` или `hidden` | Обратная сторона повёрнутого узла |
| `filter`, `backdrop-filter` | `grayscale(amount)`, `blur(radius)`, `shader(name)` | Фильтрует узел либо пиксели за ним; `none` очищает цепочку |

### Ввод и скроллбары

Сама прокрутка не является свойством стиля: контейнер прокрутки владеет офсетом, поэтому объявляется в коде через `Modifier.scrollable` (он же и привязывает этот офсет). Таблица стилей оформляет получившиеся бары.

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `hoverable`, `clickable`, `focusable`, `draggable`, `input-transparent` | boolean | Включает соответствующий ввод или пропуск указателя |
| `cursor` | `default`, `hand`, `move`, `text`, `crosshair`, `resize-horizontal`, `resize-vertical`, `resize-nesw`, `resize-nwse` | Форма курсора над узлом; наследуется детьми |
| `scrollbar`/`scrollbar-width`/`scrollbar-thickness` | длина | Толщина скроллбара; `0px` убирает бар средствами стиля |
| `scrollbar-margin`, `scrollbar-min-thumb` | длина | Внешний отступ и минимальный размер thumb |
| `scrollbar-overlay` | boolean | Рисует бар поверх контента вместо резервирования места, вытесняющего контент |
| `scrollbar-track`, `scrollbar-thumb` | paint | Фон track или thumb |
| `scrollbar-track-border`, `scrollbar-thumb-border` | значение border | Граница track или thumb |
| `scrollbar-track-radius`, `scrollbar-thumb-radius` | число | Радиус углов |
| `scrollbar-track-fit`, `scrollbar-thumb-fit` | значение image-fit | Масштабирование изображения части |
| `scrollbar-track-slice`, `scrollbar-thumb-slice` | 1–4 длины | Slice-края части |

| `slider-track`, `slider-active-track`/`slider-fill`, `slider-thumb` | paint | Paint дорожки, заполненной дорожки и бегунка |
| `slider-thumb-border` | значение border | Граница бегунка |

| `checkbox-mark`, `checkbox-active`/`checkbox-fill` | paint | Галочка и активный фон |
| `checkbox-variant`/`checkbox-style` | `checkbox`, `radio`/`radio-button` или `switch`/`toggle` | Представление checkbox |
| `caret-color`/`text-field-caret`, `selection-color`/`text-selection` | цвет | Каретка и выделение text field |
| `text-shadow`/`text-field-shadow` | `<x>, <y>, [blur], [colour]` или `none` | Тень под глифами поля |

### Текст

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `text-wrap`/`wrap` | `wrap`/`true` или `nowrap`/`false` | Включает перенос строк |
| `text-overflow` | `show`, `hidden`/`clip` или `dots`/`ellipsis` | Поведение при переполнении |
| `text-align` | `left`/`start`, `right`/`end`, `center`, `justify` | Выравнивание строк |
| `white-space`/`whitespace` | `normal`/`collapse` или `pre`/`preserve`/`pre-wrap` | Обработка пробелов |
| `line-spacing`/`text-line-spacing`/`leading` | неотрицательное число | Дополнительный интервал строк |
| `space-width`/`text-space-width` | неотрицательное число | Явная ширина пробела |
| `font-size` | длина, `85%` или `0.85em` | Размер шрифта; доля берётся от текста вокруг |
| `font-family` | имя шрифта | Семейство шрифта |
| `box-decoration-break` | `slice` или `clone` | Рисование inline-декорации через перенос строк |
| `text-effects` (`text-effect`) | эффекты через запятую | Inline-декорации и текстовые анимации |

`font-size: 85%` и `font-size: 0.85em` означают одно и то же: долю унаследованного размера, которая превращается в пиксели при разрешении стиля. Подпись, написанная так, поспевает за размером текста вокруг, поэтому inlay-подсказки следуют за шрифтом редактора кода.

Текстовые эффекты: `bold`, `italic`, `underline`, `strikethrough`, `code`, `link(url)`, `color(color)`, `font-size(size)`, `font-family(name)`, `shadow(x, y, blur, colour)`, `outline(width, colour)`, `glow(radius, colour, quality)`, `gradient(...)`, `typewriter`, `rainbow`, `pulse`, `wave(amplitude, frequency, speed, phase)`, `shake(amplitude, frequency, seed)`, `wiggle(amplitude, frequency, speed, angle)`, `swing`, `scroll`, `glitch`. Эффекты перечисляются через запятую; `none` очищает их.

### Движение

| Свойство | Значение | Назначение |
| --- | --- | --- |
| `transitions` (`transition`) | `<property> <duration> [easing]`, через запятую | Интерполирует изменения свойства; `none` удаляет переходы |
| `animations` (`animation`) | `<name> <duration>? <easing>? <count>? <direction>? <fill>? <state>?`, через запятую | Запускает keyframe-анимации; `none` очищает их |
| `animation-name`, `animation-duration`, `animation-timing-function`, `animation-delay`, `animation-iteration-count`, `animation-direction`, `animation-fill-mode`, `animation-play-state` | списки через запятую | Отдельные поля анимации |

Длительность задаётся в `ms`, `s` или миллисекундах без суффикса. Easing: `linear`, `ease`, `ease-in`, `ease-out`, `ease-in-out`, `step-start`, `step-end`, `steps(count, start|end)`, `cubic-bezier(x1,y1,x2,y2)`. Число повторов: неотрицательное число или `infinite`. Direction: `normal`, `reverse`, `alternate`, `alternate-reverse`. Fill mode: `none`, `forwards`, `backwards`, `both`. Play state: `running` или `paused`.

## В редакторе

Встроенный редактор читает ту же схему свойств, что и компилятор, поэтому предлагает ровно то, что движок примет. То есть куда удобнее пользоваться им, чем внешними редакторами, вроде VSCode.

- Автодополнение показывает свойство вместе с сигнатурой - `margin: <top> <right> <bottom> <left>`, а после двоеточия подсказывает значения того слота, на котором стоит курсор. Имена анимаций берутся из блоков `@keyframes` этого файла, а `transitions` дополняет именами свойств, которые действительно умеют анимироваться.
- Inlay-подсказки называют части сокращений: `margin: 8px 8px 60px 8px` читается как `top=8px right=8px bottom=60px left=8px`.
- У строки вида `namespace:path` и в таблице стилей, и в Kotlin-скрипте, появляется кнопка, открывающая файл. Файлы из `hollowengine/assets` открываются на редактирование, ресурсы игры - только на чтение.
