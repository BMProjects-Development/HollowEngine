# UI-панели в мире

`panel(id)` объявляет интерфейс, который рисуется на плоской панели в игровом мире: терминал, табло или кнопка на модели. Панель прикрепляется через риг к кости или ко всей модели и следует за её движением.

## Объявление и размещение

В клиентском `.ui.kts` объявите панель:

```kotlin
panel("project:terminal") {
    size(256, 160)
    content {
        Column(modifier = Modifier.padding(12.px).gap(8.px)) {
            Text("Терминал")
            Box(
                id = "terminal-open",
                modifier = Modifier.input(hoverable = true, clickable = true)
                    .onClick { send { putString("action", "open") } },
            ) {
                Text("Открыть")
            }
        }
    }
}
```

В [редакторе ригов](/docs/hollowengine/models/rig-editor) добавьте прикрепление **UI-панель** и укажите `project:terminal`. Настройте ширину в блоках, смещение и поворот. Высота в мире определяется пропорциями `size`; лицевая сторона направлена по локальной оси `+Z`.

У прикрепления есть интерактивность, дальность взаимодействия (по умолчанию 5 блоков) и собственное свечение. Для декоративного табло интерактивность можно отключить. Игрок взаимодействует с панелью, наведя на неё прицел; поверхности перед ней перекрывают доступ.

## Параметры объявления

| Параметр                           | По умолчанию         | Назначение                                                                 |
|------------------------------------|----------------------|----------------------------------------------------------------------------|
| `width`, `height` или `size(w, h)` | `256 × 160`          | Разрешение панели, от 1 до 1024 пикселей по каждой стороне.                |
| `frameRate`                        | `30`                 | Максимальная частота перерисовки.                                          |
| `background`                       | `0xFF101418.toInt()` | Фон в формате ARGB; панель непрозрачна.                                    |
| `keyboard`                         | `false`              | Разрешить ввод текста.                                                     |
| `rebuildEveryFrame`                | `false`              | Перекомпоновывать при каждой перерисовке для чтения живого состояния игры. |

При `keyboard = true` клик по текстовому полю передаёт ему клавиатуру до Escape или отвода взгляда. Без этого панель не забирает клавиши у игры.

## Данные и серверные действия

В `content` доступны `entity` (владелец панели), `data` (его синхронизируемые данные) и `isHovered`. Данные сущности общие для всех зрителей; локальное состояние Compose у каждого зрителя своё. Панель не открывает `UiSession`, поэтому `player.openUi(...)` для неё не требуется.

`send { ... }` отправляет NBT-сообщение серверу. В `.node.kts`, прикреплённом к той же сущности, обработайте его:

```kotlin
onPanelEvent("project:terminal") { event ->
    if (event.payload.getString("action") == "open") {
        event.player.openUi("project:terminal_menu")
    }
}
```

Обработчик получает `entity`, `player`, `panel` и `payload`. Без аргумента `onPanelEvent { ... }` принимает события всех панелей этой сущности. Проверяйте условия игрового действия на сервере: например, права игрока и доступность терминала.
