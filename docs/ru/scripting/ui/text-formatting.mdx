<center><h1>Форматирование текста</h1></center>

Текст собирается в Kotlin. Для простой строки используйте `Text(value)`. Для inline-потока используйте форму с содержимым, `Span`, `Image` и inline-виджеты.

```kotlin
Text(modifier = Modifier.foreground(UiColor.White)) {
    Span("Задание: ", modifier = Modifier.fontSize(16f))
    Span(data[Title])
    Image("mypack:textures/ui/star.png", modifier = Modifier.size(8.px, 8.px))
}
```

## Inline-текст и эффекты

Цвет, шрифт, переносы, выравнивание и эффекты задаются модификаторами или HSS. Эффекты представлены Kotlin-значениями, поэтому их можно переиспользовать и вычислять:

```kotlin
Text(
    "Легендарный",
    modifier = Modifier
        .foreground(UiColor(1f, 0.82f, 0.25f))
        .fontSize(18f)
        .textEffects(
            Shadow(offsetX = 1.5f, offsetY = 1.5f, color = UiColor(0f, 0f, 0f, 0.7f)),
            Glow(radius = 4f, color = UiColor(1f, 0.75f, 0.2f, 0.65f)),
        ),
)
```

Доступны `Bold`, `Italic`, `Underline`, `Strikethrough`, `TextColor`, `TextSize`, `Shadow`, `Outline`, `Glow`, `Gradient`, `Rainbow`, `Pulse`, `Wave`, `Shake`, `Wiggle`, `Swing`, `Scroll` и `Glitch`. Анимированные текстовые эффекты используют UI frame clock и не требуют `rebuildEveryFrame`.

XML-теги и XML-атрибуты текста не входят в формат скриптового UI. Форматированные фрагменты собирайте через `Text { Span(...) }`, а модификатор эффекта ставьте на нужный run или контейнер текста.

Для изменяющегося значения читайте `DataKey` в `Text`: серверный патч автоматически перекомпонует текст. Для локальной анимации используйте Compose state. Включайте `rebuildEveryFrame`, только если поверхности нужен кадровый таймер.
