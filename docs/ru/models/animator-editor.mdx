<center><h1>Редактор аниматоров</h1></center>

Настройте, как модель стоит, идёт и переключается между анимациями. Редактор сохраняет правила в `.animator`: слои задают совместное проигрывание, а граф состояний - переходы между действиями.

---

## Что он редактирует

Аниматор - то, чем модель анимирует себя сама: список слоёв, поверх которых серверный скрипт добавляет уже свои разовые клипы. Файл `.animator` хранит весь стек, редактор показывает весь стек.

Чтобы модель начала его использовать, сошлитесь на файл из её [метаданных](/docs/hollowengine/models):

```toml
animation-controller = "project:models/entity/guide.animator"
```

Файл кладите рядом с моделями или анимациями. Движок ищет `.animator` в папках `models` и `animations`. Новый файл создаётся как обычный: правый клик по папке в дереве проекта, `guide.animator`. Пустой файл - это пустой аниматор, редактор откроется сразу.

## Слои

Окно **Сцена** показывает слои и состояния контроллеров. Через его контекстное меню добавляются слои: **Контроллер** (автомат состояний), **Клип** (одна анимация) и другие доступные виды.

- Клик по слою открывает его: у контроллера появляется граф, у клипа - только параметры.
- Контекстное меню или `Delete` удаляет выбранный слой вместе с раскладкой его графа.
- **Сцена** и **Инспектор** открываются из меню **Окна** и располагаются как остальные панели IDE.

Порядок в списке ни на что не влияет - смешиванием управляет **приоритет** в параметрах слоя: слои применяются от меньшего к большему.

![Слой](/hollowengine/pictures/animation_controller/layer.webp)

## Граф состояний

Каждый узел - состояние: имя, клип, режим проигрывания. Начальное состояние помечено иконкой в правом нижнем углу.

| Действие         | Как                                              |
|------------------|--------------------------------------------------|
| Выделить         | клик по узлу, стрелке или её подписи             |
| Передвинуть узел | перетаскивание                                   |
| Создать переход  | `Ctrl` + перетаскивание от одного узла к другому |
| Перемещение      | перетаскивание пустого места                     |
| Зум              | колесо мыши                                      |
| Меню узла        | правый клик по узлу                              |
| Меню графа       | правый клик по пустому месту                     |
| Снять выделение  | клик по пустому месту                            |

Правый клик по узлу выдаёт список действий: «Сделать входным», «Сделать любым состоянием» и «Удалить». Правый клик по пустому месту - «Добавить состояние», «Добавить любое состояние» и «сбросить вид».

Мини-карта в правом нижнем углу показывает весь граф: наведение на иконку подписывает состояние, клик - переносит к нему.

![Узлы и миникарта](/hollowengine/pictures/animation_controller/nodes_and_minimap.webp)

### Любое состояние

Узел «Any State» - это источник переходов, разрешённых из любого состояния. То есть создав переход из него в любое состояние, переход будет срабатывать вне зависимости от того, какая была запущена анимация. Очевидно, поэтому сделать переход **в** любое состояние нельзя, а **из** него - можно.

![Any State](/hollowengine/pictures/animation_controller/any_state.webp)

## Смешивание клипов

Состояние **Смешивание** плавно сочетает несколько клипов по одному или двум параметрам. В одномерном режиме разместите покой, ходьбу и бег на оси скорости: между соседними точками их веса меняются автоматически. В двумерном режиме разместите клипы движения вперёд, назад и в стороны на плоскости и задайте выражения обеих осей, например `local_side_speed` и `local_forward_speed`.

У каждого клипа задаётся положение на оси или плоскости и собственный множитель скорости. Общие скорость и режим проигрывания относятся ко всему состоянию. Диапазоны осей ограничивают входные значения.

Состояние **Монтаж** проигрывает файл `.montage` во время нахождения в состоянии. Подробнее расписано в разделе [Монтажей](/docs/hollowengine/models/montages).

## Параметры

Общий **Инспектор** показывает параметры выбранного слоя, состояния или перехода.

**Слой** - имя, приоритет, вес, появление и затухание, смешивание (перезаписываемое / `override` или добавочное / `additive`). У слоя-клипа дополнительно анимация, режим и скорость.

![Настройки слоя](/hollowengine/pictures/animation_controller/layer_inspector.webp)

**Состояние** - имя, анимация, режим проигрывания, скорость. Ниже список его переходов: клик по строке `from → to` выделяет переход на графе. Там же кнопки «Сделать входным» и «Удалить состояние».

![Настройки состояния](/hollowengine/pictures/animation_controller/state_inspector.webp)

**Переход** - условие, длительность кроссфейда, приоритет и время завершения.

![Настройки перехода](/hollowengine/pictures/animation_controller/transition_inspector.webp)

:::advice
Появление и затухание есть у слоя, а не у состояния: плавный переход между анимациями делается через изменение длительности перехода.
:::

## Выражения

Вес, скорость, длительность и условие - это [выражения](/docs/hollowengine/models/animations), а не числа. В полях работает подсветка, автодополнение (в том числе после точки: `q.` предлагает члены `q`) и диагностика.

Кроме `q.` (состояние сущности), `v.`/`t.` (свои переменные) и `math.` доступен `d.` - [синхронизированные данные сущности](/docs/hollowengine/scripting/npc/data#syncing-to-the-client) по пути внутри NBT: `d.emotion.happy > 0.5`.

```text
horizontal_speed > 0.02
is_alive != 0.0 && is_sneaking != 0.0
movement_animation_speed / 1.43
```

## Горячие клавиши

В таблице указаны стандартные назначения; изменить их можно через **Помощь > Горячие клавиши**. Там же назначается действие, у которого изначально нет сочетания.

| Клавиша                 | Действие                                |
|-------------------------|-----------------------------------------|
| `Delete`                | удалить выбранное состояние или переход |
| `Escape`                | снять выделение                         |
| `F`                     | сбросить вид                            |
| `E`                     | сделать выбранное состояние входным     |
| `Insert` или `Ctrl + N` | новое состояние в центре вида           |

## Сохранение

Файл сохраняется автоматически примерно через секунду после последней правки. Аниматор, собранный кодом, работает точно так же, но его можно перезаписать ресурспаком.

Чтобы игра применила изменения, перезагрузите ресурсы (`F3 + T`).

---

## Чего пока нет

- просмотра модели прямо в редакторе - один аниматор может работать для нескольких моделей, поэтому и предпросмотра пока нет;
- редактирования процедурных слоёв - они показываются только на чтение;
- поиска по состояниям.
