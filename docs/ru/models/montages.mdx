# Монтажи анимаций

Монтаж объединяет клипы модели, движения отдельных костей, временные прикрепления и именованные события на одном таймлайне. Например, один монтаж атаки может проиграть замах, включить коллайдер оружия, запустить VFX и подать скрипту сигнал для нанесения урона.

## Создание

Создайте `hollowengine/assets/project/montages/attack.montage` и откройте его в IDE. Пустой файл открывается как новый монтаж. В Инспекторе выберите модель предпросмотра и длительность в секундах. Модель предпросмотра помогает редактировать монтаж; в игре он применяется к модели сущности, на которой запущен, поэтому имена клипов и костей должны совпадать.

В **Сцене** выбираются кости и прикрепления, в **Таймлайне** редактируются клипы, ключи, события и секции, а **Инспектор** показывает выбранное. Общие приёмы работы описаны в разделе [Таймлайн](/docs/hollowengine/ide/timeline).

## Клипы и кости

Добавьте клип и выберите имя анимации модели. У клипа задаются начало на таймлайне, длительность, смещение внутри исходной анимации, скорость, повтор, плавное появление и затухание. Пересекающиеся клипы смешиваются; маска костей ограничивает часть тела, на которую действует клип. Вес клипа тоже можно анимировать ключами.

У выбранной кости можно анимировать сдвиг, поворот, масштаб и видимость. Эти поправки применяются поверх клипов: например, можно довернуть кисть, не переделывая исходную анимацию. Скрытие кости скрывает и её потомков. Для записи позы используйте кнопку ключа у свойства или `I` в окне модели.

## Прикрепления на время действия

Добавьте прикрепление к кости или ко всей модели, как в [редакторе ригов](/docs/hollowengine/models/rig-editor), и задайте окна его активности. Оно существует только на соответствующих участках монтажа. Так можно временно включать коллайдер, звук, вложенную модель или эффект. Доступные виды зависят от установленных аддонов.

Ключами можно менять поля как временных прикреплений, так и прикреплений основного рига. Например, двигать цель IK или менять размер эффекта. Монтаж не переписывает файл `.rig`: его изменения действуют во время воспроизведения.

## Запуск из скрипта

Запускайте монтаж на сервере. Полный id указывает путь внутри `assets/<namespace>/`; расширение `.montage` необязательно.

```kotlin
val completed = npc.playMontage("project:montages/attack") {
    onEvent("hit") {
        // Здесь выполняется действие в момент события hit.
    }
}
```

`playMontage` это suspend-функция: ждёт завершения и возвращает `true`, если монтаж доиграл, или `false`, если его остановили, заменили, либо не удалось загрузить.

Для параллельного действия используйте `startMontage`:

```kotlin
val action = npc.startMontage("project:montages/charge", fadeIn = 0.1, speed = 1.2)
action?.onEvent("ready") { println("Заряд готов") }
action?.jumpTo("release")
action?.await()
action?.stop(fadeOut = 0.3f)

// Можно остановить и без сохранённого объекта управления.
npc.stopMontage("project:montages/charge", fadeOut = 0.3)
```

`startMontage` возвращает `null`, если сервер не смог прочитать ассет. Объект управления предоставляет `isPlaying` и `time` в секундах. Повторный запуск того же id на той же сущности заменяет предыдущее воспроизведение. Именованные события добавляются на таймлайне; при повторе секции обработчик может сработать снова. `jumpTo` переходит к событию и продолжает воспроизведение с него.

Монтаж также можно выбрать состоянием в [аниматоре](/docs/hollowengine/models/animator-editor). Для серверной логики по событиям используйте запуск из скрипта и `onEvent`.
