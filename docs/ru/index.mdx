## Что такое __HollowEngine__?

HollowEngine это полноценная платформа для создания контента внутри Minecraft:

- Встроенная IDE поверх игрового клиента;
- Полноценный Kotlin скриптинг (`.kts`) с поддержкой корутин, взаимодействием с игровым миром и сохранением состояния скриптов;
- NPC, 3D-модели, анимационные контроллеры, источники света с гибкой настройкой;

## Установка

На текущий момент поддерживется NeoForge и Fabric для 1.21.1.
Актуальная версии мода доступна на [GitHub](https://github.com/HollowHorizon/HollowEngine/releases/tag/latest-1.21.1). Для написания скриптов необходимо установить аддон `HollowEngineCompiler`, он также есть на GitHub.

Аддоны кладутся либо в обычную папку `mods` рядом с самим модом, либо в `hollowengine/addons`. Разницы нет: движок ищет их в обеих папках, а если один и тот же аддон окажется в обеих, будет загружена версия поновее.

## С чего начать?

Если открываете мод впервые, вы могли уже заметить шестерёнку в левом верхнем углу экрана. Нажав на неё откроется главная панель мода с несколькими вкладками:
- Файл: Раздел с полезными функциями: открытие папки мода, перезагрузки клиентских и серверных ресурсов.
- Окна: Раздел с разными окнами движка, здесь уже лежит основной функционал движка: Файлы проекта, Катсцены, Редакторы и т.п.
- Инструменты: Раздел с вспомогательными функциями, сейчас там только управление трансформациями моделей.
- Помощь: Раздел с полезной информацией вроде ссылок на сообщество проекта или документацией.

По файлам проекта и путям к ресурсам сначала посмотри [Ассеты](/docs/hollowengine/assets). Там описано, куда складывать модели, UI, HSS, текстуры, звуки и скрипты.

## Рабочая папка

Практически весь пользовательский контент живёт в директории `hollowengine`, которую мод создаёт в папке с игрой. Внутри неё важнее всего:

```text
hollowengine/
├─ assets/            # Папка с клиентскими ресурсами
│  ├─ hollowengine/     # Ресурсы для проекта HollowEngine
│  └─ project/          # Ресурсы для проекта project
├─ data/              # Папка с серверными ресурсами
│  ├─ hollowengine/     # Данные для проекта HollowEngine
│  └─ project/          # Данные для проекта project
├─ scripts/           # Папка для ваших скриптов
│  └─ example.kts       # Пример файла скрипта
```

Пути к скриптам считаются относительно `hollowengine/scripts/`. Ресурсы указываются через resource location, например `project:models/npc.gltf` ссылается на `hollowengine/assets/project/models/npc.gltf`.
