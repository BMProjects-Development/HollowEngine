## Что такое __HollowEngine__?

HollowEngine это полноценная платформа для создания контента внутри Minecraft:

- Встроенная IDE поверх игрового клиента;
- Полноценный Kotlin скриптинг (`.kts`) с поддержкой корутин, взаимодействием с игровым миром и сохранением состояния скриптов;
- NPC, 3D-модели, анимационные контроллеры, источники света с гибкой настройкой;

## Установка

HollowEngine поддерживает NeoForge и Fabric для Minecraft 1.21.1. Актуальная версия мода доступна на [GitHub](https://github.com/HollowHorizon/HollowEngine/releases/tag/latest-1.21.1).

Установите jar HollowEngine в обычную папку `mods`. Для написания и компиляции скриптов также установите аддон `HollowEngineCompiler` из того же релиза.

Аддоны кладутся либо в `mods` рядом с HollowEngine, либо в `hollowengine/addons`. Движок проверяет обе папки. Если один id аддона есть в обеих, при запуске выбирается более новая версия; при одинаковых версиях приоритет у копии из `hollowengine/addons`.

## Рабочая папка

Практически весь пользовательский контент живёт в директории `hollowengine`, которую мод создаёт в папке с игрой. Внутри неё важнее всего:

```text
hollowengine/
├─ assets/            # Папка с клиентскими ресурсами
│  ├─ hollowengine/     # Ресурсы для проекта HollowEngine
│  └─ project/          # Ресурсы для проекта project
├─ data/              # Папка с серверными ресурсами
│  ├─ hollowengine/     # Данные для проекта HollowEngine
│  └─ project/          # Данные для проекта project
├─ scripts/           # Папка для ваших скриптов
│  └─ example.kts       # Пример файла скрипта
└─ addons/            # Необязательная папка для аддонов HollowEngine
```

Пути к скриптам считаются относительно `hollowengine/scripts/`. Ресурсы указываются через resource location, например `project:models/npc.gltf` ссылается на `hollowengine/assets/project/models/npc.gltf`.
