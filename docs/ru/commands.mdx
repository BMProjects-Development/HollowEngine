<center><h1>Команды</h1></center>

*Прописав в чате символ для команд `/`, вы могли заметить совершенно новую команду 👀*

![Команды HollowEngine в чате](/hollowengine/pictures/commands/chat.webp)

Мод добавляет довольно много полезных команд, которые можно найти через 2 основные команды:

| Команда         | Описание           |
| --------------- | ------------------ |
| `/hollowengine` | Полное имя команды |
| `/he`           | Короткий алиас     |

Команды `scripting` и `addons`, что-либо меняющие, требуют прав оператора (уровень 2).

---

# Скриптинг

| Команда                                        | Описание                                                                                    |
|------------------------------------------------|---------------------------------------------------------------------------------------------|
| `/he scripting run <path>`                     | Запустить обычный скрипт, запустить node-скрипт на сервере или подменить тела mixin-скрипта |
| `/he scripting run <path> <state>`             | Запустить node-скрипт в указанном состоянии                                                 |
| `/he scripting stop <path>`                    | Остановить запущенный серверный node-скрипт                                                 |
| `/he scripting attach <entity> <path>`         | Прикрепить node-скрипт (с `@file:Attach`) к сущности                                        |
| `/he scripting attach <entity> <path> <state>` | То же, но с запуском в указанном состоянии                                                  |
| `/he scripting detach <entity> <path>`         | Открепить node-скрипт от сущности                                                           |
| `/he scripting list`                           | Список запущенных серверных нод                                                             |
| `/he scripting list entity <entity>`           | Список нод, прикреплённых к сущности                                                        |
| `/he scripting compile`                        | Скомпилировать все скрипты и заполнить кэш, чтобы пак работал без аддона компилятора        |

Скрипт из аддона пишется с пространством имён: `/he scripting run my-addon:nodes/quest.node.kts`. См. [Скриптинг](/docs/hollowengine/scripting) и [Скрипты и ресурсы в аддонах](/docs/hollowengine/addons/scripts).

# Аддоны

| Команда                   | Описание                                   |
|---------------------------|--------------------------------------------|
| `/he addons list`         | Показать все аддоны с версией и состоянием |
| `/he addons enable <id>`  | Включить аддон                             |
| `/he addons disable <id>` | Отключить аддон                            |
| `/he addons reload <id>`  | Перезагрузить аддон                        |

Встроенные аддоны добавляют собственные команды: `/he mcp` ([MCP-сервер](/docs/hollowengine/addons/mcp)) и `/he video` ([Видео](/docs/hollowengine/addons/media)). См. [Аддоны](/docs/hollowengine/addons).

# VFX

Запустите `.vfx` эффект в позиции или на сущности:

```mcfunction
/he vfx ~ ~1 ~ project:sparks
/he vfx @s project:sparks
```

`project:sparks` указывает на `hollowengine/assets/project/vfx/sparks.vfx`. Как создать файл и пользоваться редактором, см. в [Визуальные эффекты (VFX)](/docs/hollowengine/vfx), а как управлять эффектами из скрипта - в [Запуск эффектов](/docs/hollowengine/vfx/playback).

# Частицы

Bedrock-частицы (`.bedrock.json`) запускаются отдельными командами.

| Команда                        | Описание                            |
|--------------------------------|-------------------------------------|
| `/he particle <pos> <name>`    | Создать эффект частиц в позиции     |
| `/he particle <entity> <name>` | Привязать эффект частиц к сущности  |
| `/he remove-particles <name>`  | Удалить все частицы указанного типа |

### Аргументы

| Аргумент | Тип      | Описание          |
|----------|----------|-------------------|
| `pos`    | `vec3`   | Позиция           |
| `entity` | `entity` | Целевая сущность  |
| `name`   | `string` | ID эффекта частиц |

### Примеры

```mcfunction
/he particle ~ ~1 ~ hollowengine:example
/he particle @s hollowengine:trail
/he remove-particles hollowengine:trail
```

# Модели

## Информация

| Команда                     | Описание                                       |
|-----------------------------|------------------------------------------------|
| `/he model <model>`         | Показать информацию о модели: клипы, материалы |
| `/he model info <model>`    | То же самое                                    |
| `/he model entity <entity>` | Показать модель, которую показывает сущность   |

Так можно узнать настоящие названия анимаций модели, прежде чем проигрывать их или использовать в скриптах.

## Прикрепление моделей

| Команда                             | Описание                     |
|-------------------------------------|------------------------------|
| `/he model attach <entity> <model>` | Прикрепить модель к сущности |

## Отключение ванильной модели

| Команда                                    | Описание                         |
|--------------------------------------------|----------------------------------|
| `/he model hide-vanilla <entity> <hidden>` | Скрыть/показать ванильную модель |

## Установка пресета

| Команда                                          | Описание                                        |
|--------------------------------------------------|-------------------------------------------------|
| `/he model player-preset <entity>`               | Применить стандартный пресет                    |
| `/he model player-preset <entity> <hideVanilla>` | То же самое, но с настройкой «скрыть ванильную» |

# Анимации

## Запуск

| Команда                                                                   | Описание                    |
|---------------------------------------------------------------------------|-----------------------------|
| `/he model animation play <entity> <animation>`                           | Проиграть анимацию          |
| `/he model animation play <entity> <animation> <mode>`                    | Проиграть анимацию в режиме |
| `/he model animation play <entity> <animation> <mode> <fadeIn> <fadeOut>` | Полная команда              |

### Аргументы

| Аргумент  | Тип      | Значения                                   |
|-----------|----------|--------------------------------------------|
| `mode`    | `string` | `once`, `loop`, `clampforever`, `pingpong` |
| `fadeIn`  | `float`  | `0..10`                                    |
| `fadeOut` | `float`  | `0..10`                                    |

Без режима анимация проигрывается один раз (`once`).

## Остановка

| Команда                                                | Описание                         |
|--------------------------------------------------------|----------------------------------|
| `/he model animation stop <entity> <animation>`        | Остановить анимацию              |
| `/he model animation stop <entity> <animation> <fade>` | Остановить анимацию с затуханием |
