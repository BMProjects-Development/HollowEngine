# Работа с миром

Здесь собраны инструменты для наполнения игрового мира и постановки сцен. Большинство настроек можно сделать в IDE; примеры скриптов на соответствующих страницах помогают связать результат с игровыми событиями.

| Раздел | Что можно сделать |
| --- | --- |
| [Объекты мира](/docs/hollowengine/world/objects) | Разместить модели, эффекты и звуки, собрать иерархию объектов и настроить отдельный экземпляр. |
| [Декали](/docs/hollowengine/world/decals) | Нанести изображение или видео на поверхности окружения. |
| [Коллайдеры](/docs/hollowengine/world/colliders) | Добавить столкновения, области взаимодействия и попадания по частям модели. |
| [Катсцены](/docs/hollowengine/world/cutscenes) | Поставить камеру, анимировать время суток и погоду и запустить сцену игроку. |

Для подготовки ассетов см. [модели и анимацию](/docs/hollowengine/models) и [VFX](/docs/hollowengine/vfx). Общие операции с ключами, кривыми и секциями описаны в [Таймлайне](/docs/hollowengine/ide/timeline).
