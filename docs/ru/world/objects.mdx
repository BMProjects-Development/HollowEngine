# Объекты мира

Объект мира - это размещённая в мире декорация, модель, звук, декаль или VFX. У него нет здоровья, ИИ и гравитации; он сохраняется вместе с миром и не исчезает как обычный моб. Компоненты и node-скрипты позволяют добавить ему логику, взаимодействие и коллайдеры.

## Размещение

Включите режим редактирования в меню **Инструменты**. Для редактирования мира нужны права на использование команд (читы). Перетащите файл из `assets/` в дереве проекта или менеджере ассетов в окно игры внутри IDE:

| Ассет                | Результат                        |
|----------------------|----------------------------------|
| Модель               | Объект с моделью.                |
| `.vfx`               | Эффект в мире.                   |
| Аудиофайл            | Источник звука.                  |
| `.png`               | Декаль на поверхности.           |
| Поддерживаемое видео | Видео-декаль; нужен аддон Media. |

Маркер показывает место размещения. При попадании на блок объект ставится на его поверхность; если под курсором ничего нет, то в воздухе перед камерой. Пустой объект можно создать в **Сцене** для группировки других объектов.

## Сцена и иерархия

Когда активна работа с миром, окно **Сцена** показывает его объекты. Можно выбрать отображение ближайших, попавших в кадр или всех загруженных объектов. Поиск проходит по всем загруженным объектам, независимо от выбранного фильтра.

Перетаскивание в дереве меняет родителя. Дочерний объект следует за перемещением, поворотом и масштабом родителя; при смене родителя его положение в мире сохраняется. Контекстное меню позволяет отвязать объект, дублировать, удалить, опустить на землю, скопировать UUID или добавить в избранное. Избранное помогает снова найти объект, в том числе когда его чанк выгружен.

Объект с моделью можно раскрыть и увидеть его кости и прикрепления. Правки конкретного экземпляра позволяют менять его позу и вложенные части без изменения исходного ассета для остальных объектов.

## Трансформации и история

Выберите объект или его часть в мире либо в Сцене. Числа редактируются в **Инспекторе**, а положение - через Gizmo в окне просмотра. Сочетания клавиш по умолчанию:

| Сочетание                       | Действие                                            |
|---------------------------------|-----------------------------------------------------|
| `G`, `R`, `S`                   | Перемещение, поворот, масштаб.                      |
| `X`, `Y`, `Z`                   | Ограничить начатую трансформацию определённой осью. |
| `Enter` / ЛКМ                   | Подтвердить.                                        |
| `Escape` / ПКМ                  | Отменить текущую трансформацию.                     |
| `Alt + G`, `Alt + R`, `Alt + S` | Сбросить соответствующую трансформацию.             |
| `Ctrl + D`, `Delete`            | Дублировать или удалить выбранное.                  |

Ориентацию манипулятора можно переключить между локальной и мировой. Изменения мира поддерживают отмену и повтор; окно **История** позволяет вернуться к выбранному шагу. Подробнее о переназначении клавиш и выборе истории можно прочитать в [работе с IDE](/docs/hollowengine/ide).

Для интерфейса/оверлеев на объектах используйте [UI-панели](/docs/hollowengine/scripting/ui/world-panels), для изображений на окружении - [декали](/docs/hollowengine/world/decals), для блокирующей геометрии и областей взаимодействия - [коллайдеры](/docs/hollowengine/world/colliders).
