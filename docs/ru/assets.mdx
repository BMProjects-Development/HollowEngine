<center><h1>Ассеты</h1></center>

*Куда класть модели, текстуры, UI, звуки, скрипты и другие ресурсы проекта.*

![Ассеты и скрипты в дереве проекта](/hollowengine/pictures/ide/project-tree.webp)

HollowEngine загружает пользовательский контент из папки `hollowengine/` в директории игры. Все файлы, которые указываются через resource location, используют обычную структуру Minecraft: `assets/<namespace>/`.

Для проекта лучше выбрать отдельный namespace, например `project`. Тогда `project:textures/ui/panel.png` будет ссылаться на файл:

```text
hollowengine/
└─ assets/
   └─ project/
      └─ textures/
         └─ ui/
            └─ panel.png
```

## Основные папки

| Папка | Для чего | Пример ссылки |
|-------|----------|---------------|
| `assets/project/textures/` | UI-текстуры, текстуры сущностей, иконки | `project:textures/ui/icon.png` |
| `assets/project/models/` | glTF, Blockbench и модели сущностей | `project:models/entity/guide.gltf` |
| `assets/project/ui/` | HSS-стили и другие ресурсы интерфейса | `project:ui/dialogs/confirm.hss` |
| `assets/project/sounds/` | Пользовательские звуки | `project:sounds/voice/hello.ogg` |
| `scripts/` | Kotlin-скрипты и диалоги `.story` | `quest/intro.node.kts` |

Держи связанные файлы рядом. UI объявляется Kotlin-скриптом в `hollowengine/scripts`, а HSS и текстуры лежат в `hollowengine/assets` и доступны через resource location:

```text
hollowengine/
├─ assets/project/
│  ├─ ui/dialogs/quest.hss
│  └─ textures/ui/quest_portrait.png
└─ scripts/ui/quest.ui.kts
```

## Как ссылаться на ассеты

В Kotlin UI, HSS и скриптах используй полные resource location:

```kotlin
Column(modifier = Modifier.style("project:ui/dialogs/quest.hss")) {
    Image("project:textures/ui/quest_portrait.png")
}
```

```css
.panel {
    background: image("project:textures/ui/panel.png");
}
```

```kotlin
val guide = npc(
    pos = pos(10.0, 64.0, 10.0),
    model = "project:models/entity/guide.gltf",
)
```

Импорты Kotlin-скриптов разрешаются внутри namespace скрипта, а не как resource location. Подробнее в разделе [Импорты скриптов](/docs/hollowengine/scripting/imports).

## Практические правила

- Переиспользуемые UI-стили складывай в `assets/project/ui/components/`, а общий Kotlin-код интерфейсов — в `scripts/ui/`.
- Общие UI-текстуры держи в `assets/project/textures/ui/`, а локальные для одного экрана можно хранить рядом с этим экраном.
- Используй resource location вместо абсолютных путей.
- Текстуры модели держи в том же namespace, что и модель.
- Рядом с моделью может лежать `<модель>.hemeta`, см. [Модели и материалы](/docs/hollowengine/scripting/models).
- В путях используй нижний регистр и символы `a-z`, `0-9`, `_`, `-`, `.`, `/`.

Если ассет используется из `.ui.kts` или `.hss`, укажи это рядом с документацией интерфейса, чтобы при изменениях не искать связь по всем скриптам.
